The body is made of blocks: paragraphs, headings, lists, quotes, callouts, toggles, tables, code blocks, dividers and more. Everything can be set from the floating toolbar, many blocks can also be inserted from the slash menu, and Markdown shortcuts work as you type. Every formatting change can be undone in one step.

## Text styles

- **Bold, Italic, Underline, Strikethrough, Superscript, Subscript, Inline code**: select text and tap the matching toolbar button. Clear formatting removes the formatting from the selection.
- **Font size**: tap Font size to open a panel with Small, Normal, Large and Huge.
- **Text color / Background color**: opens a color panel above the toolbar with three pages:
  - Swatches: the default color and 12 preset colors, with a row of your own colors below;
  - Material: the full Material shades; swipe sideways to change the color family;
  - Custom: pick any color from a spectrum, adjust opacity for backgrounds, or type a color code. Colors you mix here are saved to your colors automatically (up to 24 each for text and background); tap the pen button or long-press a swatch to manage them.

## Headings and alignment

- **Header style**: opens a panel with Body and headings 1 to 6. You can also type `# ` at the start of a line (two # for heading 2, and so on).
- **Alignment**: Align left, Center, Align right or Justify, applied to the whole block.

## Lists, checklists and indent

- The toolbar has Ordered list, Bullet list and Checklist. Tap the button again while the cursor is already in that kind of list to open the list style panel. Numbered lists can use 1., (1), ①, 一、, a., A., i. or I.; bulleted lists can use a filled dot, hollow circle, square, diamond, star, arrow or dash. The whole list changes together.
- Checklist items can be ticked right on the preview page, and the change is saved.
- **Indent / Outdent**: on a normal paragraph it indents only the first line by two characters; on lists, checklists and toggles it changes the nesting level.

## Quotes, callouts and toggles

- **Quote**: tap Quote or type `> ` at the start of a line. Neighboring quote paragraphs share one continuous bar.
- **Callout**: a colored block with an emoji icon. With the cursor in a callout, tap Callout again to change the icon (💡 📌 ⭐ ✅ ⚠️ ❗ ❓ 📝), change the color (Default, Yellow, Green, Blue, Red, Purple) or Convert to text.
- **Toggle**: a heading line with content underneath that can be collapsed. While editing, tap the triangle to collapse or expand it (this is saved). On the preview page, opening it only changes what you see this time; the entry isn't changed.

## Tables

Tap Table to insert a 3 × 3 table with a header row. With the cursor in a cell, tap Table again for Row above, Row below, Column left, Column right, Delete row, Delete column, Header row (on or off) and Delete table. Tables always fill the width with equal columns and never scroll sideways; the editor allows up to 6 columns. Tab and Shift + Tab move between cells, and Tab in the last cell adds a row.

## Code blocks and dividers

- **Code block**: tap Code block to turn the current line into a code block. Inside one, tap it again to choose a language (automatic detection, plain text or 22 languages), Copy code, Exit code block or Convert to text. Empty lines are allowed inside; pressing Enter on a second empty line in a row at the end leaves the block. Set the color theme, line numbers, font and more in Settings → Editor → Code block style.
- **Divider**: tap Divider or type `---` at the start of a line to insert a horizontal line at the cursor.

## Pasting Markdown

When pasted text is clearly Markdown (headings, lists, quotes, code, tables, bold, links and so on), it turns into the matching formatting. Ordinary text pastes as one paragraph per line, and formatted content from web pages keeps its formatting. Pasting into a code block or table cell keeps the raw text; on desktop, Ctrl / ⌘ + Shift + V always pastes plain text.

## Good to know

- The body font, size, line height, paragraph spacing and first-line indent are set in one place: Settings → Editor → Body font & layout. See "Body text layout and editor settings".
- Desktop shortcuts: Ctrl / ⌘ + B and I for bold and italic, Ctrl / ⌘ + Shift + H for a yellow highlight, Ctrl / ⌘ + . and Ctrl / ⌘ + , for superscript and subscript, Ctrl / ⌘ + K for a link.
