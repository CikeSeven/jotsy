The editor has the title at the top and the body below, with a floating toolbar at the bottom while the keyboard is up. For formatting, see "Text formatting and blocks"; for pictures, videos and recordings, see "Photos, videos and recordings".

## Where to start a new entry

- The New button at the bottom right of the Diaries page (inside a notebook it reads "Write in" plus the notebook's name, and the new entry goes into that notebook). An empty list also has a button in the middle.
- Calendar: long-press a day and choose "Write for this day", or tap "Write for this day" on a past date with no entries.
- On desktop, press Ctrl / ⌘ + N.

If you have drafts, "Continue a draft" opens first: pick up a recent draft, view all drafts, "Start from a template" or "New blank entry". A new blank entry never deletes a draft.

## Title and body

- The title is optional; cards use the first line of the body instead.
- Markdown shortcuts convert as you type. At the start of a line, `# ` makes a heading (`## ` for heading 2, and so on), `- ` or `* ` a bulleted list, `1. ` a numbered list, `[] ` a checklist item (`[x] ` for a ticked one), `> ` a quote and `---` a divider. A line with only `` ``` `` followed by Space or Enter becomes a code block (you can add a language name, such as `` ```dart ``). Inline, you can type `**bold**`, `*italic*`, `~~strikethrough~~`, `` `inline code` `` and `[text](URL)` links. Inside code blocks and table cells these symbols stay as typed.
- New entries save to Drafts as you write, and by default edits to existing entries save automatically, so there's no save button to press. With **Save edits manually** turned on in Settings → Editor, edits to an existing entry are saved only when you tap the save button in the top bar (or press Ctrl / ⌘ + S on a computer); going back with unsaved edits asks Cancel / Exit / Save and exit, and Exit discards them.

## The floating toolbar

- It appears at the bottom while the keyboard is up and hides when the keyboard goes away. On desktop it's always shown.
- The first slots are Undo, Redo, Recording, Bold, Italic, Underline, lists, Insert image and so on. Tools that don't fit in one row go into More at the right end. If a tool in More is in effect, a small dot lights up on More.
- Colors, Header style, Alignment, Font size, list styles, code blocks, tables and callouts open a panel above the toolbar without closing the keyboard.
- Insert current time writes the current time at the cursor. Change its format with the gear next to it on the toolbar order page.

## Slash commands

Type / in the body to open the "Insert block" menu next to the cursor: paragraph, headings 1 to 6, quote, callout, toggle, code block, lists, divider, table, insert image, video or attachment, diary card, recording and more. Keep typing to filter (Chinese names also match pinyin, such as /biaoti). Tap outside the menu or press Back to close it; what you typed stays.

## Undo, redo and moving blocks

- The first two toolbar buttons are Undo and Redo. On desktop you can also press Ctrl / ⌘ + Z.
- A small handle sits to the left of the block with the cursor. Tap it for "Move block up", "Move block down" or "Hold to drag", or long-press the handle and drag the block to a new spot. One undo puts it back.

## Selecting text

On a phone, long-press to select and a menu appears by the selection: Cut, Copy, Paste and Select all (plus AI when the AI assistant is on). More has Share and, on Android, text actions from other apps such as translation. On desktop, right-click for a menu with shortcut hints.

## Editing an existing entry

Edit on the preview page, double-tapping the preview text on a phone, Edit in the right pane on wide windows, or Edit in a card's right-click menu on desktop all open the editor. It looks just like the preview page, and the title and body can be changed in place:
- Tap the body to place the cursor; the keyboard and toolbar follow. Done in the top bar closes the keyboard.
- Tap the details bar under the title (or More → Edit details) to change the cover, tags, notebooks, place and weather, publish time, mood and energy.
- More also has Share, Export, Write a comment, Save as template, Photos from this day, Delete and more.

## Editor settings

In Settings → Editor: Toolbar order (drag to reorder, untick a tool to hide it), Toolbar size (Small, Standard, Large, Extra large) and Always show toolbar (phones only). Under Behavior: Open diaries in the editor (skip the preview page), Publish new diaries when going back, Save edits manually, and Show that day's photos automatically. See "Body text layout and editor settings" for details.

## Good to know

- With the AI assistant on, the toolbar and slash menu gain AI writing (continue, polish, summarize and more).
- On desktop you can drag pictures, videos or files straight into the body.
