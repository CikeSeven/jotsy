正文由一块块内容组成：段落、标题、列表、引用、提示块、折叠块、表格、代码块、分隔线等。格式都能从悬浮工具栏设置，很多也能从斜杠菜单插入，或用 Markdown 写法直接输入。每次改格式都可以一步撤销。

## 文字样式

- **加粗、斜体、下划线、删除线、上标、下标、行内代码（单行）**：选中文字后点工具栏上对应的按钮。
- **清除格式**：作用于光标所在或选区碰到的每一整段（不只是选中的几个字）：去掉加粗、颜色、链接等全部行内格式并转回正文，标题、列表、待办、引用和对齐也会一起去掉，可以一步撤销。
- **链接**：点工具栏的“链接”（桌面也可以按 Ctrl / ⌘ + K），在“网址”页填“链接地址”后点“确认”。选中了文字时给这段文字加上链接；没选文字时不会插入任何字，接着打的字会成为这条链接，打出空格或换行就结束。光标在已有链接上时可以改网址，或点“移除链接”。
- **字号**：点“字号”展开面板，选小、正文、大、特大。
- **文字颜色 / 背景颜色**：在工具栏上方展开颜色面板，分三页：
  - 色板：默认色和 12 种预设颜色，下方一行是“我的颜色”；
  - 色系：Material 全套色阶，左右滑动换色系；
  - 自定义：在色谱里自由取色，背景色可调不透明度，也能输入颜色代码。在这里调出的颜色会自动存进“我的颜色”（文字色、背景色各最多 24 个），点笔形按钮或长按色块可以管理。

## 标题与对齐

- **标题样式**：展开面板，选正文或一到六级标题；也可以在行首输入 `# `（两个 # 是二级，依此类推）。
- **对齐**：左对齐、居中、右对齐、两端对齐，作用于整段。

## 列表、待办与缩进

- 工具栏有“有序列表”“无序列表”“待办列表”。光标已在这种列表里时再点一次，会展开列表样式面板：有序可选 1.、(1)、①、一、、a.、A.、i.、I.，无序可选实心圆点、空心圆、方块、菱形、星形、箭头、短横线，整段列表一起改。
- 待办在预览页也能直接勾选，自动保存。
- **增加 / 减少缩进**：普通段落只缩进首行两个字；列表、待办和折叠块是改变层级。

## 引用、提示块与折叠块

- **引用**：点“引用”或行首输入 `> `，相邻几段引用的竖条会连成一条。
- **提示块**：带 emoji 图标的彩色块。光标在提示块里时再点“提示块”，可以换图标（💡 📌 ⭐ ✅ ⚠️ ❗ ❓ 📝）、换底色（默认、黄、绿、蓝、红、紫）或“转为正文”。
- **折叠块**：标题行下挂着可以收起的内容。编辑时点行首三角收起或展开（会保存）；在预览页点开只改变这次的显示，不改动日记。

## 表格

点“表格”插入 3 × 3、带表头行的表格。光标在格子里时再点“表格”，可以上方 / 下方插入行、左侧 / 右侧插入列、删除行、删除列、开关表头行或删除表格。表格铺满宽度、各列等宽，不会横向滚动，编辑器里最多 6 列。Tab / Shift + Tab 在格子间移动，最后一格按 Tab 追加一行。

## 代码块与分隔线

- **代码块**：点“代码块（多行）”把当前行转为代码块。在代码块里再点它，可以选语言（自动识别、纯文本或 22 种语言）、复制代码、退出代码块或转为正文。代码块里可以留空行，在末尾连续第二个空行上回车才退出。配色主题、行号、字体等在“设置 → 编辑器 → 代码块样式”里调。
- **分隔线**：点“分隔线”或在行首输入 `---`，在光标处插入一条横线。

## 粘贴 Markdown

粘贴的文字明显是 Markdown（标题、列表、引用、代码、表格、粗体、链接等）时，会自动转成对应格式；普通文字照常每行一段，网页上排好版的内容按原格式粘贴。粘到代码块或表格格子里时保留原文；桌面上 Ctrl / ⌘ + Shift + V 始终粘贴纯文字。

## 注意

- 正文字体、字号、行距、段间距和首行缩进在“设置 → 编辑器 → 正文字体与排版”里统一设置，见《正文排版与编辑器设置》。
- 桌面快捷键：Ctrl / ⌘ + B、I 加粗和斜体，Ctrl / ⌘ + Shift + H 黄色高亮，Ctrl / ⌘ + . 和 Ctrl / ⌘ + , 上标和下标，Ctrl / ⌘ + K 插入链接。
