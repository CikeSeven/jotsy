日记卡片（首页、搜索、归档、日历里的卡片）、日记预览页（阅读日记的页面）和首页导航栏都能自定义外观。三个样式页用法相同：顶部是实时预览，下面是分标签的选项，改动立即生效。

## 在哪里
- 设置 → 外观 →「页面样式」组：**日记卡片样式**、**日记预览页**、**导航栏样式**。
- 阅读日记时，点预览页顶栏的“更多” → **页面样式**，直接进入预览页样式。
- 背景与材质页「玻璃」标签的“分别设置”分组末尾，也有导航栏样式和日记卡片样式的入口。

## 共同用法
- 预览上方可切换浅色 / 深色预览；卡片样式还能切换列表 / 瀑布流，两种布局分别调整。
- 「预设」标签：点内置风格一键套用；**保存当前样式** 存进“我的样式”（最多 12 个）；**复制样式码** 发给朋友或留作备份；**从剪贴板导入** 套用别人分享的样式码。
- 右上角 **重置** 恢复默认样式，之后可以撤销。
- 自定义颜色时可以打开“深色模式自动配色”，按浅色值推导出暗色下易读的颜色。

## 日记卡片样式
- 内置风格：经典（默认）、紧凑、杂志、极简、画廊、便签、手账、心情色、玻璃。
- 标签依次为：预设、布局、封面、内容、日期、排序、字体、色彩、质感。
- **色彩**：材质 实色 / 玻璃（玻璃的模糊只在页面设置了背景图时才有）；**卡片底色** 可选默认、主色、次色、第三色、心情、首个标签、自定义；卡片不透明度；**渐变底色**（从卡片底色过渡到第二种颜色，默认关闭）。
- **内容**：显示标题、**没有标题时用正文第一行作标题**（默认开，关闭后直接省略标题行）、显示摘要、标题与摘要最多行数、标签样式与最多显示几个标签（可设为不显示）、置顶标记与“置顶卡片着色”、显示心情 / 天气，以及“底栏附加信息”：地点、精力、字数、图片与附件标记、留言数（留言数只在开启留言功能时出现）。
- 其他标签：封面位置、大小、形状与多图拼贴；日期格式、星期、时刻与日期依据；拖动调整卡片各部分的顺序；字号、字重、颜色与 **自动保证可读**；圆角、间距、瀑布流列数；描边、强调色条与阴影。

## 日记预览页样式
- 内置预设：经典（默认）、纸书、杂志、极简、夜读、手账、心情色、沉浸。
- **页面**：配色基调（跟随应用 / 心情 / 首个标签 / 自定义）与着色强度（柔和 / 原色 / 鲜明），“取不到颜色时”用跟随应用或中性灰；基调不跟随应用且纸张为“主题”时，还可开“纸张随基调染色”与“背景遮罩随基调染色”（有背景图片时才起作用）；纸张（主题、暖白、米黄、护眼绿、浅灰、墨色、自定义）、自定义正文颜色、左右边距、限制正文宽度、顶栏（随滚动隐藏 / 固定，显示哪些按钮）、阅读进度线、回到顶部按钮。
- **头图**：通栏 / 内嵌 / 不显示，高度、圆角，没有封面时是否用正文第一张图。
- **标题**、**信息**：标题大小、字重、对齐、颜色，没有标题时是否显示“无标题”；信息栏放在标题上方、标题下方或正文之后，排成分行、单行或信息卡，选择显示日期、字数、阅读时长、地点、天气、心情、精力、标签等。
- **正文**：字体与排版（与编辑页共用）、“最后编辑于”的格式；阅读行为：允许勾选待办、允许长按选择文字、双击正文进入编辑（只在手机上）、长图折叠或完整显示。
- **翻页**：“阅读行为”一组有左右滑动切换日记（按打开时所在列表的顺序，默认开），开着时还有 **翻页灵敏度**（灵敏 / 标准 / 防误触，默认标准；越往后越需要更水平的滑动才翻页，“防误触”还要拖过半屏或用力一甩）与翻页时轻震；下面是翻页效果（平移 / 层叠 / 淡入）、正文末尾显示上一篇 / 下一篇、到头时提示。
- 预设与样式码不改变阅读行为：正文页的允许勾选待办、允许长按选择文字、双击正文进入编辑、长图显示，以及翻页页的左右滑动、翻页灵敏度、翻页时轻震。翻页效果、上一篇 / 下一篇与到头时提示属于样式：套用预设会把它们恢复为默认，样式码也会带上它们。

## 导航栏样式
- 管首页底栏，以及日记、日历、探索、设置的顶栏。内置风格：经典（默认）、玻璃、通透、浓雾、主题色、紧凑。
- **材质**：实色 / 玻璃。玻璃时底栏变成悬浮胶囊，可调模糊强度、不透明度、色调、阴影与描边，并可打开 **顶栏也用玻璃**。
- **悬浮栏**（只在玻璃下使用）：高度、圆角、两侧边距、离底距离；新建按钮放在 **栏上方** 或 **栏右侧**。
- **导航项**：文字（始终显示 / 仅选中项 / 不显示）、图标大小、选中指示器（胶囊 / 色块 / 无）。
- **行为**：下滑时收起底栏（只在玻璃悬浮栏下可用）、指示器跟随滑动。

## 注意
- 窗口较宽时（例如电脑上）首页底栏换成左侧导航栏。
- 三种样式都随完整备份导出。
- AI 助手不能替你改这些样式，但可以帮你打开对应页面。
