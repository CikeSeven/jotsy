网盘备份把数据备份到你自己的网盘、WebDAV 服务器或对象存储，换机或重装后可以直接从那里恢复。Jotsy 没有自己的服务器，备份只发往你填写或授权的位置。

## 在哪里
设置 → 数据管理 → 网盘备份。可以添加多个备份位置，每个位置单独设置。

## 添加备份位置
点“添加备份位置”，从三组里选一个：
- **网盘（授权登录）**：Google Drive、OneDrive、Dropbox、百度网盘、阿里云盘（以面板里实际列出的为准）。在网盘官方页面授权，应用只能访问它自己的备份目录；按网盘不同，可能弹出系统账号选择、显示授权代码让你到授权页面输入，或在浏览器授权后把授权码粘贴回来。位置页会写明备份存放的文件夹：Google Drive 的「Jotsy」文件夹，OneDrive、Dropbox 的「应用」文件夹，百度网盘的「我的应用数据」，阿里云盘为授权时选的文件夹（默认根目录的「Jotsy」）。授权失效时（例如阿里云盘授权到期）点位置页的“重新授权”。
- **WebDAV**：坚果云、123云盘、Alist / OpenList、CloudDrive2、Nextcloud、ownCloud、Seafile、群晖 NAS、威联通 NAS、Koofr、pCloud、pCloud (EU)、InfiniCLOUD、Hetzner Storage Box、kDrive、Yandex Disk、Mail.ru Cloud，或“其他 WebDAV”。填服务器地址、用户名、密码或 Token 与远程目录，每项服务下面有填写说明。夸克、115 等可以经 Alist / OpenList 挂载后当作 WebDAV 用。
- **对象存储（S3 兼容）**：阿里云 OSS、腾讯云 COS、七牛云 Kodo、华为云 OBS、火山引擎 TOS、百度智能云 BOS、京东云 OSS、Amazon S3、Amazon S3（中国区）、Cloudflare R2、Backblaze B2、Wasabi、DigitalOcean Spaces、Scaleway、Storj、IDrive e2、Akamai (Linode)、Oracle Cloud、Google Cloud Storage、MinIO，或“其他 S3 兼容存储”。填服务地址、区域、存储桶与访问密钥。

列表里没有的服务，只要支持 WebDAV 或 S3 兼容接口，就能用“其他 WebDAV”或“其他 S3 兼容存储”自己填写；既不在网盘一组、又不支持这两种接口的网盘不能直接用。

填好后可以先“测试连接”，再“保存配置”。地址、密码与授权只保存在本机，不会写进备份文件。

## 备份
位置页上方有三个按钮：
- **备份**：增量备份，只上传新增和变化的内容；照片等媒体按内容去重，同一份在网盘上只存一次；数据没有变化时什么都不传。第一次备份时设定密码（留空不加密），密码记在本机，之后的备份都用它。
- **上传完整 ZIP**：上传一份完整备份文件，可选加密，也能下载下来在 数据管理 → 导入数据 里恢复。
- **刷新列表**：重新读取下方的“远程备份”。

网盘上已有增量备份时（例如在另一台设备上备份过），点“备份”会让你选：**接着备份**（加密的要输入它的密码），已上传的照片与媒体不用重传；或 **开始新的一串**，要重新上传全部照片与媒体。

“增量备份”一组里还可以设置：
- **保留份数**：10 / 30 / 100 / 全部，默认 30 份。更早的增量备份自动删除，只被它们用到的照片与媒体一并清理。完整 ZIP 不会被自动删除。
- **自动备份**：先手动备份成功一次才能开启，频率为每天或每周。打开或离开应用时、以及使用期间每小时检查一次，到时间就在后台静默备份；新增内容超过 50 MB 时不上传，显示“需要手动备份”。结果显示在位置列表和位置页里。
- **重新设置密码**：让本机忘掉现在的增量备份密码，自动备份随之暂停，下次备份时重新选择。本机记住的密码打不开网盘上的备份（可能在另一台设备上换过密码）时也用它。

## 从网盘恢复
“远程备份”里完整 ZIP 和增量备份按时间排在一起。点一份的“恢复”，先预检，再选择合并或覆盖本机数据，规则与本地导入相同，见《备份与恢复》。恢复增量备份时，本机已有的照片直接复用，只下载缺少的部分；在别的设备上恢复加密的增量备份要输入当时的密码。在新设备上恢复增量备份后，会记住这串备份和密码，之后点“备份”直接接着备份，已在网盘上的照片不用重传。

## 注意
- 增量备份的密码请自己记好，换设备恢复时需要它。
- 坚果云等网盘有流量和请求次数限制，增量备份更省额度；遇到限流或断网会自动重试，下次接着传。
- “移除此备份位置”只清除本机保存的连接信息与授权，网盘里的备份文件不会删除；删除某份远程备份不能撤销。
- 网盘操作只能你自己完成，AI 助手可以帮你打开网盘备份页面。
