Jotsy 有 Windows 与 Linux 桌面版，界面和手机版是同一套，只是按窗口宽度换成更适合电脑的布局，并加上键盘与鼠标操作。

## 宽窗口布局
- 窗口宽一些时，首页底栏换成左侧导航栏：顶部是新建按钮，设置固定在栏底。
- 窗口足够宽时，日记标签页变成左右两栏：左边是日记列表，点一篇在右边直接阅读，正在阅读的卡片外圈有一道细环。窗口变窄后点卡片照常打开预览页。
- 日历在很宽的窗口里分成两栏（左边月历，右边选中日的内容）；设置、搜索、日记本等页面居中排版，不会被拉得过宽。

## 快捷键
- 首页：**Ctrl + N** 新建日记（在待办页为新建待办），**Ctrl + F** 搜索日记，**Ctrl + 1～5** 切到第几个标签页。
- 双栏阅读：**↑ / ←** 上一篇，**↓ / →** 下一篇，**Enter** 编辑，**Delete** 删除（先确认，可撤销），**Esc** 取消选中。
- 预览页与看图页：鼠标停在页面上时左右边缘出现翻页按钮；**← / →** 或 **PageUp / PageDown** 翻页，**Esc** 返回。看长图时滚轮上下滚动，**Ctrl + 滚轮** 缩放。
- 阅读时选中文字可 **Ctrl + C** 复制、**Ctrl + A** 全选。
- 编辑正文：**Ctrl + K** 插入或修改链接，**Ctrl + Shift + H** 高亮，**Ctrl + .** 上标，**Ctrl + ,** 下标，**Ctrl + Shift + V** 粘贴为纯文本，**Esc** 返回。

## 鼠标操作
- **右键菜单**：日记、搜索、归档列表的卡片上点右键，可以编辑、置顶 / 取消置顶、收进或移动到日记本、归档 / 取消归档、删除；键盘的菜单键或 Shift + F10 也能打开。待办在电脑上同样用右键菜单代替滑动。
- **多选**：Ctrl + 点击卡片逐张勾选，Shift + 点击选中一段范围。首页标签栏里 Ctrl + 点击标签可以多选标签（相当于手机上的长按）。
- 编辑正文时右键弹出复制、粘贴等菜单；从文件管理器把图片或文件拖进正文，出现“松开以插入”后松手，即插入到光标处。
- 横向滚动的条带可以按住鼠标拖动，或用 Shift + 滚轮横向滚动。

## 与手机版不同的地方
- 没有侧滑归档，改用右键菜单；编辑页工具栏一直显示；预览页双击正文是选词，不会进入编辑。
- 没有拍照和录像，图片、视频按钮直接打开文件选择；没有补写时的“这天拍的照片”；地点和天气不能自动获取，可以手动填写。
- 待办提醒只在 Jotsy 打开时弹出，关掉应用后到点的提醒不会弹出。
- 保存图片、视频和导出文件时弹出系统的“另存为…”对话框；正文里的视频不在页内播放，点按 **用系统播放器打开**。
- 不能直接分享到微信、QQ 等指定应用，Linux 的分享面板改为复制文字和保存图片；也不能导入手机厂商与 WPS 的云端笔记。
- Linux 暂不支持录音（可以播放），应用锁只能用应用密码。电脑上没有指纹 / 面容快速解锁、锁屏时上锁和防截屏，改为可选的“闲置时上锁”。
- 局域网同步配对时，电脑只显示二维码，由手机来扫。存储管理里没有压缩图片和视频。

## 启动、关闭与更新
- 重复启动会唤起已经打开的窗口，正在编辑的内容保留。关闭窗口前会先保存日记、草稿和发布面板的改动，保存失败时提示并保留窗口。
- 有新版本时同样会提示，点 **前往下载** 在浏览器里下载新安装包（Windows 为安装程序，Linux 为压缩包），覆盖安装即可，日记数据会保留，见《更新与支持》。
