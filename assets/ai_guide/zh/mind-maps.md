思维导图就是一种日记：和普通日记在同一个列表里，同样有日期、心情、标签和日记本，也会一起备份、同步和搜索。

## 新建一张导图
- 新建日记时，正文还没写字就会在标题下面看到“思维导图”按钮，点一下这篇就变成导图，画布从按钮处展开。
- 中心主题就是这篇日记的标题；没写标题时会直接进入编辑中心主题。
- 还只有中心主题时，下方有“从模板开始”：头脑风暴、SWOT 分析、读书笔记、项目计划、一周计划、决策分析、旅行清单、年度目标，每个模板自带合适的结构和配色，已写的中心主题会保留。这时也可以点“转回文字日记”。
- 写完点右上角的“+”发布，与普通日记一样；返回会留在草稿箱。

## 编辑主题
- 点一下选中主题，再点一下（或双击）编辑文字；底部工具坞有子主题、同级主题、编辑、收起 / 展开、样式、删除。中心主题不能删除。
- 手机上编辑文字时键盘上方有子主题、同级主题、换行、完成。
- 长按主题拿起后拖动：放到另一个主题上成为它的子主题，放到两个主题之间就插在那里；长按不动会弹出菜单。电脑上直接用鼠标拖，右键打开菜单。
- 有子主题的主题选中后旁边有一个“−”小圆钮，点它收起；收起后显示被藏起的数量，点数量展开。
- 顶栏有撤销、重做；双击空白处适应屏幕，右上角的百分比可以选适应屏幕、实际大小、放大、缩小。
- 电脑快捷键：Tab 子主题、Enter 同级主题（Shift + Enter 加在前面）、F2 或空格编辑、Delete 删除、方向键在主题间移动、Ctrl + Z / Y 撤销重做、Ctrl + 0 适应屏幕、Ctrl + = / − 缩放、Ctrl + 1 实际大小、Ctrl + / 收起或展开、Esc 取消选中；滚轮平移，Ctrl + 滚轮缩放。

## 图标、标签、备注、链接与待办
- 选中主题后点工具坞的“插入”：图标（优先级、进度、旗帜、星标、表情、符号，或输入任意 emoji；同一类只能放一个，再点一次取消）、标签、备注、链接（网址或一篇日记）、待办（主题前出现可勾选的方框）。
- 有待办的子主题时，父主题后面会出现进度环；完成的待办文字变淡并划掉。
- 点主题上的备注标记查看 / 编辑备注，点链接标记打开网址或那篇日记。
- 选中主题后点“样式”可以单独改这个主题的形状、底色、文字颜色、分支颜色、粗体 / 斜体 / 删除线和字号，“恢复默认样式”一键还原。

## 大纲视图
- 左上角切换“画布 | 大纲”。大纲是同一张导图的缩进列表，点一行就能编辑：回车新起同级，空行退格删除；电脑上 Tab / Shift + Tab 缩进 / 取消缩进、Alt + ↑ / ↓ 上移下移，手机键盘上方有同样的按钮。

## 复制与粘贴
- “更多”或右键菜单里有复制、剪切、粘贴（电脑上 Ctrl + C / X / V）。复制的主题连同子主题和样式一起贴回；从别处复制的多行文字会按缩进变成主题。

## 结构与配色
工具坞的“样式”（或顶栏“更多 → 导图样式”）里可以换：
- 结构：思维导图（左右分布）、逻辑图、左向逻辑图、组织结构图、树形目录、时间线、鱼骨图。
- 配色主题：跟随应用、彩虹、海盐、森林、晚霞、樱花、墨韵（黑白）、纸本、霓虹、马卡龙，亮色和暗色都会自动适配。
- 连线：曲线、直线、直角、圆角；间距：紧凑、标准、宽松；彩虹分支（每个一级分支一种颜色）；点阵背景。

## 在普通日记里插入导图
- 在正文里输入“/”，选“思维导图”，插入一张导图并直接全屏编辑；返回后正文里是一张导图卡片，撤销一次即回到编辑前。
- 编辑时点卡片再次打开编辑，长按或右键可以编辑、全屏查看或删除；阅读时点卡片全屏查看。

## 阅读与筛选
- 列表卡片上显示导图缩略图和一级主题；预览页里是一张大图，点它全屏查看，可以平移缩放。
- 智能日记本和搜索筛选的“媒体”里有“有思维导图”，能筛出导图日记和插入了导图的日记。
- 搜索、字数、日记导出和分享文字都会带上每个主题的文字，按大纲写出。

## 用 AI 整理导图
- 打开 AI 助手并开启“写作助手”后，导图里会出现 AI 入口：
  - 还只有中心主题时，起步卡最前面是“AI 生成”：填一个主题，选层数（2–4）和风格（发散、结构化、学习笔记），可以再写点补充要求。预览里主题会边生成边长出来，满意了点“使用这张导图”；导图里已经有内容时会替换它，可以撤销。
  - 选中一个主题，工具坞或右键菜单里点“AI 展开”，AI 会参考它的位置和整张导图，给它添加 3–7 个子主题，点“添加到导图”才会加进去。
  - 没选中主题时工具坞的“AI”里还有“AI 总结导图”：可以复制、写进中心主题的备注，或另存为日记。
- 文字日记的预览页“更多”里有“AI 生成思维导图”，会生成一篇新的导图日记，原来的日记不变；导图日记的“更多”里有“AI 总结导图”。
- 生成中随时可以停止；私密日记本里的日记要在 AI 隐私里打开“允许对私密日记使用 AI”后才能用。

## 导出导图
- 编辑导图时点右上角“更多 → 导出导图”，预览页“更多”、全屏查看页顶栏也有。可以导出成图片（PNG）、PDF、XMind、Markdown、OPML、FreeMind，或复制为大纲文字。
- 每一行右边可以选分享、保存为文件，图片在手机上还能保存到相册；点整行默认分享（电脑上为保存）。
- XMind 会保留主题、图标、标签、备注、网址链接、收起状态和结构；图片按当前明暗与配色画出。

## 导入与转换
- “更多 → 从文件导入”或起步卡右上角的导入按钮：支持 XMind（新版与 XMind 8）、OPML、FreeMind（.mm）、Markdown 和纯文本大纲。导图里已经有内容时会先问是否替换，替换后可以撤销。
- 文字日记的预览页“更多”里有“转为思维导图”：按标题和列表的层级生成一篇新的导图日记，原来的日记不变。

## 开关
- 设置 → 功能管理 → 思维导图（默认开）。关闭后隐藏新建页的按钮、“/”菜单的插入导图和新建筛选里的“有思维导图”，已有的导图照常显示和编辑。
