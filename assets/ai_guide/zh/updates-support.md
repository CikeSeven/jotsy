“关于”页集中了版本更新、反馈与支持，以及隐私和开源信息。

## 在哪里
- 设置 → 关于（设置首页最后一行）。顶部显示应用版本，下面三张卡片：检查最新版本、更新日志；提交 Issue、QQ反馈群、支持开发者；开源仓库、隐私与数据安全、第三方开源组件与协议。
- 有新版本时，设置首页的“关于”和“检查最新版本”行尾会出现“新版本”标记。

## 检查与安装更新
- 点 **检查最新版本** 进入“软件更新”页：显示当前版本和检查结果，有新版本时列出“更新内容”。
- Android：点 **下载并安装**，下载会显示进度，可以取消，之后点 **继续下载** 从断点接着下；下载完成后点 **安装** 交给系统安装。第一次安装可能需要允许 Jotsy 安装应用，点 **去设置** 打开即可。安装前会核对文件校验值和应用签名，不符时会删除文件并提示。
- 电脑（Windows / Linux）：只检查不在应用内安装。点 **前往下载** 会在浏览器里下载新安装包：Windows 为安装程序，运行即可覆盖安装；Linux 为压缩包，解压后运行其中的 install.sh。日记数据会保留。
- **跳过此版本**：之后启动时不再提醒这个版本，仍可手动检查。

## 更新设置
- 软件更新页“更新内容”下方的“更新设置”：
  - **自动检查更新**（默认开）：打开或回到应用时检查，每 2 小时最多一次，只读取公开的版本信息。发现新版本时弹出提示，可选 **立即更新**（电脑上为 **前往下载**）、**跳过此版本** 或 **以后再说**。
  - **下载线路**：自动选择（国内网络推荐）、几条内置镜像、GitHub 直连，或填写自定义镜像。下载慢或失败时可以换一条线路。

## 更新日志
- 设置 → 关于 → **更新日志**：各版本从新到旧排列，本机安装的版本标着“当前版本”。每张卡片先显示版本要点，点 **展开全部** 查看完整说明。
- 更新日志随应用打包，不需要联网。只有中英文，日语、俄语界面显示英文版。

## 反馈与交流
- **提交 Issue**：在浏览器里打开项目的 GitHub Issue 页面，可以报告 Bug 或提建议。
- **QQ反馈群**：群号 678136434，点一下即复制到剪贴板。

## 支持开发者
- 点 **支持开发者** 打开打赏面板，可在 **微信** 和 **支付宝** 之间切换。支付宝可以点 **打开支付宝付款** 直接付款；微信需要先把赞赏码保存下来（手机上为 **保存到相册**，电脑上为 **另存为…**），再在微信“扫一扫”里从相册选这张图。
- Jotsy 免费开源、没有广告。打赏完全自愿，不会解锁任何功能。

## 隐私与数据安全
- Jotsy 没有账号，也没有自己的服务器。日记、标签与媒体文件只保存在本机，不会默认上传到云端。
- 只有这些情况会联网：自动获取地点和天气（只在 Android 上，也可以手动填写）、网盘备份与恢复（连你自己设置的服务器或网盘）、检查与下载更新（不含任何日记数据）、导入云端笔记（在对应厂商官网登录）、使用 AI 助手（AI 助手默认关闭，开启后只在你使用时把所需内容直接发给你自己配置的 AI 服务，密钥只存在本机）。局域网同步只在同一局域网内的设备之间传输。
- 数据只在本机，卸载应用或清除应用数据会把日记一起删掉，建议定期备份。
- **开源仓库** 打开项目的 GitHub 页面；**第三方开源组件与协议** 列出用到的开源组件许可。

## 注意
- AI 助手可以帮你打开关于、软件更新或更新日志页面，但不能替你下载安装更新或打赏。
