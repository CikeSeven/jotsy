# 桌面编辑与退出验证

适用 Windows、Linux。所有修改只使用临时测试数据；Windows 安装版与便携版共用同一用户数据目录。

- `test/core/services/desktop_exit_guard_test.dart`：等待保存、重复关闭共用任务、失败/异常取消、注销和手机行为。
- `test/ui/diaries/pages/desktop_exit_save_test.dart`：桌面平台下输入后立即关闭、只读数据库导致的失败与重试、新建草稿只保存一份。
- `test/ui/diaries/controllers/publish_diary_controller_test.dart`：发布面板最后改动的关闭补存、写入失败与重试。
- `test/ui/diaries/controllers/diary_todo_autosave_controller_test.dart`：退出补存、写入期间勾回原状态、保存失败与卸载时的串行尾写入。
- `test/ui/diaries/controllers/diary_editor_clipboard_test.dart`：双向跨段复制、格式保留、反向剪切和撤销。
- `test/ui/diaries/editor/diary_read_only_shortcuts_test.dart`：桌面阅读复制/全选、禁止修改和输入法连接、继续响应页面翻页、禁用文字选择。

## 原生窗口检查

在 1280×800 和 900×700、明暗主题下分别检查：

| 触发步骤 | 预期结果 |
| --- | --- |
| 打开已有日记，修改标题与正文后立即点窗口 ×；重新打开。 | 保留最后输入，不依赖等待自动保存的防抖时间。 |
| 新建日记，输入后立即关闭；重新打开草稿箱。 | 只有一份草稿，包含最后输入。 |
| 进入发布页，修改心情或标签后立即关闭并重开。 | 已发布日记保留最后的面板改动。 |
| 预览页或双栏阅读中勾选待办后立即关闭；重新打开。 | 保留勾选，归档、标签等状态不变。 |
| 在编辑页输入后，再启动应用；Linux 可从菜单和终端分别启动，Windows 可交替运行安装版和便携版。 | 仍只有原来的应用进程/窗口，回到当前编辑会话，不产生另一份数据库连接。 |
| 最小化应用，再次启动。 | 原窗口恢复，当前内容和窗口大小保留。 |
| 正常关闭后再次启动。 | 能正常重新运行，不残留单实例锁。 |

数据库写入失败由内存数据库的 `PRAGMA query_only` 与拒绝更新的触发器在自动测试中模拟，无需改动真实日记目录权限。

## 选区与快捷键检查

1. 在正文写两段 `alpha`、`beta`，先从第一段第 3 个字符之后选到第二段前 2 个字符，再反向选择同一范围。两次 Ctrl+C 粘贴结果都应为两行 `ha`、`be`，文字样式一致。
2. 反向选择同一范围按 Ctrl+X，再粘贴到新位置：原位置剩 `alpta`，新位置是两行 `ha`、`be`；撤销能恢复原文。
3. 在预览页和双栏阅读中拖选部分正文，按 Ctrl+C：复制所选文字；Ctrl+A 再 Ctrl+C：复制整篇正文。Ctrl+X、Ctrl+V、Delete、输入字符均不改正文，左右键仍可翻页。
4. 在预览样式中关闭“允许选择文字”：鼠标和复制快捷键均不能选取正文。手机上的长按选区行为保持原样。

系统强制结束进程、断电不经过可取消退出请求；上述关闭验证针对系统正常关闭窗口。
