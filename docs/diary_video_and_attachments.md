# 视频与附件验收

在亮色和暗色主题下各执行一次。系统文件面板及视频解码需要 Android/iOS 真机确认；组件测试使用模拟播放器和文件打开服务，不代表已在手机上完成验收。

| 操作步骤 | 预期结果 |
| --- | --- |
| 新建日记，点击正文唤起工具栏，横向滚动到“插入视频”，多选两个 MP4 文件。 | Android 拉起与图片入口相同的系统相册，仅筛选视频；导入时显示 Expressive 等待效果；每个视频独立成块，保持选择顺序；不会自动播放，光标可继续输入正文。 |
| 点击播放、暂停并拖动进度条；切换到其他页面或将应用放到后台。 | 播放状态与进度同步；被覆盖的页面或后台停止播放；无法解码的视频显示可交给其他应用打开的卡片。 |
| 在编辑器收起键盘后，点击视频播放/暂停、连续点击或拖动进度；再点击视频后的正文。 | 操作播放器不会拉起键盘；正文点击仍可唤起键盘继续编辑。 |
| 在编辑器收起键盘后，点击录音播放/暂停、连续点击或拖动波形；再重命名录音并点击后方正文。 | 播放和波形操作不会拉起键盘或改变正文选区；重命名只为弹窗输入框唤起键盘；确认后正文保持未聚焦，点击正文可继续输入。 |
| 点击“导出视频”，在确认弹窗中先取消，再次点击后确认；导出时重复点击。 | 取消不保存；确认后将视频复制到手机相册，显示等待及完成提示；不会重复弹窗或并发导出。权限拒绝、文件缺失、空间不足时显示对应提示。 |
| 播放到中途进入“全屏播放”，拖动进度并暂停，再通过返回键或“退出全屏”回到日记。 | 全屏使用同一播放器，进入/退出不重置播放进度和暂停状态；全屏导出同样需要确认；后台仍会暂停。 |
| 点击“插入附件”，选择带中文、空格的 PDF、DOCX、ZIP；再导入一个同名文件。 | 显示原文件名、类型和大小；同名文件分别保存，不互相覆盖。 |
| 在编辑页、发布预览页及保存后的阅读页点击附件。 | Android 交给系统 ACTION_VIEW 文件处理器，iOS 显示系统文档交互面板；安装了对应应用时可以打开；连续点击不会重复拉起。 |
| 取消文件选择，或在复制期间返回退出编辑器。 | 正文保持原样；取消的操作不会留下已提交的附件；没有异常弹窗或退出后的状态更新。 |
| 删除原始导入文件，保存并重新打开日记；仅插入视频或附件、保持标题和文字为空后发布。 | 应用中的文件副本仍可访问；仅媒体日记可发布及恢复草稿；视频的空行不会随重复打开增加。 |
| 导出 ZIP 备份，在另一安装环境导入；另测带密码备份及错误密码。 | 视频、附件及草稿完整恢复，名称/大小不丢失，路径绑定到当前应用目录；错误密码不覆盖现有数据。旧版 file/attachment/video 节点可显示。 |
| 打开没有对应处理应用的附件，以及缺失或损坏的文件。 | 显示本地化提示；日记正文仍可阅读。 |
| 在“设置 → 编辑器 → 工具栏排序”移动或隐藏视频、附件入口，再回到编辑器。 | 排序与隐藏生效；已有工具栏配置自动补入新工具，用户已有顺序保留。 |
| 对含媒体的日记导出 Markdown/PDF。 | Markdown 保留带文件名的链接，PDF 保留可读文件名称；原正文不被转换或改写。 |

自动验证覆盖文件持久化、流复制失败清理、多选插入、选区变更/页面退出、草稿与正文往返、普通/加密备份、旧格式转换、资源删除、系统打开错误分类，以及两种主题下的文件卡片和视频控件。

大型视频/附件的普通 ZIP 导出直接流式写盘。带密码导出仍受当前 archive 库对单个条目加密缓冲的限制。

本次执行结果（含音频/视频播放手势、导出确认和全屏）：Dart 格式化及本地化生成完成；`flutter test --no-pub` 全量 282 项通过；`flutter analyze --no-pub --no-fatal-infos` 无错误或警告，保留 9 条已有 info；`flutter build apk --release` 成功。使用现有 release 签名通过 `adb -s 1b8418ca install -r` 覆盖安装，保留应用数据。合并后的 Android Manifest 已确认注册文件打开插件的 FileProvider，并且无需外部文件读取权限。播放器交互使用组件测试验证，实际相册导出和视频解码仍需真机按上表验收。
