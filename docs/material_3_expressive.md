# Material 3 Expressive 迁移与验收

Expressive 是 Material 3 的扩展，应用继续启用 `useMaterial3: true`。本项目采用 Flutter 原生组件的统一主题、少量公共交互组件，以及已有的 `loading_indicator_m3e`。这不是 Flutter 提供的一个“一键 Expressive”开关，也未用第三方库替换整个 Material 框架。

## 实现范围

| 层级 | 实现 |
| --- | --- |
| 色彩与排版 | 使用 `DynamicSchemeVariant.fidelity` 保留用户种子色的色相和高彩度；Expressive 应用于形状、组件与动效，不旋转种子色；保留 HarmonyOS 字体、明暗模式与字号设置 |
| 按钮 | Filled / tonal / elevated / outlined / text / icon 全局状态圆角，按压时由圆润形状收紧；保留禁用、焦点、键盘和危险操作颜色 |
| 表单与反馈 | 填充输入框、粗轨道与竖向手柄滑块、芯片、复选框、开关、提示；所有等待入口使用统一 Expressive 加载封装 |
| 容器与弹层 | 卡片、列表项、标题栏、菜单、搜索容器、Dialog、日期/时间选择器和底部弹层统一语义表面与圆角 |
| 公共交互 | 底部导航选中图标弹簧过渡、带文字的新建 FAB、支持窄屏/大字号纵排的连接按钮组 |
| 业务页面 | 日记列表/瀑布流/选中态、筛选标签、编辑工具栏、发布面板、日历/时间线、探索卡片、设置首页及二级页面、图片查看页 |

按钮形变由 `expressive_controls.dart` 管理；表面由 `expressive_surfaces.dart` 管理；新空间动效与减少动画适配由 `expressive_motion.dart` 管理。原生日期选择器、文本编辑、Quill 编辑能力及系统认证/文件选择交互保留原有行为。系统弹窗由平台控制，不承诺改成应用内视觉。

## 工具链兼容

当前验证环境为 Flutter 3.47.5 / Dart 3.13.4。最低声明调整为 Flutter 3.44 / Dart 3.12，以匹配 `flutter_quill 11.6.0`。升级前的 `flutter_quill 11.5.0` 缺少新 SDK 的 `TextInputClient.onFocusReceived`，`font_awesome_flutter 10.12.0` 继承了已变为 final 的 `IconData`，原项目测试因此无法编译。

Font Awesome 升至 11.0.0 后，业务图标声明使用 `FaIconData`；Quill 仍只接受 `IconData` 的 API 边界使用 `.data`，工具栏与设置预览保持相同图标来源。未修改本地 Flutter SDK 或缓存包来绕过兼容问题。

## 自动验证

在仓库根目录运行：

```sh
flutter pub get
flutter analyze
flutter test
flutter test --dart-define=EXPRESSIVE_PREVIEWS=true test/ui/widgets/expressive_pages_test.dart
```

最后一条命令同时验证真实设置组件，并将明暗主题 PNG 写入 `build/expressive-review/`。这些是 widget 测试渲染，不是设备截图。普通测试不会生成图片。

新增验证覆盖：按钮按压/松开与禁用，选择组点按/键盘与窄屏大字，滑块两端，导航越界/空列表/单项，加载语义与减少动画，320dp 中英文设置页、明暗主题、主题设置持久化、字号弹窗取消，以及窄屏日历操作。已有日记选择、发布面板和标签数量测试使用实际应用主题回归。

本次主题修复（2026-10-04）：移除会将蓝色种子色的主色相旋转为绿色的 `DynamicSchemeVariant.expressive`，改为能保留种子色相和彩度的 `fidelity` 变体；移除全局 `ListTileThemeData` 的背景、形状和额外内边距，保留页面原有列表密度。

图片导入修复：ZIP 内的封面和正文图片随包完整，但数据库仍可能保存导出端应用目录的绝对路径。导入现在先恢复媒体，再将可找到的托管路径重绑到当前应用目录；数据库 v7 -> v8 迁移也会修复此前已导入的数据。迁移只修改目标文件存在的托管路径，保留缺失路径、外部文件、网络 URL、data URI 和其他日记字段。本地 APK 验证显示已有日记与图片正常加载。

图片导入修复：ZIP 内的封面和正文图片以应用私有目录的相对内容保存，但数据库字段可能包含导出端应用目录的绝对路径。导入现在先恢复媒体、再把可找到的托管图片路径重绑到当前应用目录；schema v7 -> v8 另会修复已导入且文件仍存在的旧路径。外部文件、缺失图片、网络 URL 和 data URI 保持原值。手机预览版已验证升级现有数据库后，日记卡片图片恢复显示。

全量迁移初次执行结果（2026-09-28）：

- `dart format`：全部修改的 Dart 文件已格式化。
- `flutter build bundle --debug --no-pub`：通过，应用入口及页面可编译。
- `flutter analyze --no-pub`：0 error、1 warning、10 info。warning 为原有 `webdav_client.dart` 的 `unawaited_return_in_try_block`；info 为 3 条旧 API 弃用及 Dart 语言版本升级后对原有构造函数产生的 7 条初始化风格提示。未将分析结果描述为全部通过。

## 可复现人工验收清单

以下步骤在亮色、暗色各执行一次，另选一种种子色复查文字和图标对比度。

1. 冷启动，切换四个底部标签，返回日记；预期形变加载可见、选中胶囊与图标同步，新建 FAB 在日记/日历可用，提示出现时仍会避让。
2. 切换日记列表/瀑布流，筛选标签，长按选中后归档并撤销；预期圆角表面、选中边框清晰，列表状态和撤销行为正常。
3. 新建日记，编辑标题/正文，使用加粗、图片与列表工具，展开发布面板；预期图标一致，定位/天气等待显示形变动画，标签、心情、精力和时间锁可用，保存期间不可重复发布。
4. 打开日历，前后切月、选择日期、跳回今天；预期窄屏英文月份不压住页标题，选中日期和当天文字可读，时间线可打开日记。
5. 打开探索、媒体与图片查看页；预期卡片和标题统一，明暗主题工具按钮可见，加载失败仍有重试/占位。
6. 设置 → 外观与语言，切换系统/亮/暗，换主题色、字号和语言；预期设置持久化，320dp/大字号下连接按钮组自动纵排，字号弹窗取消不会保存。
7. 设置 → 数据与隐私，打开 WebDAV、回收站等二级页和确认弹窗；预期输入框聚焦边框、禁用态和错误态可辨识，取消为灰色，危险确认保留错误色。
8. 启用系统减少动画，重启并切换导航/选择组；预期新增动效停用或即时结束，等待状态仍有静态图形与读屏标签。

本次在 Android 16 设备完成预览包安装与启动验收：核对已有日记列表、封面和正文图片均可显示，并未清除或重置测试版数据。
