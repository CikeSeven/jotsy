# 性能优化记录（2026-10-17）

本轮针对大日记库的查询、探索统计和长期使用后的正文驻留进行优化。页面布局、
配色、字体、图片质量、动效参数和手势保持原有实现。

## 可复现基准

在同一台 Linux 主机、仓库固定的 Flutter SDK、内存 SQLite 和 Flutter 测试 VM
中比较。基线为 `1fe6686`；固定生成 10,000 篇日记，每篇 100 行中英混排正文、
3 个标签，包含置顶、归档和删除记录。探索查询实际返回 9,656 篇。
每项预热一次，再取 7 次的耗时中位数；分页改变 offset，避免重复命中同一个流结果。

```sh
flutter test --no-pub test/performance/diary_performance_test.dart \
  --dart-define=PERFORMANCE_BENCHMARK=true --reporter expanded
```

不稳定的墙钟耗时设置 CI 门槛。

## 实现与取舍

- **分页查询**：先筛选、排序并截取日记 id，再读正文与聚合标签，避免对全库
  先做大字段 JOIN/GROUP BY。空关键词不再引用正文列。六种排序、置顶优先、
  标签 AND 语义、分页边界和未解封胶囊的搜索限制保持一致。
- **排序索引**：schema v10 为未删除、未归档日记增加更新时间、发表时间两项
  复合索引，覆盖置顶、时间和唯一 id。只新增索引；不重写 v9 的数据。使用
  两项常用排序索引，控制索引存储与保存时的额外写入成本。
- **探索统计**：先用时间戳排除趋势窗口外的记录，只为相关日记解析一次
  metadata；心情和精力共用扫描与评分表，每天只保留和、数量。连续天数用
  日期整数键，避免为整库构造本地零点；保留原有日期与夏令时匹配口径。
  标签按每个标签一个计数器聚合，最后生成展示模型，减少短命对象分配。
- **字数算法**：共用标点延迟到下一实体字符时统一结算，消除重复向后扫描的
  O(n²) 路径；直接遍历 runes，不再复制全文 rune 列表。字数口径保持一致。
- **查询生命周期**：日历的月、年、日、“那年今日”、正文首图和归档/回收站
  查询复用闲置保活策略；最后一个活跃监听离开后保留 30 秒，恢复监听取消
  计时，当前页面的查询持续保留。避免已访问日期与整份正文永久留在 provider。
- **正文缓存**：卡片派生数据除 600 条上限外，增加 4,194,304 个 UTF-16
  码元的原始文本预算，按 LRU 回收。超预算单篇正常展示但不长期缓存；预算
  不等同于实际堆内存上限，派生对象、活动页面和解码图片另占内存。瀑布流
  签名改用列表弱引用，避免签名缓存延长整份列表的生命周期。

启动沿用已有的首屏查询预热与延迟加载；编辑器沿用正文 widget 缓存、自动保存
防抖和光标跟随；图片沿用保持比例的有界解码、长图分片和可见范围加载；导入、
备份与导出沿用后台 isolate 和流式媒体处理。本轮保留这些已有优化。

- `dart format --output=none --set-exit-if-changed lib test integration_test tool`
  通过；`flutter analyze --no-pub` 零问题；ARB 检查通过。

  后，11 个受跟踪生成文件的内容哈希均不变。
- `flutter build apk --release --target-platform android-arm64` 成功，验证 AOT、
  图标裁剪与 Android release 编译链路。全量测试的非生成代码行覆盖率为 83.4%。
- 新增分页与实际执行计划验证、v9 升级与重开数据保留验证；补查 v1/v6 的索引升级。
- 新增闲置释放、恢复监听、活动查询不超时、容器销毁取消计时器的验证。
- 新增趋势日期窗口、独立均值、损坏 metadata、自定义心情兼容、标签统计与超长
  正文缓存边界的验证。
- 另与基线实现比较 15,261 组 Unicode 输入和 40 组探索展示数据，全部字段一致；
  对照运行使用 `America/New_York` 时区，覆盖夏令时、闰日和 UTC 输入。
- 另在独立内存数据库中对照基线 SQL 的 216 组排序、筛选与分页窗口，日记全部
  字段及标签顺序一致，包含无标签、空白标题、通配符搜索与空窗口。

复查现有交互时，在明暗主题分别执行：

1. 日记列表滚动、切换瀑布流、切换六种排序，组合标签与关键词后打开预览；
   预期卡片外观与顺序规则一致，翻页不重复、不丢标签，返回位置正常。
2. 日历连续选日、翻月、切换年视图和照片样式，再访问归档与回收站；离开超过
   30 秒后返回。预期仍按原有方式加载，统计、缩略图、恢复与撤销正确。
3. 阅读与编辑超长正文、包含长图的日记并返回列表。预期正文完整，摘要长度、
   图片比例与位置不变，自动保存、键盘光标跟随和预览左右翻页正常。

本次未连接 Android 设备，尚未采集真机 profile 的启动耗时、滚动帧时间或峰值
RSS。进一步调整渲染和预加载策略应依据同一设备、同一数据集的实际采样。
