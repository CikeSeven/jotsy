# 2026-11 性能优化与真机验证

本轮在 `origin/main` 的 `e1cd6c7` 上实施，覆盖编辑器、探索、查询保活、背景图、
备份和 AI 对话。保留现有视觉与数据口径，没有数据库 schema、依赖或 ARB 改动。
实现与验证在独立工作树中完成。

## 已实施

| 路径 | 改动与边界 |
| --- | --- |
| 工具面板 | 祖先布局更新上限时，展开及收起动画中的面板在当前帧刷新；同时约束 AnimatedSize 自身。上限不足以容纳外框时不占面板高度。完全收起时跳过高度通知，不增加键盘逐帧重建。 |
| 保存快照 | 当前正文版本只构造一次 JSON 树，同时生成 JSON 与纯文本，只缓存这两个字符串。同步事务 after 事件在通知保存监听者前失效，覆盖原生输入、格式、撤销/重做、拖动、恢复。标题、选区和 metadata 改动复用正文快照。 |
| 探索 | 256 篇起或正文/metadata 合计达到 64 Ki UTF-16 码元时，经 `ExploreComputationController` 把条目索引与整页聚合一起交给 worker。小样本及设置预览保持同步。一次最多一个 worker，只排队最新输入，旧结果不覆盖新条件；输入变化立即撤下旧结果，避免继续显示已删除/转私密的条目。逐篇缓存随结果返回，后续变化继续复用。 |
| 查询保活 | 保留闲置 30 秒策略；一个 ProviderContainer 最多保留 12 个闲置查询，分页/搜索窗口另按正文、纯文本、metadata、标题与标签估算 32 MiB 合计预算。按最近闲置顺序淘汰，活动查询不登记、不被预算释放。其他未提供大小估计的查询受项数约束；这不是进程总内存上限。 |
| 背景图 | 除 3 项 LRU 外，增加 32 MiB RGBA 像素预算。超大单图照常交给活动页面，只放弃长期缓存，不缩小原有画质。内存压力清理缓存自己的句柄，活动 clone 保持有效；压力之前发起的加载不能回填缓存。 |
| 备份 | 完整备份和日记包的 JSON、UTF-8 编码与落盘移到 worker；编码器分块同步写文件，避免 UI 构造整份 JSON 字符串，或 IOSink 排队全部输出。事务快照、格式、媒体处理与失败清理口径保持。 |
| AI | 16 ms 合并流式增量通知，完成/失败/重置立即通知，末尾内容不丢。字符串按增量失效，重复读取不重建整段文本；对话历史改惰性 item builder，按消息 id 维护位置与操作。 |

## 真机合成负载

设备：USB 连接的 `2211133C`（fuxi），Android 16，1080×2400，系统当前 120 Hz；Flutter
3.47.5 / Dart 3.13.7，arm64 profile，Impeller Vulkan。USB 供电，不作为电耗试验。

`tool/profile_hotpaths.dart` 是独立的 Flutter 构建入口：只创建内存合成数据，不
打开应用数据库、设置、媒体或网络。reference 在同一个 AOT 包中重放改动前
的同步路径，与当前生产入口比较，避开不同构建/数据集的混淆。

- 探索：10,000 篇，每篇 1,700 个 UTF-16 码元，含 metadata，默认可见卡片。
- 快照：10,000 个短段落，JSON 1,500,041、纯文本 969,998 个 UTF-16 码元。
- 每组 5 次；下表取中位数。心跳为 5 ms 周期计时器，记录每个测量窗口里最大
  间隔，再对 5 次取中位数；间隔包含计时器自身的周期及调度波动，不等同于帧耗时。

| 指标 | 同步参考路径 | 当前路径 |
| --- | ---: | ---: |
| 探索计算总耗时 | 221.670 ms | 235.585 ms |
| 探索期间最大心跳间隔，中位数 | 226.594 ms | 9.484 ms |
| 探索期间最大心跳间隔，最坏样本 | 235.334 ms | 11.782 ms |
| 正文未变时再次读取完整快照 | 37.353 ms | 0.037 ms |
| 快照期间最大心跳间隔，中位数 | 42.177 ms | 5.870 ms |

探索的收益是减少 UI 连续阻塞，总计算耗时因 isolate 搬运略增。快照首次构造
仍需同步工作：本机本轮单个冷样本为 **29.955 ms**，不声称每次编辑后的第一次
保存已经低于帧预算。后续可再分解树快照与编码，保持后台/退出补存的一致性。

## 正常应用入口的前后复测

另对基线和优化后的正常入口 profile 包，各采集首页滚动、探索滚动和模板编辑器
键盘升降 3 轮，保留手机原有玻璃与背景设置。两侧共 **4,703 个 UI Frame**。

下表是每轮 p95 的中位数，单位 ms。UI 来自 VM Timeline 的 `Frame`，光栅阶段
来自 `Rasterizer::DrawToSurfaces`；不是以屏幕录像估算的 FPS，也不直接等同于
完整的 FrameTiming 光栅指标。每轮完整样本量、p50/p95/p99 和长尾均保留在附件。

| 场景 | UI 基线 → 优化 | 光栅基线 → 优化 | UI 样本数：基线 / 优化 |
| --- | ---: | ---: | ---: |
| 首页滚动 | 5.821 → 5.045 | 8.955 → 9.269 | 645 / 647 |
| 探索滚动 | 1.893 → 1.886 | 6.785 → 6.852 | 802 / 804 |
| 键盘升降 | 5.353 → 4.125 | 5.238 → 5.240 | 903 / 902 |

这组普通规模数据的差异含温度、GC、输入法与系统负载波动，**不据此承诺滚动
或 GPU 加速比例**；尤其首页光栅 p95 没有改善，部分长尾仍超过 120 Hz 预算。
本轮可复现的主要收益来自上面的长文复用和大库后台计算。已留存 meminfo 快照，
但没有把一次 PSS/RSS 差异当作内存降幅，也没有测连续 100 张图片或长时电量。

## 验证结果

- `dart format --output=none --set-exit-if-changed lib test integration_test tool`。
- `flutter analyze --no-pub`：零问题；`dart run tool/check_arb.dart` 通过。
- 全量 `flutter test --no-pub --concurrency=6`：**5,997 通过，3 项可选基准跳过**。
- Android arm64 profile 与 release、Linux release 构建通过。
- 新增/扩展回归覆盖：缩窗首帧及收起动画、收起时不重建；快照原生事务、撤销/
  重做与恢复；worker 本地化日期、损坏 metadata、最新请求、失败和销毁；闲置
  预算与活跃查询保护；超大背景与压力期间加载；备份 UTF-8 结果等价及文件失败；
  AI burst 合并、末块、重置与取消。

构建验证串行执行。Flutter 3.47.5 在测试/profile 与 release 间会重新生成平台
插件注册文件；切换构建模式使用默认 pub 流程刷新工具文件，避免残留 dev-only
插件引用。本轮曾遇到此类构建干扰，刷新后 release 构建通过，未改签名或 Gradle。

所有 APK 安装均先检查正式证书一致，使用指定设备的 `adb install -r`；未卸载、
清空应用或导入合成库。本地包未注入正式发布用的网盘 OAuth 应用密钥，所以
调试完成后恢复设备原正式包；优化代码与签名 APK 留作评审/后续正式发布。
USB 保持唤醒设置在结束时恢复原值。

## 复现命令与后续范围

```sh
flutter test --no-pub
flutter analyze --no-pub
flutter build linux --release
flutter build apk --release --target-platform android-arm64 --build-number 2025
flutter build apk --profile --target-platform android-arm64 --build-number 2025 \
  --target tool/profile_hotpaths.dart
```

最后一条是专用合成入口，安装后会自动输出 `PERF_DEVICE` 与
`PERF_DEVICE_DONE`；结束后恢复正常入口包。构建号应按目标设备现有版本选择，
同签名覆盖安装；缺失或不匹配则停止，不得以卸载/清数据绕过。

本轮没有改 SQL/分页模型、媒体回收协议、同步收敛或字体覆盖。后续优先依据大库
真实驻留与 GPU trace 评估轻量列表投影、导出像素峰值、维护任务调度和无变化
同步扫描；这些结构性改动需要独立的数据一致性与低内存设备验收。

原始数据位于本轮交付目录 `jotsy-performance-optimization-2026-11-07/evidence/`：
`device-hotpaths.log`、`device-hotpaths-summary.json`、各场景的 timeline/summary、
`full-tests-final.log`、`analyze.log`、各平台构建日志与 meminfo；外置采集脚本也随
目录保留。截图仅用于本地 UI 验证，不作为公开性能报告的内容。
