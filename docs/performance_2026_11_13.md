# 2026-11-13 探索首屏与图片滚动优化

本轮基于 `origin/main` 的 `63c25384`，在独立工作树中优化探索页挂载、统计查询
与共用图片解码链路。此前的后台聚合等优化见
[2026-11 性能记录](performance_2026_11.md)；其中的真机数据属于此前测试，不能
作为本轮的前后对照。

## 改动与原因

| 路径 | 原有开销 | 当前行为 |
| --- | --- | --- |
| 探索首屏 | 一个 `SliverToBoxAdapter` 包含整列卡片，进入时同时挂载全部图表、附加数据订阅与图片 | 单列和对齐行使用惰性 `SliverList`，错落布局使用 `SliverMasonryGrid`；按视口及缓存范围挂载，已访问行保留状态。设置页预览继续使用原有盒布局。 |
| 探索滚动 | 排布整体是一个大盒子 | 每行有独立重绘边界；sliver 布局子树只按列宽更新，滚动偏移变化复用原有代理。 |
| 探索查询 | 标签 JOIN 后按日记分组，再对包含完整纯文本的行排序 | 标签按日记在相关子查询内聚合，主查询可沿更新时间索引读取，减少临时排序开销；私密、归档与胶囊过滤口径保留。 |
| 探索统计 | 改外观、顺序或卡片宽度也让整个聚合缓存失效 | 缓存仅比较可见卡片的统计选项及数据输入；统计范围、显隐或数据变化仍重算。 |
| 回忆摘要 | `maxLines` 只限制显示，摘要仍把整篇纯文本交给排版 | 先取最多 512 个字素再单行化，只排版可见摘要，保留组合 emoji。 |
| 照片统计 | 在 UI isolate 解析全库带图日记正文 | 照片数在 worker 计算；最近图片正文超过 64 Ki UTF-16 码元时也在 worker 解析，达到显示数量立即停止处理后续日记。 |
| 快速滚动 | `LongImageCoverAlignment` 直接解析图片流，绕过 `Image` 自带的滚动解码延后机制 | 两个监听都遵循 `ScrollAwareImageProvider`；高速滚动暂停未开始的解码，缓存命中立即显示，离屏销毁后不再启动排队加载。 |
| 图片尺寸 | 行尾小图按猜测的两倍宽解码，正文小图先额外读取文件头 | 使用编码头回调计算刚好铺满容器的最小等比尺寸；正文小图省去额外头部读取。普通竖图在行尾方格中的解码像素可减少到原来的四分之一，横图按实际比例保证裁切清晰度。 |

cover 解码同时限制边长为 8192、总像素约为 4 Mi；小图不放大。此预算约束单幅
封面/缩略图的解码目标，不代表进程总内存上限。原图、正文普通图片与看图页
继续使用原有解码/长图分片策略；未解封胶囊保留极低清封面。

## 验证与复现

测试覆盖：单列、对齐双列及错落网格的明暗主题懒挂载和滚回后的状态保留；
外观复用与统计选项失效；后台媒体去重、旧正文和损坏正文；横图、竖图、长图、
小图不放大、像素预算、同键单次解码、快速滚动延后与离屏取消；概览标签聚合、
同时间排序、归档与私密范围。

```sh
dart format --output=none --set-exit-if-changed lib test integration_test tool
flutter analyze --no-pub
flutter test --no-pub
flutter test --no-pub test/performance/diary_performance_test.dart \
  --dart-define=PERFORMANCE_BENCHMARK=true --reporter expanded
flutter build linux --release
```

同一开发机、Flutter 3.47.5 / Dart 3.13.7、内存 SQLite、10,000 篇合成日记，
概览查询（包含映射与断言）的七次热运行中位数为 **28.441 → 25.529 ms**。
该结果受 JIT、系统负载和缓存影响，只用于同环境对比，不等于 Android 首屏
时间，也不能推出帧率改善比例。聚合算法本身沿用原有 worker，不将其测量波动
计作本轮收益。

本轮初次优化验证时未连接 Android 设备；随后按装机请求完成 M098FE 的
release 覆盖安装及启动检查，但尚未进行低端机 profile、连续滚动驻留内存或
帧时间分位数测量。

## UI 检查清单

| 触发步骤 | 预期 |
| --- | --- |
| 手机明暗主题分别打开含大量日记的探索页，慢查询期间尝试切换 Tab | 顶栏与切页仍可响应；等待超过 300ms 才出现加载反馈，统计完成后显示内容。 |
| 快速滚动探索页到底，再回到顶部；随机回顾换一篇后重复 | 下方卡片按需出现，已访问卡片的随机结果、轮播位置保留，图片缓存命中不重复淡入。 |
| 反复切换周/月/年/全部，再修改卡片外观、宽度与顺序 | 最终统计对应最新范围；外观调整不清空或重新扫描已有统计。 |
| 启用“照片数”和“包括正文里的图片”，使用大篇幅/旧格式/损坏正文 | 后台解析不中断切页，封面和正文图去重一致，损坏正文保留有效封面。 |
| 在首页列表、日历、探索媒体画廊与正文三图一排之间快速滚动 | 高速滚动优先保持帧响应，减速后加载新图；横竖图保持比例，长图露出顶部，小图不抖动布局。 |
| 图片缺失、删除日记或把日记加入私密本后返回探索 | 失败占位正常，已删除/私密条目不会沿用旧统计结果继续显示。 |
| 桌面 1280×800、900×700 和带小数的窗口宽度，切换对齐/错落与列数 | 内容按实际可用宽度排布，居中与间距保留，无 overflow。 |
