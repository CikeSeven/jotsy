# 滚动渲染优化（2026-11-14）

基于 `7d4c586a`（PR #254）。接续 `scroll-perf` 工作树中未提交的实现，补齐
缓存边界、资源释放和回归验证。范围为首页滚动、玻璃背景、预览翻页及隐藏的
加载指示器，数据库和持久化格式不变。

## 渲染与构建

- **内容玻璃**：背景已落定时，复用预模糊位图；每张卡片的 Follower 在合成
  阶段对齐背景，滚动不再逐帧回读并模糊相同的静态图片。背景尺寸变化通知
  画笔重绘，卡片自身高度未变也会更新 cover 取景。遮罩烘进同一位图，淡入时
  只应用一次透明度。
- **画面一致性**：背景正在交叉淡入、首页各区域背景不同、预览页按基调染色
  遮罩时保留实时模糊。顶栏、底栏、菜单与浮层仍模糊实际滚动内容。纯色与无
  背景沿用原有显示逻辑，高对比度继续关闭模糊。
- **缓存预算**：预模糊输出保持比例缩小，单项约 4 MiB，最近四项复用；源图
  句柄与输出合计按 32 MiB 估算预算淘汰，至少保留正在使用的一项。淘汰仅释放
  缓存自己的句柄，不释放背景层持有的图。渐变顶栏复用最近八个透明度着色器。
- **日记卡片**：分页重发等值数据时复用原子树；日记、标签、选择、样式、
  高亮或继承数据变化时失效。回调在触发时读取最新 widget，跨天或胶囊解封后
  再次构建时也会刷新外观。
- **预览翻页**：复用输入未变的页面；滑动中尚未露出的缓存页延后到停下时
  构建，若提前进入可见范围立即构建。停下后预构建仍可能占用较长一帧，
  只是避开了翻页动画；这项优化不等于消除了编辑器首次布局的成本。
- **快速滚动条**：普通滚动只更新按钮、气泡与命中区域的位置；刻度与轨道
  复用，按住拖动时才更新需要为气泡让位的标签。
- **隐藏等待**：遮罩淡出完成后卸下第三方指示器，取消不受 TickerMode 控制
  的形变定时器；重新显示时恢复。减少动画时显示静态 Expressive 图形与读屏
  标签，不保留形变定时器。首页悬浮底栏与新建按钮共用背景读取。

## 验证口径

自动回归覆盖等值卡片复用及最新回调、选择与语言更新、缓存页延后构建与
提前可见、监听取消、图像克隆复用与淘汰、超大窗口的位图预算、移动后的
取样像素、背景淡入与区域差异、窗口尺寸变化及隐藏等待不再请求新帧。

设备采样使用小米 13（`2211133C`，120 Hz），沿用此前导入的 500 篇测试日记
与图片、现有玻璃和图片背景。Flutter profile 的帧事件按 8.333 ms 判断 UI 或
raster 超时；该比例不能直接视为实际呈现掉帧率，也不能外推为低端机结果。
不同轮次受温度、缓存、数据位置及系统调度影响。

原工作树中途采样（`base` → `s3`）记录：首页冷滚动超时帧 3.5% → 1.6%，
日历 17.8% → 13.9%，探索 16.5% → 13.3%，预览翻页 9.8% → 6.2%。这些数值
来自上一轮尚未收尾的包，不能作为最终包的新测量。原始数据在本机
`/tmp/jotsy-scroll-perf-review/previous-measurements.json` 留档。

最终 profile 包（已清除临时性能开关）同机复测：

| 场景 | 采样帧数 | 基线超时帧 | 最终超时帧 | 最终 UI / raster 超时帧数 |
| --- | ---: | ---: | ---: | ---: |
| 首页冷滚动 | 1649 | 3.5% | 1.8% | 22 / 8 |
| 首页往返滚动 | 1315 | 5.5% | 3.8% | 3 / 47 |
| 日历 | 522 | 17.8% | 13.2% | 0 / 69 |
| 探索 | 737 | 16.5% | 13.7% | 0 / 101 |
| 预览翻页 | 819 | 9.8% | 6.7% | 14 / 43 |

日历与探索的 UI 线程没有超预算帧，剩余主要为 raster/GPU 一侧；预览仍有
停下后的相邻编辑器首次布局。当前结果没有达到全程零掉帧，进一步调整动态
玻璃需要单独的 GPU 时间线与视觉回归，不能通过隐藏原有材质来宣称解决。
最终帧事件、CPU 采样与截图保留于同一验收目录的 `probe/` 与
`final-measurements.json`。

返回首页静置 5 秒的单独采样没有新的 Flutter 帧（`out_final-idle.txt`），
确认隐藏指示器没有继续用定时器唤醒页面。

SurfaceFlinger 的最终补充采样（每场景三次滑动）记录：首页 375 个呈现间隔
未漏 vsync，日历 171 个间隔漏 7 次（4.1%），探索 190 个间隔漏 5 次
（2.6%）。它与 Flutter 超时帧比例的统计对象不同，且样本较小，分别留档。

最终 `dart format`、`flutter analyze` 通过；完整测试 6808 项通过、3 项按配置
跳过。Linux release、Android arm64 profile 与 release 构建通过。签名核对后
使用 `install -r` 覆盖安装，设备测试结束装回 release，USB 保持唤醒设置恢复
原值。两处已有测试同步改为检查预模糊取样和静态等待的行为，完整测试重跑
通过。

## UI 复现检查

| 操作 | 预期 |
| --- | --- |
| 明暗主题分别启用图片背景与玻璃，连续滚动列表、日历和探索 | 图片、文字、卡片圆角正常，玻璃取景与背景对齐，滑入新内容不闪白。 |
| 快速滚动后进入多选，再退出；切换标签和语言 | 选择及时更新、操作作用于当前日记，标签、文案和样式不会停在缓存旧值。 |
| 连续翻页并在动画结束前反向翻回，停下后返回列表 | 可见页完整，页码与相邻标题正确，返回目标及阅读位置正常。 |
| 各首页区域设不同背景并横向切页；换图、开关预览页遮罩染色 | 背景平滑混合，卡片不提前显出新图或错误区域，不重复叠遮罩。 |
| 桌面只改变窗口高度，再改变宽度 | 静态背景模糊同步更新 cover 取景，不拉伸、不残留旧尺寸。 |
| 等待动作结束、切走带等待状态的页、开启减少动画 | 淡出完整，隐藏页不持续出帧；减少动画时仍有可读的等待图形和标签。 |
| 按住快速滚动条跨越分段，松开，再用鼠标悬停 | 气泡、刻度让位、跳转及显隐保持原有交互。 |

## 复现命令

```sh
flutter pub get
dart format --set-exit-if-changed lib test integration_test tool
flutter analyze
flutter test --reporter expanded
flutter build linux --release
flutter build apk --profile --split-per-abi --target-platform android-arm64 \
  --build-number 27
flutter build apk --release --split-per-abi --target-platform android-arm64 \
  --build-number 27
```

构建号需按设备已有版本和打包方式选择：Flutter 的 ABI 拆包会给 arm64 APK
版本码加 2000，本例构建号 27 对应设备版本码 2027，不能把 2027 再作为
`--build-number` 传入。安装前检查证书相同，只使用指定设备的
`adb install -r`，不卸载或清除数据。构建、静态检查、完整测试与设备采样日志
保留在本机 `/tmp/jotsy-scroll-perf-review/`。
