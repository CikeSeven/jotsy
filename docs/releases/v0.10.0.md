# Release v0.10.0

[English](./v0.10.0.en.md) | 简体中文

## 版本要点
- 局域网同步：同一 Wi-Fi 下的手机和电脑配对后，双向合并全部日记与数据，不经过服务器，也不用注册账号；两边都改过的日记，两份都会保留。
- 正文格式大扩充：新增标题面板（H1–H6）、对齐、字号、上标 / 下标、提示块、折叠块和表格；粘贴 Markdown 文字时自动转成对应格式。
- 日记链接：输入 `@` 就能链接到另一篇日记或另一本日记本，也能插入显示实时内容的日记卡片；被提到的日记会列出“提到这篇的日记”。
- 心情色板：十种心情各有颜色，可以逐个修改；预览页配色基调新增着色强度、纸张染色等选项。
- 关于页新增更新日志，离线也能查看历次更新。

## 新增
### 局域网同步
- 入口：设置 → 数据与隐私 → 局域网同步。支持 Android、Windows 与 Linux，iOS 暂不支持。
- 配对：在“附近的设备”里找到对方并点“配对”，两台设备显示同一组核对码，双方都确认后完成配对；也可以让一台设备显示二维码，用 Android 手机的「扫码连接」扫描（二维码 2 分钟有效，扫过即失效）。本机开了应用锁或有上锁的日记本时，确认配对前会先验证身份。
- 同步的内容：日记（含回收站里的）、标签、日记本（含收录、书序与上下级）、留言、模板（含改过的内置模板）、纪念日、这天的心情，以及图片、视频等媒体文件。标签顺序和日记本、纪念日、日记模板、时间胶囊、留言这几项功能的开启状态始终同步；功能开关只同步“开启”，对方关掉某项不会关掉本机的。其他设置要两台都打开“同步设置”才同步。
- 不同步的内容：草稿、导入的字体文件、心情符号与心情颜色、网盘备份的登录信息、应用锁开关，以及只属于本机的偏好。
- 合并方式：每篇日记的正文、标签、日记本、归档、回收站、置顶分开判断哪一边是新的，只有两边改了同一处才算冲突。正文冲突时另存一份副本，两边写的都留着。删除只会同步到对方没再改过的日记。一次删除很多篇时会先问你，默认保留这些日记；首次同步或恢复备份后两边对不上时，会请你选择以哪边为准，默认两份都保留。
- 自动同步：打开后，应用在前台时会自动与已配对的设备同步。遇到需要你确认的情况会停下、不写入任何数据，等你去同步页确认。
- 同步页显示进度与完成摘要，设备详情页有同步记录。开着 VPN 或代理也能发现和连接；仍然找不到对方时，可以看“找不到设备？”里的排查说明，或直接输入对方的地址。
- 隐私：数据只在两台设备之间直接传输，全程加密。没有配对设备时，只在打开同步页期间联网；配对之后也只在应用打开时联网，退到后台即停止。关闭“可被发现”后，附近的设备就看不到本机。

### 正文格式
- 标题：工具栏的标题工具改为面板，可以直接选正文或 H1–H6；`/` 菜单补上 H4–H6；导入时保留原来的标题级别。
- 对齐（新工具）：左对齐、居中、右对齐、两端对齐，两端对齐的段落照常首行缩进。
- 字号（新工具）：小、正文、大、特大四档，接着输入的字沿用当前字号。
- 上标 / 下标：光标、选字与输入法照常使用，行高不变；桌面快捷键为 Ctrl / ⌘ + `.` 与 Ctrl / ⌘ + `,`。
- 提示块：带 emoji 图标的彩色块，有 6 档底色；光标在提示块里时，可以在工具栏面板里换图标、换底色或转回正文。
- 折叠块：标题行下面挂着可以收起的内容。编辑时点标记收起或展开；在预览页点开只改变显示，不会改动日记。
- 表格：铺满宽度、各列等宽，任何宽度下都不横向滚动，不会和预览页的左右翻页抢手势。可以插入或删除行列、开关表头行，编辑器里最多 6 列；Tab 与方向键在格子之间移动。
- 粘贴 Markdown：粘贴的文字明显是 Markdown（标题、列表、引用、代码、表格等）时，自动转成对应格式；粘到代码块或表格格子里保留原文，桌面上 Ctrl / ⌘ + Shift + V 始终粘贴纯文字。
- 新工具排在工具栏后半段，一排放不下时收进“更多”，提示块、折叠块与表格也能从 `/` 菜单插入；调整过工具栏顺序的，新工具补在末尾，可以在 设置 → 编辑器设置 → 工具栏顺序 里调整。
- 导出：PDF、Word、网页、Markdown、纯文本都能写出提示块、折叠块、表格与上下标；Word 与网页另外补上字号、对齐与 H4–H6。
- 导入与模板：从其他应用导入 HTML、Markdown 时，认得上下标、折叠内容和规整的表格；日记模板里也可以使用提示块、折叠块和表格。

### 日记链接
- 在正文里输入 `@`，接着输入日记标题或日记本名称（日记本名称支持拼音），从候选里选中即可插入链接；也可以用工具栏的“链接”（桌面为 Ctrl / ⌘ + K），在「日记」「日记本」两页里挑选。
- 日记卡片 / 日记本卡片：从 `/` 菜单插入，卡片显示对方的实时标题、日期、摘要与图片，日记本显示封面与篇数；编辑时点卡片，可以打开、转为行内链接或删除。
- 点按打开：预览页里点链接直接打开；编辑时双击或 Ctrl / ⌘ + 点按打开。目标在上锁的日记本里时会先验证身份；私密日记在卡片上只显示“私密日记”，未解封的时间胶囊只显示标题与解封日期。
- 反向链接：预览页正文末尾列出“提到这篇的日记”；日记本被提到时，头部显示“被 N 篇日记提到”，点按查看全部。
- 导出与分享时只保留链接文字，卡片导出为一行标题。

### 心情色板
- 十种心情各有自己的颜色，从靛紫、蓝、青、绿一路暖到橙、珊瑚与玫红。预览页配色基调选“心情”、日记卡片颜色来源选“心情”时，每种心情都能看出区别；以前开心的几档和“跟随应用”看起来一样。
- 设置 → 编辑器设置 → 心情符号：每个心情左侧多了一个色块，点开即可换颜色；“重置”会同时恢复符号与颜色。
- 预览页样式 → 页面 → 配色：新增“着色强度”（柔和 / 原色 / 鲜明，默认柔和，与之前一致）、“纸张随基调染色”与“取不到颜色时”（跟随应用 / 中性灰）；设置页的预览可以切换示例日记的心情来查看效果。预设“心情色”改为按心情着色并给纸张染色。
- 日历年视图与探索页心情图表的配色不变。

### 更新日志
- 设置 → 关于 → 更新日志：按版本从新到旧列出历次更新，卡片显示版本要点，点“展开全部”查看完整内容。说明随应用打包，没有网络也能看。

### 其他
- 标签可以点了：预览页信息栏、日记本统计页的“常用标签”和探索页“周期回顾”里的标签，点按即搜索这个标签；从日记本统计页进入时只在这本（含子本）里搜。
- 日记本头部的子日记本改为网格（手机两列，宽窗口更多列）；子本多时只显示两行，最后一格为“还有 N 本”，点按展开全部；“新建子本”移到标题行右侧。
- 日记本管理页：有子本的本子可以收起或展开，顶栏可以一键全部收起；拖动父本时子本跟着整组移动；长按整行也能拖动排序。

## 优化
- 探索页天气卡的图标格铺满整行，右侧不再空出一块。
- 正文的下划线与删除线跟随文字颜色；以前给文字设了颜色，线条仍是默认的墨色。

## 修复
- 编辑页收起键盘后，再点光标所在的位置，键盘不弹出。
- 编辑长日记后滚回顶部点标题，正文仍然抢焦点，页面跳回正文。
- 桌面版选中正文文字时立刻弹出手机样式的复制菜单，挡住文字；现在改为右键弹出，按 Esc 收起。
- 开启玻璃材质后，预览页顶栏仍是实色栏。
- 开了首行缩进时，段首的下划线、删除线和高亮会画进缩进的空白里。
- 日记本颜色选灰色时显示成青蓝色的主题色；模板颜色里的灰色也一样。
- 日记本统计页的“随机翻一篇”翻不到子本里的日记。
- 行首输入 `> ` 不能转成引用；编辑器里两端对齐不生效。

## 说明
- 本版不升级数据库，日记数据、备份文件与既有设置保持兼容。
- 局域网同步需要两台设备都升级到本版。Android 新增网络状态、Wi-Fi 组播与相机权限：相机只在扫码配对时使用，没有摄像头的设备照常安装。隐私政策已同步更新。
- 配对关系和同步状态只保存在本机，不随备份导出。用备份覆盖恢复之后，与每台已配对设备的第一次同步会请你选择以哪边为准（默认两份都保留）。
- 升级后请不要降级回旧版本：旧版本打开用了表格或折叠块的日记时，会把表格拆成一段段文字、把折叠的内容挪到外面；文字不会丢，但在旧版本里编辑保存后，结构就变了。
- 心情颜色与心情符号一样是本机偏好，不随备份导出。
- Android 可直接覆盖安装升级，也可以在 设置 → 关于 → 检查最新版本 中应用内更新。
