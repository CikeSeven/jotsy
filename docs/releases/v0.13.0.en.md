# Release v0.13.0

English | [简体中文](./v0.13.0.md)

## New
- To-dos: lists, reminders, repeats and steps, linked with the calendar and your diaries (turn on in Settings → Features).
- The AI assistant can search and edit diaries, manage tags and to-dos, and change settings, with every change undoable. A built-in guide lets you ask it how any feature works.
- Redesigned AI chat: thinking levels, a history drawer and chat export.
- Storage: see what takes up space, clear caches, and delete or compress photos and videos.
- Editing a diary now uses the same layout as the preview page.
- Thumbnails sit three to a row, and the cursor can rest next to images.
- Redesigned search: multi-word queries, filters and recent searches.
- App lock can lock again after you leave, when the screen locks or when idle; Android can block screenshots.
- Untitled diaries use the first line of the body as the card title.
- Home tags: tap to switch, long-press to select several. New option to publish new diaries when going back.
- Chapters in a notebook's contents can be dragged to reorder and collapsed.

## Improvements
- Smoother keyboard opening and closing.
- Drag handles are easier to grab.
- Easier text selection on phones.
- Explore and backups no longer stutter with many diaries.

## Fixes
- HarmonyOS devices said the APK "contains no certificates".
- Weather couldn't be fetched after picking a place from "Recent places".
- In AI chat, the toast covered the input box, and scrolling up while generating snapped back to the bottom.

## Notes
- LAN sync needs both devices on this version.
- Restoring a backup from this version with an older version leaves out to-dos.
