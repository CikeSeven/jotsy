# Release v0.13.0

[English](./v0.13.0.en.md) | 简体中文

## 新增
- 待办：清单、提醒、重复、步骤，与日历和日记联动（在 设置 → 功能管理 中打开）。
- AI 助手可以直接查日记、改日记、管理标签和待办、调整设置，改动都能撤销；内置使用指南，功能怎么用可以直接问它。
- AI 对话页重做：思考强度、历史对话抽屉、导出对话。
- 存储管理：查看占用，清理缓存，删除或压缩照片和视频。
- 编辑日记时与预览页同一版式。
- 正文小图三张一排，光标可以停在图片旁边。
- 搜索页重做：多词搜索、筛选、最近搜索。
- 应用锁可以在离开后、锁屏时、闲置时重新上锁；Android 可防截屏。
- 没写标题的日记，卡片用正文第一行作标题。
- 首页标签单击切换、长按多选；可设置返回时直接发表新日记。
- 日记本目录的章节可以拖动排序和收起。

## 优化
- 键盘升降更流畅。
- 拖动排序的手柄更好按。
- 手机上选字更顺手。
- 日记多时探索页和备份不再卡顿。

## 修复
- 鸿蒙设备安装时提示“该安装包未包含任何证书”。
- 选用“用过的地点”后取不到天气。
- AI 对话页提示条挡住输入框，生成中往上翻会被拉回底部。

## 注意
- 局域网同步需要两台设备都升级到这个版本。
- 用旧版本恢复这一版的备份时，待办不会被恢复。
