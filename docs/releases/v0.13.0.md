# Release v0.13.0

[English](./v0.13.0.en.md) | 简体中文

## 版本要点
- 新增独立待办：清单、提醒通知、重复、步骤，与日历、日记互通。默认关闭，在 设置 → 功能管理 中打开。
- AI 助手能动手了：可以查日记、做统计、打开页面，也能直接新建和修改日记、整理标签与日记本、管理待办、调整常用设置，每个改动都能撤销。它还内置一份使用指南，应用的各个功能都可以直接问它。
- AI 对话页重做：可以选思考强度，历史对话放进侧边抽屉，回答分段显示，对话可以导出。
- 新增存储管理：查看空间花在哪里，一键清理，删除或压缩占地方的照片和视频。
- 编辑已有日记时，页面与预览页同一版式；正文小图三张一排，插入点可以停在图片旁边。
- 搜索页重做，支持多词搜索与筛选；应用锁可以在离开应用后、锁屏时、闲置时重新上锁，Android 可以防截屏。

## 新增
### 待办
- 打开方式：设置 → 功能管理 → 待办（默认关闭）。打开后首页多出“待办”标签页，排在日记之后。
- 视图有今天、计划、重要、全部、收集箱、已完成，另可自建清单（颜色、图标、拖动排序）。点页头的“今天 ▾”切换视图，清单显示完成进度；“今天”顶部有进度环和剩余、逾期、已完成的数量，逾期的待办可以一键“全部改到今天”。
- 在列表末尾直接输入即可新建。智能识别会从“明天下午3点 开会 #工作 !!!”里认出日期、时刻、清单与优先级，识别错的片段点一下就能去掉，也可以在待办设置里关闭。
- 每条待办可以设步骤、日期时间、多个提醒、重复（每天、每周几、每月、每年、法定工作日，也可以自定义）、优先级、清单、关联日记和备注。详情在手机上是可上拉的底部面板，宽窗口里是右侧详情栏。
- 手机上右滑完成、左滑删除；长按进入多选（电脑上按住 Ctrl / ⌘ 点按），可以批量完成、改日期、移到别的清单、设优先级或删除。勾选和删除都能撤销。
- 提醒走系统通知，在通知上可以直接“完成”或“稍后提醒”，点通知打开这条待办。
- 日历上有待办的日子显示角标，下方列出“这天的待办”，长按日期可以添加待办。
- 日记预览页的“更多”里新增“添加待办”与“转为独立待办”（把正文里的待办清单复制成独立待办，正文不变），正文之后显示“相关待办”。日记正文里原有的待办块照旧。
- 完整备份、恢复、合并导入与局域网同步都会带上待办。

### AI 助手：能查、能改、能带路
- 在 设置 → AI 助手 → 对话与操作（原“对话”）里打开“让 AI 使用工具”（默认开），模型需要支持工具调用（模型设置里的“支持工具调用”）；不支持时照旧按检索日记的方式回答。
- 查：按关键词、日期、标签、心情、日记本找日记，读全文，统计篇数、字数、连续天数与常用心情标签，查看某天的农历、节假日、心情、日记、待办与纪念日。私密日记不会被读出全文，AI 隐私里排除的日记本与标签不会出现。
- 带路：回答里给出“前往”卡片，写明具体是哪篇日记、哪本日记本；你说“打开”时，回答结束后直接打开。
- 改：新建、续写、修改日记，加标签、置顶、归档、移到回收站、写留言；新建、改名、合并、删除标签，新建、改名日记本并收入或移出日记；管理待办（含提醒、重复、步骤、清单）、纪念日与这天的心情；切换主题、语言、字号与功能开关，以及编辑器、预览页、日历、待办里的 26 项常用设置。
- 每个改动都有“撤销”，一次回答里有多个改动时还有“全部撤销”。删除类的改动先在对话里确认；撤销日记改动前会检查这篇之后有没有被改过，改过会先问你。
- 设置里新增“允许 AI 改动数据”（默认开）、“每次改动前确认”（默认关）和“每次回答最多步数”（10 / 20 / 40）。
- 不会碰：私密日记、私密或上锁的日记本、回收站里的日记、未解封的时间胶囊；有编辑页开着时也不改。彻底删除、备份恢复、导入导出、分享、网盘、局域网配对、应用锁与密码、服务商密钥、存储清理和 AI 助手自己的设置，只给“前往”按钮，由你自己操作。
- 使用指南：内置 35 篇文章，覆盖应用的全部功能。问“怎么用”“在哪里”“能不能”时，AI 先查指南再回答，并给出前往对应页面的按钮。日语、俄语界面读英文版，按界面语言作答。

### AI 对话页
- 点 AI 入口直接进入新对话，原来的 AI 主页去掉了。欢迎页有快捷问题、回顾和最近的对话；只开了回顾模块时直接进回顾页。
- 历史对话在手机上是左侧抽屉，宽屏上是常驻侧栏：可以搜索、按时间分组、改名、置顶、导出、删除，点一段就在当前页切换过去。
- 输入框上方三个胶囊：范围、人设、“模型 · 思考”。思考强度分自动、关、低、中、高，每段对话各自记住，新对话沿用上一段的选择；服务商不支持时自动退回。
- 回答分段显示：思考和查询折进“思考了 N 秒 · 调用了 N 个工具”，前往、改动、确认卡片与正文始终显示。步骤详情写成“条件 / 结果”，不再显示 JSON。
- 回答、思考过程和你的问题都可以长按选字。
- 从卡片去了日记本或首页其他页面后，按返回回到这段对话，停在原来翻到的位置；首页也会出现“回到对话”提示条。
- 导出对话：Markdown、纯文本或 JSON，可以带上思考与步骤，也可以只勾选部分消息；导出后可以复制、分享或保存到文件。
- “另存为日记”改为带着内容打开新建页，没改动就返回不会留下草稿。
- 回答底部的用量显示缓存命中，如“输入 N（缓存 M）· 输出 K”。

### 存储管理
- 入口：设置 → 数据与安全 → 存储管理。
- 总览页显示总占用、按类别着色的占用条和 Android 设备的剩余空间；“一键清理”删掉缓存和不再使用的文件。下面列出可以释放空间的建议：缓存、未使用的文件、回收站、可压缩的照片与视频、整理日记数据。
- 媒体页可以按类别、大文件、可压缩、仅回收站筛选，按大小或时间排序，用列表或网格查看；长按多选后批量压缩或删除。点开一项能看大图，以及它用在哪些日记、封面、留言和草稿里。
- 删除前写明影响，删除后无法恢复。压缩先选档位（照片：高清 / 均衡 / 省空间，视频：1080p / 720p / 480p），显示预计大小，过程中可以取消；压缩后没有明显变小就保留原文件，照片保留拍摄时间与位置。
- 私密日记里的媒体默认打码，要看时上锁的先验证；未解封的时间胶囊始终打码。
- 压缩只在 Android 上提供。

### 阅读式编辑
- 编辑已有日记的页面改为与预览页同一版式：主题与纸色、头图、标题样式、信息栏、边距与正文宽度都和预览页一致，标题和正文就地修改。适用于“打开日记时直接编辑”、预览页的“编辑”与双击正文，以及宽窗口右栏的“编辑”；新建日记不变。
- 打开时不弹键盘，点正文在点按处落下光标；编辑中顶栏显示“完成”。
- 点信息栏打开信息面板，改心情时页面颜色即时跟着变。“更多”里有编辑信息、分享、导出、写留言、AI 回应、设为纪念日、另存为模板、页面样式、这天的照片、AI 写作、编辑器设置与删除。
- 页尾和预览页一样，有最后编辑时间、提到这篇的日记、留言与 AI 回应。

### 小图三张一排、插入点停在组件旁
- 正文里连续的小图每三张排成一排，按第一张的对齐方式靠左、居中或靠右；在小图后面插入的新图也是小图。导出 PDF、Word、网页时同样三张一排。
- 图片、视频、录音、附件、分隔线、日记卡片的左右两侧都能停插入点：点组件旁边的空白，插入点停到那一侧，键盘照常弹出；接着打字或回车就在那一侧另起一行。第一行是图片时，也能在它上面写字。
- 插入点在组件右侧时按退格删掉这个组件；组件下面的空行按退格删掉空行，不再只是选中组件。

### 搜索页
- 输入框改为胶囊样式，下面一行可以横向滑动的筛选：标签、日期、心情、图片与附件、天气、地点、含归档。
- 多词搜索：用空格隔开几个词，每个词都要出现在标题、正文或留言里；结果里标出命中的词，命中在后文时摘要从命中处附近开始。
- 没输入时显示最近搜索（可以逐条删除或清空）和常用标签。
- 结果上方显示“共 N 篇”，可以按最近更新、最新发表、最早发表排序，排序会记住。
- “存为智能日记本”带上全部的词、标签与筛选。
- 电脑上按 Esc 先清空再退出，Ctrl / ⌘ + F 回到输入框。

### 应用锁：重新上锁与防截屏
- 设置 → 应用锁与密码，开着应用锁时新增：“离开应用后上锁”（立即、1 / 5 / 15 / 30 分钟、1 小时或从不，默认从不，即和以前一样只在打开应用时上锁）、“锁屏时上锁”（Android）、“闲置时上锁”（电脑，1–30 分钟没有操作）、“自动弹出验证”（默认开）。
- 新的“隐私”分组里有“防截屏”（Android）：截屏、录屏和最近任务里都只有黑屏，不开应用锁也能单独打开。
- 选图片、拍照、选文件、系统分享面板这类应用自己打开的界面不算离开；在上锁的日记本里插完图片回来，也不用再验证一次。
- 应用锁与上锁的日记本同时要验证时，只验证一次。
- 应用锁开着时，放宽保护（推迟上锁、关掉锁屏或闲置上锁、关掉防截屏）要先验证。

### 其他
- 没写标题的日记，卡片用正文第一行作标题，摘要从第二行开始；只有图片、没有文字时仍显示“无标题”。开关在 设置 → 外观 → 日记卡片样式 → 内容：“没有标题时用正文第一行作标题”（默认开），之前关掉“无标题”的仍然不显示标题行。
- 首页标签改为单击只看这一个标签，长按可以同时选多个（电脑上 Ctrl / ⌘ + 点击）。
- 设置 → 编辑器设置 → 编辑行为 新增“返回时直接发表新日记”（默认关）：写新日记时按返回直接发表，不进草稿箱；什么都没写就照常离开，带时间胶囊的仍经发布页封存。
- Android：在顶层日记本或“未收录”里按返回直接回到桌面，再打开仍在这本里；子本里仍先回到上一级。
- 日记本目录页的章节可以拖动排序，点章节名收起或展开这一章；把日记拖进收起的章节时，这一章会自动展开。

## 优化
- 拉起、收起键盘更跟手，开着玻璃材质时尤其明显：编辑已有日记时，键盘动画期间每帧耗时从 15–25ms 降到 3–8ms。
- 拖动排序的手柄统一为一种样式，整块都能按住拿起（标签管理、工具栏、卡片区块、探索页布局、AI 写作指令、日记模板、日记本管理、日记本目录），以前只有图标本身那十几像素能按到。
- 手机上正文选字更好操作：长按选字时菜单等松手后再弹出，不挡放大镜；选区把手的触控范围变大；把手拖到屏幕上下边缘时自动滚动；拖把手、复制、全选不再把收起的键盘拉起来。
- 日记很多时，探索页的统计改在后台计算，打开时不再卡顿；完整备份与日记包的写入也移出界面线程。
- AI 多轮对话按原样带上之前的问答与调用，提示缓存更容易命中，长对话更省 token。

## 修复
- 鸿蒙与部分华为设备安装从 GitHub 下载的安装包时提示“该安装包未包含任何证书”。安装包现在同时带 v1 / v2 / v3 签名，签名证书不变，可以直接覆盖升级。
- 选用“用过的地点”后经常没有坐标，“获取天气”提示没有坐标。现在取最近一篇带坐标的日记。
- 收起键盘后，从一个空行点到另一个空行，键盘弹不出来。
- AI 对话页：提示条挡住输入框；停在底部时点输入框，键盘升起后最后几条消息被挡住；生成中往上翻要很用力，总被拉回底部。
- 带着问题打开 AI 对话页时，可能在读出设置之前就发出请求，AI 隐私里排除的日记本没有被排除。
- 重新打开固定在某篇日记上的 AI 对话时，没有读出这个固定范围。
- 搜索词里的 `%`、`_` 被当成通配符。
- 电脑上缩小窗口时，编辑页展开着的工具面板溢出。

## 说明
- 本版升级数据库（v18 → v21）：新增待办的两张表，AI 对话的消息与对话各加一列（工具步骤、模型与思考强度），不改动已有的日记。
- 局域网同步加入待办，同步格式随之升级：两台设备都升级到这个版本后才能继续同步，版本不同时会提示“版本不兼容”，不会写入任何数据。
- 用旧版本恢复这一版的备份时，待办不会被恢复。
- 待办提醒需要通知权限，Android 13 及以上会在第一次设置提醒时申请。手机上由系统定时，应用没在运行也会提醒，重启手机后自动重新安排；电脑上只在应用运行期间提醒。
- 待办与 AI 助手都默认关闭，在 设置 → 功能管理 中打开。
- 思考强度按各服务商当前的写法发送，不认的服务商会自动退回不带强度的请求。
- Android 可直接覆盖安装升级，也可以在 设置 → 关于 → 检查最新版本 中应用内更新。
