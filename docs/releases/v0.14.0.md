# Release v0.14.0

[English](./v0.14.0.en.md) | 简体中文

## 新增
- 段落选择模式：点段落把手即可多选段落，批量转换格式、设置样式，整组移动、复制或删除，还能把挤在一起的多段拆开或合并成一段。
- 编辑已有日记可以改为手动保存（设置 → 编辑器 → 手动保存修改）。
- AI 助手能看日记里的图片；对话里可以发图片或拍照，并让 AI 把图片加进日记。
- AI 对话页改版：输入栏收进“＋”菜单，新增回到底部按钮，回答匀速逐字显示，代码块和表格单独排版。

## 优化
- 从输入法剪贴板粘贴多行文字时，每行成为一个段落。
- 选区菜单跟着正文滚动，不再压住工具栏面板；展开面板时被盖住的选中文字会自动顶上来。

## 修复
- Android 7–11 上在存储管理里压缩视频时闪退。
- 编辑时长按文字拖到正文顶部会卡死，现在会自动向上滚动。
- AI 助手读日记时提示找不到正文。
- AI 新对话回答完后弹出“发送到…？”确认。

## 注意
- 用旧版本恢复这一版的备份时，AI 对话里发的图片不会被恢复。
