# Release v0.2.0+4

English | [简体中文](./v0.2.0+4.md)

## Highlights
- Migrated core app surfaces from glass style to Material style.
- Improved navigation and list interactions for smoother daily use.
- Added practical customization options in Settings and Editor.
- Added in-app version check and guided download flow.

## Added
- Added theme color selection in Settings.
- Added app font scaling setting with preview and confirm-to-apply flow.
- Added editor settings subpage and editor-only options:
  - Editor font size
  - Paragraph line height
- Added tab/page transition curve selection in Settings.
- Added "Check for updates" in About:
  - Detects latest release
  - Shows release notes before download
  - Lets user decide whether to continue download
  - Falls back to mirror endpoint when direct access fails and remembers available endpoint

## Changed
- Replaced glass-like UI layers with Material color roles across major pages.
- Reworked bottom navigation to Material style with better icon/label consistency.
- Optimized diary list app bar hide/show behavior while keeping tag area interaction stable.
- Adjusted diary excerpt line limits:
  - Normal list: 2 lines
  - Masonry list: 3 lines
- Improved About page visual style to align with Material surfaces.

## Fixed
- Fixed multiple scroll jitter and layout overlap issues around top bars and tag area.
- Fixed several light/dark theme color mismatches in tags, search area, and separators.
- Fixed delayed apply issue for editor settings when returning from settings page.
- Changed app version display to dynamic runtime value instead of hardcoded text.
