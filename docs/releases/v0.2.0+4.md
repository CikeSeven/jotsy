# Release v0.2.0+4

[English](./v0.2.0+4.en.md) | 简体中文

## 版本要点
- 核心界面从毛玻璃风格迁移到 Material 风格。
- 导航与列表交互手感优化，日常使用更顺滑。
- 设置页与编辑器新增多项可配置能力。
- 新增应用内检查新版本与下载引导流程。

## 新增
- 设置页新增主题色选择。
- 新增应用字体大小设置，支持弹窗预览并在确认后应用。
- 新增编辑器设置二级页面，并增加仅编辑页生效的选项：
  - 编辑字体大小
  - 正文行距
- 设置页新增页面切换曲线选项。
- 关于页新增“检查最新版本”：
  - 检测远程最新 release
  - 下载前先展示更新内容
  - 由用户确认后再继续下载
  - 直连失败时自动回退镜像并记忆可用入口

## 调整
- 主要页面移除毛玻璃相关视觉层，统一使用 Material 语义配色。
- 底部导航改为 Material 风格，图标和文案一致性更好。
- 优化日记列表应用栏隐藏/显示逻辑，并保持标签区交互稳定。
- 调整日记摘要显示行数：
  - 普通列表：2 行
  - 瀑布流列表：3 行
- 关于页卡片与整体配色改为 Material 风格。

## 修复
- 修复顶部区域滚动过程中的多处卡顿、抖动和重叠问题。
- 修复标签区、搜索区、分割线在明暗主题下的部分配色问题。
- 修复编辑器设置修改后返回编辑页未立即生效的问题。
- 应用版本号展示改为运行时动态读取，移除写死版本文本。
