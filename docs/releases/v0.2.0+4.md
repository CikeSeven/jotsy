# Jotsy v0.2.0+4

发布时间：2026-03-17  
变更范围：`2c43dd7 (refactor(ui): 移除毛玻璃样式)` → `8e19545 (chore: 准备 0.2.0+4 发布)`

## 主要更新

- 全局视觉从毛玻璃风格迁移到 Material Design 语义配色与层级。
- 底部导航、应用栏、探索页/主页/列表等页面配色与对比度统一调整。
- 新增主题色配置与标签页切换曲线配置，并重构设置页信息架构（一级/二级页）。
- 新增编辑器设置二级页，支持正文“字体大小 / 行距”独立配置。
- 编辑页支持右上角快速进入编辑器设置，设置变更可实时生效。
- 关于页改造：
  - 版本号改为运行时自动读取；
  - 新增“检查最新版本”能力（GitHub Release 检测）；
  - 支持检测到新版本后展示更新内容并由用户确认下载。
- 更新检测链路增强：
  - 直连优先；
  - 失败自动切换镜像回退；
  - 可用镜像起点持久化，下次优先使用上次可用入口。
- 交互与性能优化：
  - 列表/预览页应用栏隐藏显示体验优化；
  - 主页手势滑动支持；
  - 列表封面解析缓存；
  - 页面切换与局部动画流畅度优化。

## 兼容与版本

- Android 版本号：`0.2.0+4`
- 现有 `v0.1.0+1` 用户可通过“关于 -> 检查最新版本”升级。
