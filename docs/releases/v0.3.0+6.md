# Release v0.3.0+6

[English](./v0.3.0+6.en.md) | 简体中文

## 版本要点
- 新增“时间胶囊”能力，可以把日记写给未来的自己。
- 未解封内容在首页时间线和日历回顾中都会保持隐藏，避免提前暴露。
- 胶囊会保留封存时的天气、心情和能量信息，让解封时刻更有上下文。

## 新增
- 写日记发布面板新增“定时锁”，支持选择未来解封日期或具体时间。
- 新增胶囊封存流程：保存时显示极简上锁动效，并将日记放入对应解封日期。
- 时间线新增锁定卡片：正文和图片保持模糊，仅显示倒计时与封存时的心情、天气、能量。
- 新增锁定详情页：未解封前可查看倒计时和元数据，可调整解封时间或删除。
- 胶囊解封后，日记详情顶部会展示过去与现在的温暖提示。

## 调整
- 时间胶囊的发布日期改为解封日期，日历中会出现在真正打开的那一天。
- 日历当天列表对未解封胶囊只展示锁定状态，不展示正文和图片。
- 未解封胶囊不参与正文搜索和媒体回顾，减少从其它入口提前看到内容的风险。
- 时间胶囊删除后支持撤销，与普通日记的删除体验保持一致。
- 优化瀑布流胶囊卡片倒计时文案与字号，窄卡片中更易读。

## 修复
- 修复时间胶囊日期选择弹层在小屏设备上可能溢出的问题，改为使用发布悬浮面板内页。
- 修复瀑布流锁定卡片倒计时在窄列中横向溢出的问题。
- 修复日历当天列表会暴露未解封胶囊正文的问题。
