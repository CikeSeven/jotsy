# Release v0.3.0+6

[English](./v0.3.0+6.en.md) | 简体中文

## 版本要点
- 新增“时间胶囊”能力，可以把日记写给未来的自己。
- 胶囊会在设定日期前保持封存，只显示倒计时和当时的心情、天气、能量。
- 解封后会展示温暖提示，把过去写下这篇日记时的状态与今天连接起来。

## 新增
- 写日记发布面板新增“定时锁”，支持选择未来解封日期或具体时间。
- 保存胶囊时新增极简上锁动效，强化封存仪式感。
- 首页时间线新增锁定卡片：正文和图片保持模糊，中央显示“xx 后解封”。
- 锁定卡片边缘会保留封存时的心情、天气和能量信息。
- 新增锁定详情页：未解封前可查看倒计时和元数据，可调整解封时间或删除。
- 时间胶囊会出现在解封日期对应的日历页面，未解封前不会显示正文和图片。
- 未解封胶囊不会通过正文搜索或媒体回顾提前暴露内容。
- 删除时间胶囊后支持撤销。
