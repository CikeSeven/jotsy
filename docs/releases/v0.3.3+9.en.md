# Release v0.3.3+9

English | [简体中文](./v0.3.3+9.md)

## Highlights
- Improved Android data export stability to prevent crashes when saving large backup files.
- Optimized backup import flow to reduce memory pressure with large ZIP archives.
- Fixed imported Time Capsule diaries losing their locked state.

## Fixed
- Fixed an Android OOM crash caused by passing the full ZIP backup through the native save channel during export.
- Android export now saves backup files through the system document picker with streamed file writes instead of sending the whole ZIP as bytes.
- Fixed backup import reading full ZIP archives into memory multiple times, reducing memory usage for large backups.
- Fixed Time Capsule diary imports not restoring `capsuleUnlockAt` and `capsuleLockedAt`.
- Imported Time Capsule diaries now keep their original unlock time and locked state.

## Changed
- Backup ZIP import now reads from file streams and writes extracted entries incrementally to the temporary restore directory.
- Existing backup format, password flow, and overwrite-import behavior are preserved.
- Added regression coverage for backup memory handling and Time Capsule field restoration.
