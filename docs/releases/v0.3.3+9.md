# Release v0.3.3+9

[English](./v0.3.3+9.en.md) | 简体中文

## 版本要点
- 优化 Android 数据导出流程，避免大备份文件保存时因内存占用过高导致闪退。
- 优化数据导入流程，降低大体积备份包导入时的内存压力。
- 修复时间胶囊日记导入后锁定状态丢失的问题。

## 修复
- 修复 Android 导出 ZIP 备份时，将完整备份文件通过原生通道传输导致的 OOM 闪退。
- Android 导出现在会通过系统文件保存入口按流写入目标位置，不再把整个 ZIP 一次性传给原生层。
- 修复导入备份时会重复整包读取 ZIP 的问题，降低大备份导入时的内存占用。
- 修复导入包含时间胶囊的日记时，`capsuleUnlockAt` 和 `capsuleLockedAt` 未恢复的问题。
- 导入后时间胶囊日记会继续保留原本的解封时间和锁定状态。

## 调整
- 数据导入解压改为基于文件流读取 ZIP，并逐条目写入临时目录。
- 保留原有备份格式、密码导入流程和覆盖导入策略。
- 增加导入/导出相关回归测试，覆盖大备份内存风险和时间胶囊字段恢复。
