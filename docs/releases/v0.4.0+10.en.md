# Release v0.4.0+10

English | [简体中文](./v0.4.0+10.md)

## Highlights
- Added WebDAV backup support for uploading local ZIP backups to self-hosted NAS or compatible WebDAV services.
- Added in-app configuration for WebDAV server URL, account details, and remote backup directory.
- Added remote backup listing and restore from WebDAV backups.

## Added
- Added a “WebDAV Sync” entry under Settings > Data & Privacy > Data Management.
- Added connection testing before saving WebDAV configuration.
- Added upload of the current app backup to the remote WebDAV directory.
- Added remote backup list refresh for discovering available backup files.
- Added restore from remote backups with a confirmation step before applying data.
- Added remote backup deletion for backups that are no longer needed.
- Added `manifest.json` metadata for remote backups, including file name, created time, file size, and app version.
- WebDAV passwords or tokens stay in local settings only and are not written into exported backup packages.
