# Release v0.4.0+10

[English](./v0.4.0+10.en.md) | 简体中文

## 版本要点
- 新增 WebDAV 备份能力，可将本地 ZIP 备份上传到自建 NAS 或兼容 WebDAV 服务。
- 支持在应用内配置 WebDAV 服务地址、账号信息和远程备份目录。
- 支持查看远程备份列表，并从远程备份恢复到本机。

## 新增
- 设置 > 数据与隐私 > 数据管理 新增“WebDAV 同步”入口。
- 支持连接测试，便于在保存配置前确认 WebDAV 服务可用。
- 支持上传当前应用备份到远程 WebDAV 目录。
- 支持刷新远程备份列表，查看可恢复的备份文件。
- 支持从远程备份恢复数据，并在恢复前进行确认。
- 支持删除不再需要的远程备份。
- 远程备份通过 `manifest.json` 记录文件名、创建时间、文件大小和版本信息，方便多设备识别备份。
- WebDAV 密码或 Token 仅保存在本机设置中，不会写入导出的备份包。
