# Release v0.4.5+11

English | [简体中文](./v0.4.5+11.md)

## Highlights
- Added customization for the diary editor floating toolbar, including per-tool visibility, ordering, and a configurable format for the “Insert current time” tool.
- Improved smoothness across diary lists, search, calendar, Explore, and app startup, especially with larger data sets and repeated interactions.
- Added image save/share actions in Explore media viewer and optimized caching/network handling for images, location, and weather services.

## Added
- Settings > Editor > Toolbar Button Order now supports enabling or disabling each toolbar tool; disabled tools are hidden from the editor floating toolbar.
- Configurable tools now show a settings button next to the drag handle on the toolbar order page.
- Added an “Insert current time” toolbar tool that inserts the current system time at the active cursor or selection.
- The “Insert current time” tool supports custom `DateFormat` patterns. The default pattern is `M月d日 HH:mm`, for example `6月23日 21:30`.
- Explore media viewer now supports saving images to the gallery and sharing images.
- Data backup and restore now include toolbar visibility and current-time format settings.

## Improved
- Diary list and search now use database-level pagination instead of loading all matching entries before truncating in the UI.
- Search and calendar keep the last successful content while refreshing, reducing full-screen loading flicker.
- Explore now uses a lightweight data source and avoids loading full rich-text content when entering the page.
- Home tab navigation updates target state immediately and prevents floating actions from triggering the previous tab during transitions.
- Startup minimum loading duration was reduced to 1.2 seconds, with less Home prebuild work behind the loading page.
- Android native launch backgrounds now match the app surface colors for light and dark themes to reduce the perceived white flash.
- Added indexes for hot database query columns used by lists, filters, and calendar views.
- Optimized waterfall preview image decoding and layout signature caching to reduce repeated work during scrolling and refresh.
- Remote image save/share now uses streamed downloads with short-term caching, size limits, and image type validation.
- Location and weather services now use short-term caching and pending-request reuse to reduce repeated location and network calls.

## Fixed
- Fixed inaccurate timeout semantics for large WebDAV backup transfers.
- Fixed a case where restoring a remote WebDAV backup could download the same backup twice.
- Aligned WebDAV configuration field prefix icons for a more consistent settings page layout.
