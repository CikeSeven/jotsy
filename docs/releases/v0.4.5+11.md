# Release v0.4.5+11

[English](./v0.4.5+11.en.md) | 简体中文

## 版本要点
- 新增日记编辑悬浮工具栏自定义能力，可按需显示工具、调整顺序，并为“插入当前时间”配置专属时间格式。
- 优化日记列表、搜索、日历、探索页和启动流程，提升大数据量与连续操作时的流畅性。
- 新增探索媒体图片保存与分享能力，并优化图片、定位、天气等服务的缓存和网络处理。

## 新增
- 设置 > 编辑器 > 工具栏按钮排序 支持勾选/取消勾选单个工具，未启用的工具不会显示在编辑页悬浮工具栏中。
- 工具栏排序页中，支持配置参数的工具会在拖拽把手左侧显示设置按钮。
- 新增“插入当前时间”工具，可将当前系统时间插入到编辑器当前光标或选区位置。
- “插入当前时间”支持自定义 `DateFormat` 时间格式，默认格式为 `M月d日 HH:mm`，例如 `6月23日 21:30`。
- 探索页媒体查看器支持保存图片到相册和分享图片。
- 设置备份/恢复会同步保存工具栏显示状态与当前时间格式配置。

## 优化
- 日记首页和搜索页改为数据库层分页查询，避免先加载全量结果再在界面层截断。
- 搜索和日历切换时保留上一份成功内容，减少整屏 loading 闪烁。
- 探索页改用轻量数据源，避免切入页面时加载完整富文本正文。
- Home 底部导航切换状态更及时，切换动画期间避免触发旧页面的悬浮按钮动作。
- 启动加载最短展示时长调整为 1.2 秒，并减少加载页背后的首页预构建工作。
- Android 原生启动背景与应用明暗主题表面色保持一致，降低启动白屏感。
- 为数据库热点查询字段增加索引，提升列表、筛选和日历等高频查询性能。
- 优化瀑布流图片预览解码和布局签名缓存，减少滚动与刷新时的重复计算。
- 远程图片保存/分享改为流式下载，并增加短期缓存、大小限制和图片类型校验。
- 定位与天气请求增加短期缓存和并发复用，减少重复定位与重复网络请求。

## 修复
- 修复 WebDAV 大备份传输超时语义不准确的问题。
- 修复 WebDAV 恢复远程备份时可能重复下载备份文件的问题。
- 调整 WebDAV 配置输入框前缀图标对齐，提升设置页观感一致性。
