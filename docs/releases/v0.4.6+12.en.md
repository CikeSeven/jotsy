# Release v0.4.6+12

English | [简体中文](./v0.4.6+12.md)

## Highlights
- Added customizable mood emojis, allowing the 10 mood choices in the publish/edit panel to be configured from Settings.
- Diary image interactions are now more direct: tapping a cover or inline image opens the full-screen image viewer immediately.
- Fixed Explore gallery image aspect ratio handling and several locked time capsule edge cases.

## Added
- Settings > Editor > Mood emojis now supports customizing 10 mood choices ordered from lowest to happiest.
- Custom mood emojis are used by the publish page, edit page, calendar mood aggregation, and Explore mood trend.
- Mood emoji settings can be reset to defaults; empty slots automatically fall back to the default emoji for that position.
- Added a shared image viewer used by both diary image browsing and Explore media gallery, with full-screen viewing, zoom, save, and share actions.

## Improved
- Tapping a diary cover or inline image now opens the image viewer directly instead of first showing an image action menu.
- Diary image browsing now builds one image list from the cover plus inline images, so users can swipe between them after opening the viewer.
- Explore media gallery thumbnails now preserve the original image aspect ratio and fill the thumbnail frame by cropping instead of stretching.
- Calendar and Explore mood summaries remain compatible with historical default mood emojis while displaying results on the current custom mood scale.

## Fixed
- Fixed missing confirmation when deleting a locked time capsule, reducing accidental deletion risk.
- Fixed locked time capsule schedule refresh not updating promptly.
- Fixed stretched image thumbnails in Explore and gallery image lists for some aspect ratios.
