# Release v0.4.8+13

English | [简体中文](./v0.4.8+13.md)

## Highlights
- Diary card tag visibility can now be configured from 0 to 20 and is applied consistently on Home, Search, and Archived lists.
- Added optional tag-filter memory so the previously selected diary tags can be restored the next time the app opens.
- Selected diary cards now use theme-aware highlights, accents, and short motion feedback, making batch selection easier to recognize.

## Added
- Settings > Appearance & Language > Diary card tags now lets you show up to 0–20 tags. The default is 2, while 0 hides tags entirely.
- Cards retain the `+N` summary when tags exceed the configured limit, and higher limits wrap within narrow cards instead of overflowing.
- The diary card tag limit is included in local ZIP and WebDAV backup export and restore while remaining compatible with older backups.
- Settings > Tag Management > Tag memory can remember the active tag filters; disabling it clears the saved filters.

## Improved
- Selected cards use a themed tint and side accent in list layout, plus an outline and shadow in waterfall layout, with a subtle bounce when selection changes.
- Improved the visual alignment of time, location, weather, and other metadata icons on the diary preview page.

## Fixed
- Fixed the first diary card tag-limit update potentially being missed during settings initialization.
- Fixed wrapping, summary alignment, and bounds issues with high tag counts in narrow waterfall cards.
- Fixed the English label using a plural noun when the diary card tag limit is one.
