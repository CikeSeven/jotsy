# Release v0.4.8+13

[English](./v0.4.8+13.en.md) | 简体中文

## 版本要点
- 日记卡片标签显示数量支持在 0–20 之间自定义，首页、搜索与归档列表统一生效。
- 新增可选的标签筛选记忆，下次进入应用时可自动恢复上次选中的标签。
- 日记卡片选中态增加主题色高亮、描边/侧边强调和短促动画，批量操作时更易辨认。

## 新增
- 设置 > 外观与语言 > 日记卡片标签支持设置最多显示 0–20 个标签；默认显示 2 个，设置为 0 时隐藏标签。
- 日记卡片标签超过显示上限时保留 `+N` 汇总，较高上限会自动换行，避免窄屏溢出。
- 日记卡片标签显示上限会随本地 ZIP 与 WebDAV 备份导出和恢复，并兼容旧版备份。
- 设置 > 标签管理 > 标签记忆支持记住当前标签筛选；关闭后会清除已保存的筛选条件。

## 优化
- 列表模式选中卡片会显示主题色浅底和左侧强调线；瀑布流模式增加描边与阴影，并在选择/取消时播放轻微回弹动画。
- 调整日记预览页时间、位置和天气等元数据图标的视觉对齐。

## 修复
- 修复标签显示设置初始化期间可能遗漏首次更新的问题。
- 修复高标签数量在窄瀑布流卡片中的换行、汇总对齐与越界问题。
- 修复英文环境下显示 1 个标签时仍使用复数文案的问题。
