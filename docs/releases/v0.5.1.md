# Release v0.5.1

[English](./v0.5.1.en.md) | 简体中文

- 新增日记录音与播放，支持暂停续录、重命名和波形进度拖动。
- 支持插入视频和文件附件，视频可全屏播放并保存到相册。
- 支持多选图片批量插入，发表日记时可选择不记录精力状态。
- 焕新 Material 3 Expressive 界面，优化卡片、标签、排版及明暗主题。
- 首页标签筛选支持展开与滚动，优化日记封面的尺寸和显示比例。
- 修复媒体导入与备份恢复问题，完善录音、视频、附件和草稿备份，降低大文件备份与恢复的内存占用。
- 修复旧备份含已删除标签或日记的残留关联时无法导入的问题，完整恢复现存日记、标签和媒体。
- 修复未设置标签偏好时删除标签失败的问题，保留日记内容与其余标签。
