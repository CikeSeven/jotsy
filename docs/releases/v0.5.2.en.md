# Release v0.5.2

English | [简体中文](./v0.5.2.md)

## Highlights
- Fixed the status bar keeping a stale overlay color after switching between light and dark themes.
- Fixed white borders and uncovered outlines around the new/edit diary page, so its background now follows the active theme.
- Fixed diary list card shadows being clipped into hard rectangular edges, restoring natural rounded shadow diffusion.

## Improvements
- Home tabs now read the current theme surface color dynamically, so cached tab backgrounds refresh on theme switch instead of keeping the previous theme's color.
- The edit diary page drops its outer 8dp margin and standalone rounded card container, using `colorScheme.surface` consistently for a more cohesive look.
- Unified the surface colors of the archived diaries and diary search pages to theme semantic colors, removing hardcoded white.

## Fixes
- Fixed pages such as the diary preview keeping the previous theme's status bar color after a theme switch; global and per-page top bars now inject a system overlay style that adapts to light and dark themes.
- Fixed diary cards in both list and waterfall modes being clipped by `ClipRect` after their appear animation finished, which produced rectangular hard edges and incomplete rounded `BoxShadow` rendering.
- Card background color and rounded borders are now painted by `BoxDecoration` with an anti-aliased Material ink layer, removing jagged edges in hover and pressed feedback.

## Notes
This is a bug-fix release with no new features. Diaries, backup files, and existing settings remain fully compatible, so you can upgrade with a direct overwrite install.
