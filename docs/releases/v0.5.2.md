# Release v0.5.2

[English](./v0.5.2.en.md) | 简体中文

## 版本要点
- 修复切换亮暗主题后状态栏颜色滞后于当前主题的问题。
- 修复新建/编辑日记页四周出现的白色边框与未覆盖轮廓，界面底色统一跟随主题。
- 修复日记列表卡片阴影被裁成直角硬边的问题，恢复圆角阴影的自然扩散。

## 优化
- 首页各 Tab 页面改为动态读取当前主题的 surface 色，主题切换后缓存页面背景同步刷新，不再残留旧主题底色。
- 编辑日记页去掉外层 8dp 边距和独立圆角卡片容器，编辑区与页面统一使用 `colorScheme.surface`，视觉更连贯。
- 归档日记页、日记搜索页的表格面底色统一走主题语义色，移除硬编码白色。

## 修复
- 修复日记预览页等页面在切换主题后状态栏仍停留在旧主题颜色的问题，全局与各页标题栏现均注入随亮暗主题自适应的系统叠加层样式。
- 修复日记卡片在列表与瀑布流模式下，卡片入场动画结束后仍被 `ClipRect` 裁剪，导致 `BoxShadow` 出现矩形硬边、圆角阴影显示不完整的问题。
- 卡片背景色与圆角边框改由 `BoxDecoration` 统一绘制，并使用抗锯齿的 Material 墨水层，悬停/按下反馈不再出现边缘锯齿。

## 说明
本次为问题修复版本，无新增功能；日记数据、备份文件与既有设置保持完全兼容，可直接覆盖安装升级。
