# Release v0.6.0

[English](./v0.6.0.en.md) | 简体中文

## 版本要点
- 新增网盘备份：可备份到 WebDAV（坚果云、Nextcloud、群晖等预设）、S3 兼容对象存储（阿里云 OSS、腾讯云 COS、Cloudflare R2 等）以及 Google Drive、Dropbox，并在应用内查看、恢复和删除云端备份。
- 新增从其他应用导入：支持 Day One、Journey、Diarium、Daylio、Apple 手记、Evernote / 印象笔记、Google Keep、Joplin、Memos、Diaro 与 Markdown / 纯文本；还可登录小米、华为、OPPO、vivo、荣耀、魅族和 WPS 账号，直接读取云端笔记。
- 日历全面升级：农历与节气、法定节假日的休 / 班标记、纪念日与倒数日、年视图、可定制的日期格样式，以及按日期区间统计。
- 外观可深度定制：日记卡片样式、预览页样式（预设、“我的样式”、样式码）以及正文字体与排版。
- 新增分享与导出：一键分享到微博、小红书、微信、朋友圈、QQ 和 QQ 空间；可导出为 PDF、Word、Markdown、网页、纯文本或 CSV，支持多选和按日期范围批量导出。

## 新增
- 纪念日：在日历中查看纪念日与倒数日，详情页显示倒计时和“历年这一天”写下的日记；可关联日记，也可在预览页把日记设为纪念日。
- 预览页可左右滑动切换上一篇 / 下一篇；长图默认折叠、点开后按屏宽阅读，也可在阅读设置中改为完整显示；点按正文图片选“查看”，图片从原位展开，支持双击放大和下拉关闭。
- 补写过去某天的日记时，标题下会列出相册里这天拍的照片，可一键插入或设为封面。
- 编辑页工具栏放不下的工具收进「更多」面板；已发表的日记可以修改发表时间；从日历的未来日期新建时，会预设时间胶囊的解封日。
- 发表时可选择地点显示到城市、区县、乡镇、道路或门牌号；定位完成后自动获取天气；发表面板收起时显示摘要栏和发表按钮。
- 日记列表支持按发表时间正序或倒序排列；卡片可隐藏“无标题”占位。
- 单篇日记可导出为日记文件；导入备份时可选择合并或覆盖，覆盖前会严重警告。
- 首页再次点击当前 Tab 可回到顶部。

## 优化
- 全应用统一动画节奏，并遵守系统“减少动态效果”设置；看图页与封面、缩略图、正文图片之间增加共享元素过渡；操作生效时有轻微触感反馈。
- 启动时系统启动画面无缝衔接到应用内的品牌图形，首页依次展开；数据很快就绪时直接进入首页，不再固定显示加载页。
- 编辑页在键盘弹出、面板拖动时更流畅；列表、标签筛选与日历切换不再闪烁或跳动；未解封的胶囊卡片滚动更顺滑。
- 录音面板与播放器重新设计：实时滚动的声纹、随状态变形的主按钮。
- 日记列表左滑归档改为跟手反馈，越过阈值时轻震提示；多选时顶栏固定并显示已选数量。
- 正文图片以独立块显示（圆角、上下留白），缩小后的图片靠行首对齐。
- 字数统计采用与 Word、WPS 一致的口径，全应用统一。
- 新建按钮只在日记页显示；天气图标跟随主题色。
- 无障碍：应用锁定时读屏不再读出日记内容；颜色选择的点击区域扩大到 48dp；纯图标按钮补充了读屏说明。
- 英文界面不再残留中文文案。

## 修复
- 编辑页适配手机键盘：输入法编辑面板的“选择”模式现在可以选中文字；在底部打字、或点击底部文字弹出键盘时，内容随键盘上移，并与工具栏保持间距。
- 发表过程中不能返回或重复发表，避免日记已写入、草稿却仍留在编辑页；新日记的发表时间不再停留在打开发表页的那一刻。
- 编辑已发表的日记时不再丢失时间胶囊等信息；时间胶囊的选择跟随预设与精度；新日记默认不记录精力。
- 定位失败时改用系统定位重试，并修正地址解析的坐标偏移。
- 修复启动时的黑屏闪烁。
- 修复列表卡片的心情与天气印章不显示、日历缩略图变形、日历周视图点“下个月”不翻月的问题。
- 工具栏排序页返回时若有未保存的修改会先确认，不再静默丢弃。
- 归档页与回收站移除条目时有收起动画，不再硬跳。

## 说明
本版本新增功能较多。日记数据、备份文件与既有设置保持兼容，可直接覆盖安装升级；新增的卡片样式、预览页样式、正文排版、日历显示以及分享与导出选项都会随备份一起导出。
