# Release v0.6.1

English | [简体中文](./v0.6.1.md)

## Highlights
- In-app updates, rebuilt: download, verify and install inside the app, with the package that matches your phone's architecture picked for you. Built for networks in mainland China: several routes are checked at once, the fastest one is used and interrupted downloads resume.
- Faster with large libraries: paging and time-based sorting in the diary list and the stats on the Explore tab are much quicker, and the app holds less memory after long use.
- Fixed HONOR cloud notes import stopping with "session expired" while downloading images.

## New
- An App updates page (Settings → About → Check for updates): see what's new in the latest version, follow progress, speed and the route in use while downloading, and install as soon as it finishes. The download keeps going after you leave the page.
- Choose a download route: Automatic, a built-in mirror, GitHub direct or a custom mirror. Automatic tests the routes and uses the fastest; if a download stalls or slows to a crawl, it switches routes and resumes where it stopped.
- Before installing, the package's size, SHA-256, package name, signature and version are checked; if anything does not match, the file is deleted, so a mirror cannot swap in another app.
- Automatic update checks: run quietly when you open or return to the app, at most every 2 hours. When a new version is found you can pick Update now, Skip this version or Later, and the same version is offered only once per run. Settings → About marks a new version; automatic checks can be turned off in the update settings.

## Improvements
- The diary list picks the current page by filter and sort order before loading bodies and tags, and new indexes back sorting by update time and publish time. In a 10,000-diary benchmark, paging in time order is about 10× faster.
- Explore's trend, mood, energy and tag stats are computed in a single pass, about 8× faster in the same benchmark.
- Word counts no longer slow down on very long text or long runs of punctuation.
- Calendar, On this day, archive and recycle bin data are released about 30 seconds after you leave the page, and cached diary card text has a total size limit, so the app holds less memory after long use.

## Fixes
- HONOR cloud notes import read every note, then stopped with "session expired" at the first image. Attachments are now read from the file server HONOR actually uses, with your login attached.
- In the diary card style and preview style editors, the List / Waterfall and light / dark preview buttons above the preview did not update after a tap and could not be switched back and forth.

## Notes
- When upgrading from v0.6.0, its "Check for updates" still opens the browser and offers the arm64-v8a package first; on a 32-bit (armeabi-v7a) phone, download the matching package from the GitHub Release page. From this version on, updates happen inside the app.
- The first time you install an update from inside the app, Android 8 and later asks you to allow Jotsy to install unknown apps; turn it on and return to the app to continue.
- Releases now include `SHA256SUMS.txt` to verify packages you download yourself.
- Diaries, backup files and existing settings remain compatible, so you can upgrade with a direct overwrite install. On first launch the app adds sort indexes to the diary table without changing existing data.
