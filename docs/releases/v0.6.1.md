# Release v0.6.1

[English](./v0.6.1.en.md) | 简体中文

## 版本要点
- 应用内更新全面重做：直接在应用内下载、校验并安装，自动选择适合本机架构的安装包；面向国内网络，多条线路同时检查、测速择优，断线自动续传。
- 日记多了也更快：日记列表翻页、按时间排序与探索页统计明显提速，长时间使用后占用的内存更少。
- 修复荣耀云笔记导入在下载图片时提示“登录已过期”而中断的问题。

## 新增
- 「软件更新」页（设置 → 关于 → 检查最新版本）：显示新版本的更新内容，下载时显示进度、速度与所用线路；离开页面后下载继续进行，完成后直接安装。
- 「下载线路」可选自动选择、内置镜像、GitHub 直连或自定义镜像。自动选择会先测速、使用最快的线路；下载中途卡住或过慢时自动换线，并从断点续传。
- 安装前核对安装包的大小、SHA-256、包名、签名与版本，任一项不符即删除，镜像无法把它换成别的应用。
- 自动检查更新：打开或回到应用时在后台检查，每 2 小时最多一次；发现新版本时可选「立即更新」「跳过此版本」或「以后再说」，同一版本在一次运行中只提示一次。「设置 → 关于」入口会标出新版本；自动检查可在更新设置中关闭。

## 优化
- 日记列表先筛选、排序出当前页再读取正文与标签，并为按更新时间、发表时间排序新增索引；在一万篇日记的基准测试中，按时间排序的翻页读取快约 10 倍。
- 探索页的趋势、心情、精力与标签统计合并为一次扫描，同一基准下快约 8 倍。
- 超长正文或大段连续标点的字数统计不再变慢。
- 日历、那年今日、归档与回收站的数据在离开页面约 30 秒后释放，日记卡片的正文缓存设有总量上限，长时间使用后占用的内存更少。

## 修复
- 荣耀云笔记导入读完笔记后，下载第一张图片时会提示“登录已过期”并中断；现在附件改从荣耀实际使用的文件服务器读取，并带上登录状态。
- 日记卡片样式与预览页样式的编辑页中，预览上方工具条的「列表 / 瀑布流」与浅色 / 深色预览按钮点按后状态不刷新、无法来回切换，现已修复。

## 说明
- 从 v0.6.0 升级时，旧版的“检查最新版本”仍会跳转浏览器下载，并优先给出 arm64-v8a 安装包；32 位（armeabi-v7a）手机请到 GitHub Release 页面手动下载对应安装包。升级到本版本后，之后的更新即可在应用内完成。
- 首次在应用内安装更新时，Android 8 及以上会请求允许 Jotsy「安装未知应用」，开启后返回应用即可继续安装。
- Release 附件新增 `SHA256SUMS.txt`，可用来校验手动下载的安装包。
- 日记数据、备份文件与既有设置保持兼容，可直接覆盖安装升级；首次启动会为日记表补建排序索引，不改动已有数据。
