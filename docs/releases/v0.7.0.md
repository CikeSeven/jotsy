# Release v0.7.0

[English](./v0.7.0.en.md) | 简体中文

## 版本要点
- 日记本：把日记分本收纳，一篇可以同时放进几本；支持章节与书序、智能日记本、隐藏与上锁、统计与写作目标，还能整本导出成书。
- 日记模板与草稿箱：内置 8 个模板，也能自己做模板或把日记存为模板，按时间段自动套用；每次新建都是一份独立草稿，误点“新建空白”不再抹掉上一篇。
- 功能管理：日历、探索、日记本、纪念日、日记模板、时间胶囊都可以关闭，界面更清爽，数据原样保留。
- 编辑器颜色面板重做：在工具栏里直接选色，可在色谱里自由取色、输入颜色代码，并记住最近用过的颜色。
- 从其他应用导入更完整：保留颜色、字号、对齐、分隔线与各种附件；修复小米带图笔记、魅族与 vivo 部分笔记被静默跳过的问题，跳过的笔记会在预览里说明原因。

## 新增
### 日记本
- 首页标签栏第一项是日记本切换胶囊，选中某本后首页原地切换成这本，顶部卡片显示这本的概况；在本子里新建的日记自动收进这本。
- 一篇日记可以同时在多本里，移出日记本不会删除日记。可从多选栏、发布面板、编辑页与预览页收进、移出或移动。
- 章节与书序：本子可以分章节，在目录页拖动调整整本的顺序。
- 智能日记本：按标签、心情、日期、文字、有无图片等条件自动收录，可从示例开始；搜索结果可「存为智能日记本」，日历选中的一段日期可「存为日记本」；智能本也可以转为普通日记本。
- 隐藏与上锁：私密本子里的日记不出现在全部日记、搜索、日历、探索与导出中；上锁的本子进入前、编辑与删除前都要验证身份，切到后台后自动重新上锁。
- 统计页与写作目标；可为本子设默认模板，在这本里新建时自动套用。
- 导出成书：日记本 ⋮ 菜单 →「导出成书」。PDF、Word、网页、Markdown、纯文本按书序排列，带扉页、目录与章节；PDF 的目录有页码并可点按跳转。
- 日历可按日记本筛选；管理页在 设置 → 日记本。

### 日记模板
- 内置每日记录、晨间日记、晚间复盘、感恩日记、每日一问、周回顾、情绪梳理、读书笔记 8 个模板，可复制为自己的模板再修改。
- 新建空白日记时，标题下按时段推荐模板，点一下即套用，4 秒内可撤销；只套用、没写字就离开不会留下草稿。
- 模板支持 `{{日期}}`、`{{星期}}`、`{{农历}}`、`{{节气}}` 等 12 个变量，以及预设标签、心情、精力与时间胶囊。
- 按时间段自动套用：时间段可跨夜、可限定星期，时间段之外可设默认模板。
- 编辑页 ⋮ 菜单可「选择模板」或换成另一个模板，预览页与编辑页可把日记「存为模板」（图片等媒体不会保留）；模板面板支持搜索与分类筛选。
- 模板码可复制分享、从剪贴板导入；管理页在 设置 → 编辑器设置 → 日记模板。

### 草稿箱
- 每次新建都是一份独立草稿，返回、切到后台时自动保存，最后几秒的输入不再丢失。
- 有草稿时点“新建”会列出最近的草稿，可续写、「从模板新建」或「新建空白」。
- 草稿箱页（首页顶栏与 设置 → 数据与隐私）：左滑删除、长按多选，删除都可撤销。

### 其他
- 设置 → 功能管理：可关闭日历（纪念日随之关闭）、探索、日记本、纪念日、日记模板、时间胶囊。关闭只隐藏入口与自动行为，数据保留，重新开启即恢复。
- 颜色面板：文字颜色与背景颜色在悬浮工具栏内展开，不再弹窗、不收起键盘。「色板」页为预设与最近用过的颜色；「自定义」页可在色谱里取色、调背景透明度、输入颜色代码。
- 编辑页 ⋮ 菜单「这天的照片」：新建与编辑时都能打开那天拍的照片；编辑器设置里的开关改为「自动显示当天照片」，只控制补写时的自动提示。
- 发布面板的标签页：可按名称或拼音（全拼、首字母）搜索，没找到时可直接新建；支持「按字母排序」，右侧字母条可快速跳转。
- 看图页：长按图片或点 ⋮ 打开操作面板，可直接分享到微信、微博等已安装的应用、保存到相册；从探索页媒体画廊看图时还能「打开日记」。
- 导出跟随正文字体：选了导入字体时，PDF 嵌入这款字体，Word 与网页按字体名引用。

## 优化
- 首页顶栏去掉标题，搜索条更宽；没有标签时不再显示空的标签栏，标签行更贴近搜索条。
- 预览页标题栏的分享按钮改为打开分享面板，与「更多 → 分享」一致。
- 编辑页顶栏、纪念日详情页等只有几项操作的“更多”改为锚定的弹出菜单，全应用菜单样式统一。
- 选项说明折行时，单选圆点、图标与箭头相对整行居中。
- 导入笔记里的分隔线显示为细线，并导出为各格式的分隔线；正文里的小号、大号、特大号文字改为随正文字号缩放。

## 修复
- 小米云笔记中带图片的笔记整篇被跳过；魅族笔记遇到认不全的内容整篇被跳过；vivo 笔记图片或分隔线之后的正文丢失。
- 云端导入跳过的笔记（加密、手写等专有类型、无法识别）现在按原因在导入预览里列出篇数；WPS 长正文读不到时改为导入摘要，不再让整次导入失败。
- 其他应用的文件导入：修复部分来源的编码、日期、附件路径与格式问题，共享附件与重复条目不再丢失。
- 首页瀑布流快速下滑加载下一页时，列表跳回顶部附近。
- 日历删除日记后的“撤销”、新建纪念日后的“查看”提示一直不消失，撤销窗口不结束，首页按钮停在上移位置。

## 说明
- 首次启动会升级数据库，新增草稿、模板与日记本相关的表，不改动已有日记；旧版本里那份未完成的新建草稿会出现在草稿箱中。
- 完整备份新增日记本、模板与草稿。用不含模板的旧备份做“覆盖全部”会清空本机模板，警告框会列出个数；合并导入只新增本机没有的模板，不覆盖已有模板。
- 上锁日记本与应用锁一样依赖系统锁屏，手机没有设置锁屏密码时无法打开上锁的本子。
- 用导入字体导出的 Word 与网页文件不嵌入字体，只有装了这款字体的设备才会显示它。
- 日记数据、备份文件与既有设置保持兼容，可直接覆盖安装升级，也可以在 设置 → 关于 → 检查最新版本 中应用内更新。
