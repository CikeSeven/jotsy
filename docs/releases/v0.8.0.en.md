# Release v0.8.0

English | [简体中文](./v0.8.0.md)

## Highlights
- Navigation bar style: turn the bottom bar into a floating frosted-glass bar, and the top bars of Diaries, Calendar, Explore and Settings into glass too. 6 built-in presets, fine control over material, floating bar, nav items and outlines, and your own styles saved or shared as style codes.
- Code blocks, rebuilt: 10 color themes, syntax highlighting and language detection for 22 languages, line numbers, and a header with the language name and a copy button. Switch the language, copy or leave a code block right from the toolbar.
- Exports keep colors and code highlighting: Word and web pages keep text and background colors, and code blocks in PDF, Word and web exports are colored with your code block style.
- The color panel gets a Material tab and "My colors": the full Material shades are back, and colors you mix yourself are saved for next time.
- The editor can always show its toolbar, so you can format text with a physical keyboard too.

## New
### Navigation bar style
- Settings → Appearance & Language → Navigation bar style. Pick from 6 presets (Classic, Glass, Clear, Misty, Tinted, Compact), save your own styles, or share and import them as style codes.
- With the glass material the bottom bar floats over the page and content blurs as it scrolls underneath. Adjust blur, opacity, tint (neutral, accent or a color of your choice) and shadow.
- "Glass top bars too" turns the top bars of all four pages into frosted glass that content scrolls under. The top bar divider is off by default and has its own switch.
- The bottom bar outline and the top bar divider each have their own color (default, highlight, accent or custom), opacity and width.
- Set the floating bar's height, corner radius, side margins and distance from the bottom, and place the New button above the bar or beside it.
- Nav items: labels always, for the selected item only, or hidden; icon size; icon to label spacing; and a capsule, block or no selection indicator.
- Behavior: hide the bar when scrolling down (with the floating glass bar) and let the indicator follow swipes. Behavior doesn't change with presets or style codes.

### Code blocks
- Settings → Editor → Code block style (also the gear next to the code block tool in toolbar order), with a live preview:
  - Theme: Match app, GitHub, One, Solarized, Gruvbox, Catppuccin, Tokyo Night, Nord, Dracula and Rosé Pine, each in light and dark, following the app's brightness or fixed to one;
  - Display: line numbers, header bar, language detection, border and corner radius;
  - Font: system monospace, your body font or an imported font, with size and line height.
- Syntax highlighting for 22 languages: Dart, Python, JavaScript, TypeScript, Java, Kotlin, Swift, C/C++, C#, Go, Rust, PHP, Ruby, Lua, Shell, SQL, JSON, YAML, HTML/XML, CSS, Markdown and Diff. Code blocks without a language are detected automatically; colors don't flicker while you type and the language is checked again once you pause.
- A header above each code block shows the language and a copy button, in the editor and on the preview page.
- Inside a code block, the code block button on the toolbar opens a panel in the toolbar card: pick a language (auto, plain text or one of the 22), copy the code, exit the code block, or convert it to text. The keyboard stays up.
- Enter keeps the current line's indentation. Blank lines are allowed inside a block; Enter on the second blank line at the end leaves it, and a single undo brings it back.
- Markdown and web page imports and exports keep the code block language.

### Color panel
- New Material tab: every shade of the 19 Material color families, accents A100–A700 included. Swipe the shades or tap the dots below to switch families; it opens on the family of the selected text's color.
- My colors: a color you mix on the Custom tab is saved once it is applied (fine-tuning the same text keeps only the last one), up to 24 each for text and background. The row under the Swatches tab scrolls sideways: tap + to mix a new color, or tap the pen or long-press to manage — remove colors, or keep ones used in this diary.
- Your old recent colors carry over as My colors, and the panel keeps one height, so switching tabs no longer makes it jump.

### More
- Editor → Toolbar & mood → "Always show toolbar" (off by default): the floating toolbar stays at the bottom of the editor when the on-screen keyboard is hidden or a physical keyboard is connected. When editing an existing diary it sits above the collapsed info panel bar and makes way when the panel expands.
- Exports: Word and web pages keep text and background colors (web pages keep translucency, and colors stay the same in dark mode). Code blocks in PDF, Word and web exports are highlighted with your code block style; when brightness follows the theme, web pages switch to the dark palette in dark mode.
- Settings → About → "Support the developer": a WeChat tip code and an Alipay payment code. Alipay opens straight to payment; for WeChat, save the code to your gallery and scan it from there. Tipping is entirely optional, unlocks nothing, and nothing is sent or recorded.

## Improvements
- Popup menus now have a translucent frosted surface with accent-colored icons; single-choice menus such as tag sorting highlight the current option with a check mark.
- On the Calendar, scrolling down tucks the month row under the title bar so the day's diaries get more room; it comes back when you scroll to the top.

## Fixes
- Leaving a blank line in a code block, or pressing Enter right after turning a line into code, moved you out of the code block.
- PDF exports painted translucent background colors as solid colors, making text nearly unreadable on a matching background (such as red text on light red).

## Notes
- No database upgrade in this version. Navigation bar style, code block style and My colors are included in full backups; restoring an older backup without these two styles keeps the ones on this device. "Always show toolbar" is a per-device preference and is not backed up.
- Code highlighting in exports follows the theme and language detection set in Settings → Editor → Code block style. Markdown only writes the language on the fence; plain text and CSV stay uncolored.
- Diaries, backup files and existing settings remain compatible, so you can upgrade with a direct overwrite install or update inside the app from Settings → About → Check for updates.
