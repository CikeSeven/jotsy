# Release v0.8.0

[English](./v0.8.0.en.md) | 简体中文

## 版本要点
- 导航栏样式：底栏可换成磨砂玻璃悬浮栏，日记、日历、探索、设置的顶栏也能一起变成玻璃；内置 6 套预设，材质、悬浮栏、导航项与描边都能细调，可存为“我的样式”或用样式码分享。
- 代码块重做：10 套配色主题、22 种语言的语法高亮与自动识别、行号，顶部标题栏显示语言并可一键复制；在工具栏里就能切换语言、复制或退出代码块。
- 导出保留颜色与代码高亮：Word 与网页保留文字颜色和背景色，PDF、Word、网页里的代码块按你的代码块样式着色。
- 颜色面板新增「色系」页与“我的颜色”：找回 Material 全套色阶，自己调出的颜色自动存下，随时再用。
- 编辑器可「始终显示工具栏」，连接实体键盘时也能设置格式。

## 新增
### 导航栏样式
- 设置 → 外观与语言 → 导航栏样式。预设有经典、玻璃、通透、浓雾、主题色、紧凑 6 套，也可以存为“我的样式”，或用样式码分享、导入。
- 玻璃材质下底栏悬浮在页面上，内容从栏下滚过时透出模糊；可调模糊强度、不透明度、色调（中性 / 主题色 / 自选颜色）与阴影。
- 「顶栏也用玻璃」：四个页面的顶栏一起变成磨砂，内容从顶栏下滚过；顶栏分隔线默认关闭，可单独打开。
- 底栏描边与顶栏分隔线可分别设颜色（默认 / 高光 / 主题色 / 自选）、不透明度与粗细。
- 悬浮栏可调高度、圆角、两侧边距与离底距离；新建按钮放在栏上方或栏右侧。
- 导航项可设文字显示方式（始终 / 仅选中项 / 不显示）、图标大小、图标与文字间距；选中指示器可选胶囊、色块或无。
- 行为：下滑时收起底栏（玻璃悬浮栏下可用）、指示器跟随左右滑动。行为不随预设与样式码改变。

### 代码块
- 设置 → 编辑器设置 → 代码块样式（工具栏排序里代码块工具旁的齿轮也能进入），带实时预览：
  - 配色：跟随应用、GitHub、One、Solarized、Gruvbox、Catppuccin、Tokyo Night、Nord、Dracula、Rosé Pine，每套都有浅色与深色，明暗可跟随主题或固定；
  - 显示：行号、标题栏、自动识别语言、边框、圆角；
  - 字体：系统等宽、正文字体或导入的字体，可调字号与行距。
- 语法高亮支持 Dart、Python、JavaScript、TypeScript、Java、Kotlin、Swift、C/C++、C#、Go、Rust、PHP、Ruby、Lua、Shell、SQL、JSON、YAML、HTML/XML、CSS、Markdown、Diff 共 22 种语言；没指定语言的代码块自动识别，输入时颜色不闪，停手片刻再重新识别。
- 代码块顶部的标题栏显示语言名与复制按钮，编辑页和预览页都有。
- 在代码块里点工具栏的代码块按钮，工具栏卡片内展开代码块面板：选语言（自动、纯文本与 22 种语言）、复制代码、退出代码块、转为正文，键盘不会收起。
- 回车沿用当前行的缩进；块里可以留空行，在块尾第二个连续空行上回车才退出代码块，一次撤销即可还原。
- Markdown 与网页的导入、导出会带上代码块的语言。

### 颜色面板
- 新增「色系」页：19 个 Material 色系的全部色阶（含 A100–A700 强调色），左右滑动色阶或点下方的圆点切换色系，打开时停在所选文字当前颜色所在的色系。
- “我的颜色”：在「自定义」页调出的颜色写入正文后自动存下（同一段文字上接连微调只留最后一个），文字色与背景色各最多 24 个。「色板」页下方一行可以横向滚动：点 ＋ 去调新颜色；点笔形按钮或长按进入管理，可以移除颜色，或把这篇日记里用过的颜色存下。
- 以前“最近用过的颜色”原样成为我的颜色；面板高度固定，切换页签不再跳动。

### 其他
- 编辑器设置 → 工具栏与心情 →「始终显示工具栏」（默认关）：收起软键盘或连接实体键盘时，悬浮工具栏仍留在编辑页底部；编辑已有日记时叠在信息面板收起栏上方，展开信息面板时让位。
- 导出：Word 与网页保留文字颜色和背景色（网页保留半透明效果，深色模式下颜色不变）；PDF、Word、网页里的代码块按代码块样式语法着色，明暗跟随主题时，网页在深色模式下换用深色配色。
- 设置 → 关于 →「支持开发者」：微信赞赏码与支付宝收款码，支付宝可直接跳转付款，微信可先把赞赏码保存到相册再扫码。打赏完全自愿，不解锁任何功能，也不联网、不记录任何信息。

## 优化
- 弹出菜单换成半透明的磨砂表面，图标改用主题色；标签排序这类单选菜单的当前项高亮并带对勾。
- 日历页向下滚动时，月份那一行收到标题栏下面，只留标题栏，看当天的日记空间更大；回到顶部即恢复。

## 修复
- 在代码块里留一行空行，或刚转成代码块就回车，会被移出代码块。
- PDF 导出把半透明的背景色画成实色，与同色系的文字几乎分不清（如红字配浅红底）。

## 说明
- 本版不升级数据库。导航栏样式、代码块样式与我的颜色随完整备份导出；用不含这两项样式的旧备份恢复时，本机当前的样式保持不变。「始终显示工具栏」是本机偏好，不随备份导出。
- 导出代码高亮跟随 设置 → 编辑器设置 → 代码块样式 的配色与自动识别开关；Markdown 只在围栏上写语言，纯文本与 CSV 不着色。
- 日记数据、备份文件与既有设置保持兼容，可直接覆盖安装升级，也可以在 设置 → 关于 → 检查最新版本 中应用内更新。
