# Release v0.8.1

[English](./v0.8.1.en.md) | 简体中文

## 版本要点
- 内置模板换新：8 个内置模板全部重写，小标题改成与正文同字号的彩色粗体，不再被大号标题占满一屏；内置模板可以直接编辑、删除，改过的随时能恢复默认。
- 草稿箱与回收站支持全选；回收站改版，能看到正文摘要与封面，选中后在底部恢复或彻底删除。
- 导出更忠实：PDF 里正文标题的颜色与格式不再丢失，Word 正文跟随你设置的字号、行距、字间距与段间距。

## 新增
### 日记模板
- 8 个内置模板全部重写：小标题前带表情，用与正文同字号的彩色粗体；晨间日记带醒来时间与节气、周回顾带第几周与今年的进度等灰色小字，各段之间空一行。在小标题后面接着写，文字不会跟着变粗、变色。
- 内置模板可以直接编辑：点开即进入编辑页，保存后替换默认内容，仍留在内置列表原位并标「已修改」；最近使用、按时间段自动套用与日记本默认模板照常指向它。「恢复默认」可撤销。
- 内置模板可以删除：删除后不再出现在管理页、模板面板与建议条里，在管理页末尾「恢复已删除的内置模板」可逐个或全部找回，删除前改过的内容一并回来。
- 内置模板能直接改，原来的「复制为我的模板」「隐藏」随之移除。

### 草稿箱与回收站
- 全选：草稿箱多选时，删除旁边多了「全选」，再点一次取消全选并退出多选；回收站有日记时顶栏就有「全选」。
- 回收站改为卡片列表：显示两行正文摘要、封面缩略图与“日期 · 删除时间”；私密日记本里的日记只显示占位标题与锁，未解封的时间胶囊只显示标题与日期。
- 选中日记后底部升起操作栏，可「恢复」或「彻底删除」；选择时左上角变为关闭按钮，系统返回也先取消选择。

## 修复
- PDF 导出的正文标题丢失文字颜色、背景色、粗细、下划线等格式与链接，同一行里格式不同的文字被合并成一样。
- Word 导出的正文没有跟随“正文字体与排版”里的字号、行距、字间距与段间距；列表与引用也一并跟随。
- 新版本刚发布、安装包还在上传的几十分钟里，手动检查更新会显示“检查失败”；现在显示已是最新，等安装包上传完成才提示新版本。

## 说明
- 本版不升级数据库。
- v0.8.0 里“隐藏”的内置模板，升级后算作已删除，不再出现在管理页列表中，可在 设置 → 编辑器设置 → 日记模板 末尾的「恢复已删除的内置模板」里找回。
- 内置模板的新样式只影响之后套用的日记，已经写好的日记不变。改过的内置模板随完整备份导出与覆盖恢复；合并导入仍只新增本机没有的模板，不覆盖已有模板。
- 日记数据、备份文件与既有设置保持兼容，可直接覆盖安装升级，也可以在 设置 → 关于 → 检查最新版本 中应用内更新。
