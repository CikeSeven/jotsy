# Release v0.9.0

[English](./v0.9.0.en.md) | 简体中文

## 版本要点
- 桌面版来了：Windows 与 Linux 首次提供安装包。宽窗口下有侧边导航栏、日记列表与阅读双栏，支持右键菜单、Ctrl / Shift 多选、键盘快捷键和把文件拖进正文。
- 全新编辑器：正文改用块编辑器，支持 Markdown 快捷输入、光标旁的 `/` 命令菜单、拖动段落（实时预览）与缩进嵌套；列表可选多种编号与符号，工具栏可调大小，正文排版新增首行缩进。
- 背景与材质：给全局或单个页面设背景颜色、背景图片，顶栏、工具栏、面板、对话框、卡片与小控件可以分别换成磨砂玻璃。
- 探索页重写：21 张卡片任意排序、显隐、调宽度和选项，顶部按本周 / 本月 / 今年 / 全部统计，内置 5 套布局，也可存为“我的布局”或用布局码分享。
- 日记本可以嵌套子本、自定义封面；书架新增“未收录”，一眼找出还没归进日记本的日记。
- 新功能：给重读的日记写留言、在日历上记录“这天的心情”；还能从榴莲日记与锤子便签导入。

## 新增
### Windows 与 Linux 桌面版
- 安装包：Windows 10 及以上（x64）提供安装程序与便携版，Linux（x64，GTK 3）提供压缩包与 `install.sh`。下载地址与安装方法见 README 与官网。
- 宽窗口布局（按窗口宽度，平板横屏同样适用）：600 以上用左侧导航栏代替底栏；1024 以上日记页为“列表 + 阅读”双栏，点卡片在右栏阅读，正在读的那张卡片带主色外环。编辑页、预览页与二级页的内容收成居中的一列，不再铺满整个窗口。
- 鼠标：右键日记卡片可编辑、置顶、收进日记本、归档或删除；Ctrl / ⌘ + 点按多选，Shift + 点按连选一段；横向条带可以拖动，Shift + 滚轮横向滚动；看长图时滚轮上下滚动，Ctrl + 滚轮缩放。
- 键盘：Ctrl / ⌘ + N 新建、F 搜索、1–4 切换页面；双栏里 ↑ / ↓ 换篇、Enter 编辑、Delete 删除（可撤销）、Esc 取消选中；预览页与看图页 ← / → 翻页，Esc 返回。
- 编辑：从文件管理器把图片、视频或文件拖进正文，插在光标处；悬浮工具栏一直显示，常用格式快捷键（Ctrl + B / I / Z）照常可用。
- 关闭窗口前会先保存未存的改动，保存失败时保留窗口；重复启动会唤起已打开的窗口。
- 检查更新：有新版本时提示，点“前往下载”在浏览器里经镜像线路下载本平台的安装包。
- 暂时只在手机上提供：分享到指定应用、手机厂商与 WPS 云端笔记导入、“这天拍的照片”、自动定位与天气；Windows / Linux 上正文视频交给系统播放器打开；Linux 版暂不支持录音、应用锁与上锁日记本。

### 全新编辑器
- 编辑页、预览页与模板统一使用块编辑器：软键盘上也能用 Markdown 写法（`# `、`- `、`> `、`1. ` 等）直接转换格式。
- `/` 命令：在光标旁弹出内联菜单，接着输入即可筛选（支持拼音，如 `/biaoti`），键盘不会收起。
- 段落把手：点光标所在段落左侧的把手，可以上移、下移，或“长按拖动”；拖动时段落实时挪到新位置，缩进层级保持不变，一次撤销即可还原。
- 列表样式：光标在列表里时点列表工具，展开列表面板——有序可选 1. / (1) / ① / 一、/ a. / A. / i. / I.，无序可选实心圆、空心圆、方块、菱形、星形、箭头、短横线；整段列表一起改，导出也带上同样的样式。
- 工具栏大小：设置 → 编辑器设置 → 工具栏大小，可选小、标准、大、特大。
- 首行缩进：设置 → 编辑器设置 → 正文字体与排版（预览页的排版面板也有），0–4 字，默认不缩进；只作用于普通段落，Word 导出同样缩进。
- 打开日记时直接编辑：设置 → 编辑器设置，开启后从各处点开日记直接进入编辑页（未解封的时间胶囊仍先进封存页）。

### 背景与材质
- 设置 → 外观与语言 → 背景与材质。背景可以设在全局，也可以按日记、日历、探索、设置、编辑、预览、其他 7 个区域分别选择跟随全局、不显示或单独设置；类型为纯色或图片，图片支持取景、模糊与浅色 / 深色遮罩。
- 组件风格：经典或玻璃一键切换，也能对二级页顶栏、编辑器工具栏、底部面板、对话框、卡片与分组、小控件与提示条分别设置；玻璃的模糊、不透明度、底色与描边可调。
- 日记卡片样式新增“玻璃”材质与预设；日记卡片、导航栏、预览页与代码块的样式编辑页，预览都画在对应页面的背景上。
- 背景图随完整备份导出。

### 探索页
- 21 张卡片分四组：回顾与灵感（今日问候、那年今日、随机回顾、周期回顾、里程碑）、统计图表（数据看板、写作热力图、写作节奏、写作习惯、心情趋势、心情分布、精力趋势）、生活记录（标签、媒体画廊、足迹、天气）、关联功能（纪念日、时间胶囊、日记本、草稿箱、最近的留言）。
- 顶部统计范围：本周 / 本月 / 今年 / 全部，跟随范围的卡片随之重新统计。
- 自定义：点探索页顶栏的按钮或进入 设置 → 外观与语言 → 探索页。卡片可以拖动排序、开关、设半宽或整宽并调整各自选项；外观可调密度、圆角、标题样式、卡片表面、强调色与宽窗口列数；内置均衡、精简、数据控、回忆、全部显示 5 套布局；预览可切换“我的数据 / 示例数据”。
- 长按卡片（桌面为右键）可以直接进入这张卡的设置，或隐藏它（可撤销）。

### 日记本
- 子日记本：最多三层，父本里能看到子本的全部日记；书架上有子本的封面叠放显示，首页头部列出子本并带上级路径，返回时先回到上级。上级上锁或隐藏时，子本一并私密。
- 自定义封面：经典、满版、书脊、贴签、极简 5 种版式，圆点、横线、方格、斜纹 4 种纹理；封面图可以拖动、缩放取景，也能直接从本子里的日记中选图。
- 书架“全部日记”下新增“未收录”，只列没有收进任何日记本的日记；“全部日记”行尾显示总篇数。
- 父本导出成书时，子本按顺序各成一章；日历按日记本筛选时，选父本也包含它的子本。

### 留言
- 设置 → 功能管理 → 留言（默认关闭）。打开后，在预览页“更多 → 写留言”给这篇日记写一段回应，可带心情；留言按时间排在正文末尾，显示“写下后 N 天”，可编辑、复制、删除（可撤销）。正文保持原样。
- 日记卡片与信息栏显示留言数；搜索也会匹配留言内容；探索页新增“最近的留言”卡片；导出可选“包含留言”。
- 分享文字与长图不带留言。

### 这天的心情
- 在日历上长按某一天，可以记下这天的心情（很糟 / 不太好 / 一般 / 不错 / 超棒），没写日记的日子也能记；日期格整格画成心情色与表情，年视图按心情着色时优先用它。
- 与日记里每篇的心情相互独立，可在日历显示选项里关闭显示。

### 导入
- 榴莲日记：支持导入「导出榴莲日记压缩包」得到的 `.lld` 文件，以及压缩成 ZIP 的导出文件夹；正文、图片、视频、附件、心情、天气、地点、标签与日记本都会带上，追记接在正文末尾。
- 锤子便签：在应用内登录欢喜云后只读导入，登录信息只在本次导入中使用，结束即清除。

### 其他
- 首页日记列表新增快速滚动条：滚动时在右缘出现，按住拖动即可跳到任意月份（按标题排序时为首字母、日记本书序时为章节），日记再多也能快速定位。
- 设置 → 功能管理 新增“侧滑归档”开关，不习惯左滑归档的可以整体关掉。
- 颜色面板的色板加入纯白。

## 优化
- 发表更省一步：在编辑页点“发布”即发表，之后在发布页补的封面、标签、心情、时间胶囊等随改随存，顶栏显示“✓ 日记已发表”，不再弹提示条。
- 侧滑归档只在松手时已越过阈值才生效，不再因为快速一甩误归档；滑动露出的背景按卡片圆角裁切。
- 预览页顶栏的“编辑”始终紧挨“更多”，与“分享”对调位置。
- 列表符号、待办框、代码行号与首行文字精确对齐；标题字号跟随正文字号缩放。
- 调整段间距、标题字号等排版时，已打开的编辑页与设置预览立即生效，不用重新打开。

## 修复
- Android 上导入视频时，部分设备授权失败或返回异常导致闪退。
- PDF 导出把标题与正文里格式不同的文字合并成一样，丢失颜色、粗细、下划线与链接。
- 把带缩进子段落的段落转成标题、引用或代码块后，子段落看不见了；已有的这类日记打开时会自动恢复显示。
- 预览页的文字选区把手慢慢拖动时拖不动；只读正文点按后留下光标。
- 图片调整大小时没有实时预览。

## 说明
- **本版升级数据库（v13 → v16）并改用新的正文格式，升级后请不要降级回旧版本**：旧版本读不出新格式的正文，再编辑可能覆盖内容；本版导出的备份也不能在旧版本中恢复。升级前建议先在 设置 → 数据与隐私 → 数据管理 中做一次完整备份。
- 原有日记无需转换即可正常显示和编辑，保存后以新格式存储。模板码升级为 v2，仍能导入旧的 v1 模板码。
- 默认值调整：新安装时纪念日与留言默认关闭（已经建过纪念日的用户升级后保持开启）；预览页信息栏的字数与阅读时长默认不显示，可在预览页样式的“信息”里打开。
- 背景与材质、探索页布局、这天的心情、留言与日记本嵌套随完整备份导出；用不含这些内容的旧备份恢复时，本机的对应设置保持不变。工具栏大小是本机偏好，不随备份导出。
- 桌面版的安装程序暂未做代码签名，首次运行时 Windows SmartScreen 可能提示“未知发布者”，可用 `SHA256SUMS.txt` 核对文件。
- Android 可直接覆盖安装升级，也可以在 设置 → 关于 → 检查最新版本 中应用内更新。
