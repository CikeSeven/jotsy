# Release v1.0.0

[English](./v1.0.0.en.md) | 简体中文

## 新增
- 思维导图：导图就是一篇日记，可在画布或大纲里编辑，也能嵌进正文；支持导入导出、文字日记转导图，还能让 AI 生成、展开和总结导图。
- Android 桌面小组件：快速记录、今日、待办清单、纪念日、心情月历、那年今日、最近日记、写作统计、照片回忆，样式在小组件工作室里调整。
- 查找与替换：编辑时可查找替换正文（支持正则），预览页和搜索结果里也能查找。
- 导出为 EPUB 电子书。
- 留言支持粗体等格式，可以插入日记、日记本和网址链接。
- 支持 Obsidian 的 [[ ]] 双链：导入时转成日记链接，正文里输入 [[ 即可插入链接。
- 熄屏或切到后台时继续录音；导入的音频在正文里直接播放。
- 视频可以显示为小图、调整大小，全屏播放页改版，可双指放大。
- 探索页媒体画廊按日期分组，双指切换列数，可按日记本和时间筛选。
- 日记卡片可以显示所属日记本（在卡片样式中打开），也可以不用正文第一张图当封面。
- AI 助手可以管理日记模板。

## 优化
- 导航栏统一为悬浮玻璃胶囊，可调圆角和导航项；首页 Tab 固定为日记、待办、日历、探索。
- 设置、草稿箱和归档收进日记页的“更多”菜单。
- 弹出菜单改版：更紧凑，按住可以滑动选择。
- 日记卡片展开成预览页、返回时缩回卡片；切换 Tab 和标签时有方向感的过渡。
- 首页左右切页、探索页和玻璃材质下的滚动更流畅。
- 预览页与编辑页的顶栏按钮位置固定，“更多”改为弹出菜单。
- 待办优先级用醒目的颜色标出，默认按优先级排序。
- 全局搜索也能搜到“不在全部日记中显示”的日记本里的日记。
- 各处选日记本的列表都能收起和展开子本。
- 存储管理里未使用的文件可以立即清理，也能逐个查看和删除。
- 取消缩进可以只为这一段取消全局首行缩进。

## 修复
- PDF 里的 emoji 印成方框。
- 开启同步设置后，导入的字体被改回鸿蒙字体。
- 手动填写的天气在日记卡片上不显示图标。
- 日记本目录里没写标题的日记不显示正文第一行。
- 退出段落选择后回车无法换行；桌面上点行首会误入段落选择。
- 看图时双指捏合会误触翻页或关闭。
- 待办提醒不能选今天之后的日期；计划视图里新建的待办看不到。

## 注意
- 局域网同步需要两台设备都升级到这个版本。
- 用旧版本恢复这一版的备份时，留言的格式会丢失，思维导图无法显示。
