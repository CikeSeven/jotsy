# Release v1.1.0

English | [简体中文](./v1.1.0.md)

## New
- Notebook swipe deck: swipe right on the home diary list (or tap the notebook chip) to pull out a floating deck right where you invoke it, replacing the bookshelf sheet. Drag to switch, expand sub-notebooks, long-press for actions, and swipe left to dismiss.
- Floating island top bar: preview, reading editor, new diary, mind map, and sealed pages now share a floating top bar over a fading status bar strip. The islands stay fixed while swiping between diaries, and mind map pages move the Canvas/Outline switch into a center island that hides on gesture.
- AI assistant can edit diary bodies directly: fix typos, polish text, add or remove paragraphs, and adjust formatting with undo support, replacing the append-only tool.
- Long-press and drag to reorder side-by-side photo thumbnails in the diary and template editors.
- Mind map outline upgrades: follows body typography settings, adds node font size controls and a long-press / right-click node menu, and separates Canvas and Outline exports with new PDF, Word, HTML, and plain text exports for outlines.
- Custom mood symbols and mood colors now sync over LAN and are included in backups and restores.

## Improvements
- Settings returns to the end of the navigation bar with compact items; you can choose between the navigation bar or the Diaries "More" menu in Navigation Bar Style → Behavior.
- Drafts moves back to the Diaries top bar beside the AI assistant with a count badge.
- Waterfall is now the default home layout (users who already chose List stay on List, and you can switch back in More → Layout).
- New diaries expand from the create button and land in the drafts badge or the new list card on return; cards smoothly make room when list data changes.
- Date pickers now go back to 1900 across the calendar, publish date, export, and AI recap ranges.
- Exported comment moods now appear at the start of the metadata line instead of inline with the comment text.

## Fixes
- Switching away from the app and back while editing no longer shifts the diary scroll position.
- Mind map outline editing now clears the keyboard and accessory bar, and tapping a line no longer jumps to the top.
- Calendar cell badges now stay inside the cell corners on narrow screens and larger font sizes.
- Tables containing `jotsy://` diary links stay as tables when importing or pasting Markdown or HTML.
- Home tab headers stay left-aligned on wide windows instead of jumping horizontally when switching tabs.
- Removed a faint seam along the top bar fade edge and restored glass blur on floating islands over the status bar fade strip.

## Notes
- LAN sync requires both devices to be on this version due to the mood symbol and color sync update.
- Users who have never changed the home layout will default to Waterfall after updating; switch back anytime in More → Layout.
