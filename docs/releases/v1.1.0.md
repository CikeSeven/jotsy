# Release v1.1.0

[English](./v1.1.0.en.md) | 简体中文

## 新增
- 日记本卡组：在首页列表右滑（或点按日记本切换胶囊）即可在唤出位置拉出悬浮卡组，取代原书架面板；支持拖选切换、展开子本与长按菜单，左滑跟手收起。
- 浮岛顶栏：预览页、阅读式编辑页、新建页、思维导图页与封存页统一改为浮岛顶栏与状态栏渐隐带；左右翻页时浮岛固定在页面之上，导图页顶栏中间改为「画布 / 大纲」切换岛并随手势自动收起。
- AI 助手可直接编辑日记正文：智能体支持直接修改文字、润色、增删段落与调整格式并可撤销，取代原先只能末尾追加的方式。
- 并排小图支持长按拖动排序（编辑页与模板编辑器）。
- 思维导图大纲增强：跟随正文排版设置，支持调整主题字号与长按/右键主题菜单；导出区分画布与大纲两类，大纲新增导出 PDF、Word、网页与纯文本。
- 自定义心情符号与心情颜色支持局域网同步，并随备份导出和恢复。

## 优化
- 设置默认放回导航栏末尾并收小导航项，同时可在「导航栏样式 → 行为」中自选把设置放在导航栏或日记页「更多」菜单。
- 草稿箱入口移回日记页顶栏，紧挨 AI 助手右侧并显示份数角标。
- 首页默认显示布局改为瀑布流（已选过列表的用户保持不变，可在「更多 → 显示布局」切回）。
- 新建日记从按钮原地展开，返回时按结果收进草稿箱角标或落进列表新卡片；列表数据变化时卡片平滑让位。
- 日期选择范围统一放宽到 1900 年（日历、发表时间、导出与 AI 回顾范围）。
- 导出日记时，留言心情移到说明行开头，不再混入留言正文第一行。

## 修复
- 编辑日记时切到其他应用再返回，正文滚动位置跳动。
- 思维导图大纲编辑时被键盘与附件条遮挡，以及点击某一行时页面跳到顶部。
- 窄屏或大字号下，日历日期格与心情格的角标超出圆角边界。
- 导入或粘贴 Markdown / HTML 时，表格单元格内包含日记链接导致表格退化为纯文本。
- 宽窗口下切换首页各 Tab 时，页头标题随内容列宽度左右跳动。
- 渐隐顶栏分界处出现细线，以及玻璃材质下状态栏渐隐带过透与浮岛失去模糊质感。

## 注意
- 局域网同步新增心情符号与颜色同步（格式升级），需要两台设备都升级到这个版本。
- 此前未手动改过首页布局的用户升级后将默认变为瀑布流，可在日记页「更多 → 显示布局」切回列表。
