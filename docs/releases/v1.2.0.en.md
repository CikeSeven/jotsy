# Release v1.2.0

English | [简体中文](./v1.2.0.md)

## New
- Custom desktop data storage location: On Windows, Linux, and macOS, open Settings → Storage → Data storage location to migrate your diary database, media, backgrounds, and imported fonts to a custom folder (or switch to an existing Jotsy data folder) or reset to default. The Windows installer wizard adds a data folder step (with `/DATADIR=` for silent installs), and portable builds support a `jotsy_data_location.json` file next to the executable.
- To-dos integrated into the calendar day timeline: To-dos and diaries for the selected day share one timeline (all-day to-dos first, timed to-dos interleaved by due time, with "Add a to-do" even on empty days). On Today, earlier unfinished to-dos appear in an Overdue group above the timeline with "Move all to today".
- Media deduplication: Identical photos, videos, attachments, imported audio, and covers are stored once and reused automatically on insert or import, saving space and redundant sync transfers. Settings → Storage → Duplicate files lets you review and merge existing duplicates group by group or all at once.
- CJK–Latin auto spacing (Pangu spacing): Turn it on in Settings → Editor → Body font & layout (with live preview) to add visual spacing between CJK characters and Latin letters or numbers without modifying stored text—covering diary bodies, titles, cards, and HTML, EPUB, Word, and PDF exports.
- Direct chapter picking, transfers, and multi-select for notebooks:
  - Pick a target chapter (or No chapter) right when adding or moving entries into a manual notebook; the details panel also shows and switches "Notebook · Chapter".
  - From a notebook's contents page, transfer the entire contents or a single chapter to a parent or sub-notebook in the same tree (including creating a new sub-notebook in the picker), keeping order and supporting undo.
  - Multi-select in notebook contents supports per-chapter select all / deselect all checkboxes, and long-pressing a chapter header or entry row enters multi-select directly.
- Two new editor behavior switches in Settings → Editor → Behavior (also configurable via the AI assistant): Insert images & videos as thumbnails by default, and Expand details on publish page automatically for new diaries.
- AI assistant notebook chapter tools: The assistant can create, rename, reorder, and delete notebook chapters (with confirmation and undo) and move entries between chapters.
- Balanced mind maps support "Add left" and "Add right" when the central topic is selected, pinning existing branches to their current sides when adding or dragging to a specific side.
- Desktop Drafts page adds a top-bar "Select" button, `Ctrl`/`⌘` and `Shift` modifier selection, and a row right-click menu ("Continue writing" / "Delete"), replacing swipe-to-delete on desktop.

## Improvements
- Redesigned calendar header and tighter layout: Merges the month title into the standard single-line header (tap to enter year view; wide windows and desktop show month arrows in the header, while mobile swipes the grid) and tightens card padding to reveal more of the day below.
- Pressing Enter on the mobile soft keyboard in a mind map outline now adds a sibling topic (or child topic from the central topic) and keeps typing without dismissing the keyboard, scrolling long outlines automatically.
- Fixed the "All" chapter chip count on the home diary list to include sub-notebook entries consistently with the list view.

## Fixes
- Soft line breaks inside blocks (such as desktop `Shift + Enter` or imported notes) stay within the same block on export, preventing broken numbering and duplicate markers in EPUB, PDF, Word, HTML, Markdown, and plain text.
- Fixed the calendar day timeline rail breaking into disconnected segments when diary cards are tall.
- Fixed duplicate cards briefly appearing in the list during container-transform open/close transitions and eliminated shadow pop at the start of expansion and end of collapse.
- Tapping a web link while editing now selects the full link span and opens the app's own link dialog instead of an upstream overlay that could overflow narrow screens (double-tap or `Ctrl`/`⌘` + click still opens the URL, and `Ctrl`/`⌘` + `K` uses the same dialog).
- Fixed external links in diary bodies silently failing to open on Android 11+ by adding package queries and falling back cleanly to copying the link.
- Improved to-do reminder reliability with automatic retry on scheduling failures, rescheduling future alarms on Android cold start, preserving pending snoozed notifications, and scheduling upcoming overdue repeating reminders.
- LAN sync now updates a paired peer's host and port from incoming connections, so initiating a sync still reaches a peer whose IP changed even when broadcast beacons are blocked.

## Notes
- Database schema and LAN sync protocol remain compatible with v1.1.0; Pangu spacing and the new editor switches are safely ignored by older versions.
- After merging duplicate files in Storage, deleting the kept copy later removes it from every entry, cover, and comment that references it.
- Changing the desktop data folder moves diaries, media, backgrounds, and imported fonts; app preferences, passcodes, and the location pointer stay in the system config directory. The Windows installer keeps the same AppId for seamless in-place upgrades.
