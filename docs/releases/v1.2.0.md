# Release v1.2.0

[English](./v1.2.0.en.md) | 简体中文

## 新增
- 桌面端自定义数据存储位置：Windows、Linux 与 macOS 可在「设置 → 存储管理 → 数据存储位置」将日记数据库、媒体、背景与导入字体等迁移到自定义文件夹（或切换到已有数据目录），并支持恢复默认位置；Windows 安装向导新增数据存储目录选择（静默安装支持 `/DATADIR=`），便携版支持同目录 `jotsy_data_location.json` 配置。
- 选中日待办并入日历时间线：日历页的日记与待办排进同一条时间线（全天待办在前，定时待办按截止时刻穿插，空的一天也能直接「添加待办」）；选中今天时，之前未完成的待办会以「已逾期」列在时间线之上并支持「全部改到今天」。
- 重复媒体只存一份：插入或导入图片、视频、附件、音频与封面时自动复用存储中完全相同的文件，节省空间并减少同步重复传输；「设置 → 存储管理 → 重复的文件」支持查看并逐组或全部合并旧有重复文件。
- 盘古之白渲染间距：在「设置 → 编辑器 → 正文字体与排版」开启「盘古之白」（支持实时预览）后，可在不改动原文的前提下于中西文与数字之间自动留出渲染间距，覆盖正文、标题、日记卡片及网页、EPUB、Word、PDF 导出。
- 日记本章节直选、转移与快速多选：
  - 收进或移动日记到手动日记本时，可直接指定目标章节或「未分组」，底部信息面板也会同步展示并支持切换「日记本 · 章节」。
  - 日记本目录页支持将整份目录或单个章节转移到同一棵树下的上级或子日记本（可在面板内直接新建子本，保留顺序并支持撤销）。
  - 目录页多选模式支持按章节一键全选或取消全选，普通模式下长按章节标题或日记行即可直接进入多选。
- 编辑器新增两项偏好：在「设置 → 编辑器 → 编辑行为」新增「插入图片和视频时默认小图」与「发布时自动展开详细信息」（AI 助手也可直接调整这两项设置）。
- AI 助手接入日记本章节工具：可直接创建、重命名、重排或删除日记本章节（删除需确认且可撤销），并调整日记所属章节。
- 思维导图（平衡结构）选中中心主题时，可指定「向左添加」或「向右添加」分支；指定一侧添加或拖动后，已有分支固定在当前一侧不再左右跳换。
- 桌面草稿箱顶栏新增「多选」按钮，支持点击多选、`Ctrl` / `⌘` 或 `Shift` + 点按多选，以及草稿行右键菜单（继续写 / 删除）。

## 优化
- 日历页改版：页头合并为与其他首页标签统一的单行月份标题（点击切年视图，宽窗口与桌面将翻月箭头放进页头，手机左右滑网格翻月），并收紧日历卡片留白以留出更多首屏空间。
- 思维导图大纲在手机上按软键盘回车可直接添加同级主题（中心主题则添加子主题）并接着输入，键盘不再收起；长列表会自动滚到新行。
- 修正存在子日记本时，首页章节筛选中「全部」胶囊显示的日记篇数口径（与列表汇总保持一致）。

## 修复
- 块内软换行（如桌面 `Shift + Enter` 或导入笔记中的换行）留在同一块内导出，编号列表、待办、折叠列表与标注在 EPUB、PDF、Word、网页、Markdown 与纯文本中不再序号错乱或重复。
- 修复日历选中日时间线卡片较高时，条目之间的竖线断开的问题。
- 修复日记卡片展开进入预览或收回时，原位置同时出现两张卡片，以及展开开头与收回末尾卡片投影跳变的问题。
- 修复编辑态点击正文网址链接时弹出可能超出屏幕的上游浮层，改为选中整段链接并打开应用自身的链接对话框（双击或 `Ctrl` / `⌘` + 点击仍打开网址，`Ctrl` / `⌘` + `K` 统一使用应用对话框）。
- 修复部分 Android 11+ 设备点按正文外部链接打不开的问题（补齐包可见性声明；打不开时稳定回落为复制链接并提示）。
- 修复待办提醒漏发问题（排程失败自动重试、Android 冷启动恢复未来闹钟、保留队列中尚未投递的延迟提醒，并补齐逾期重复待办后续排程）。
- 修复局域网同步中对方设备更换 IP 且收不到广播信标后本机发起同步连不上的问题（对方连进来握手后更新其最新地址与端口）。

## 注意
- 本版不升级数据库与局域网同步协议，盘古之白与新增编辑偏好在旧版中会自动忽略，局域网同步与备份均可与 v1.1.0 互通。
- 在「存储管理 → 重复的文件」完成合并后，之后再删除被保留的那份文件，会从所有用到它的日记、封面或留言中一并移除。
- 桌面端迁移或自定义数据存储位置后，应用偏好、应用密码与位置索引仍保留在系统默认配置目录中；Windows 安装程序保持原 AppId，可直接覆盖升级。
