# AI 助手

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.29；接口、数据与提示词见 `docs/ai_assistant.md`。

- 必须：AI 助手（设置 → AI 助手，功能管理里默认关闭；接口、数据与提示词见 `docs/ai_assistant.md`，界面见 DESIGN.md §5.29）用用户自己配置的服务。**只在用户操作时联网**：每个请求都由一次点按触发，唯一的自动行为“发表后自动回应”默认关闭，开启后也只发给已确认过的主机且确认方式不是“每次”；发请求前一律经 `confirmAiSend`（`ai_privacy_gate.dart`）按隐私设置确认，禁止绕过。入口只看 `aiAvailableProvider`（开关开启且至少一个可用的服务商与模型）再叠加各自模块的 `aiModuleAvailableProvider`（主页入口为 `aiHubAvailableProvider`），没配好服务时不放点了只会报错的入口；新增 AI 入口同样如此，并补“关闭 / 未配置时不出现”的测试。协议只经 `AiChatClient`（`lib/core/services/ai/`，OpenAI 兼容 Chat / OpenAI Responses / Anthropic / Gemini，新增协议只加 `ai_client_<协议>.dart`），请求只经 `AiService`（解析任务模型、首个块之前才重试、记用量；模型的图片与思考默认开启，首块之前收到 400 时依次去掉图片、思考再试，被拒过的模型在本次运行内记住——禁止改回按模型名猜测能力），HTTP 只用 `dart:io`，禁止为 AI 引入第三方 SDK；新增服务商只在 `ai_provider_presets.dart` 加预设，预设不带模型（新建后由用户获取模型列表），不用任何品牌图标。AI 页面与面板经 `AiTapOutsideUnfocus` 让点输入框以外的地方取消焦点（手机默认不取消，收起键盘后再打开面板会把键盘带回来），希望点了不收键盘的按钮用 `TextFieldTapRegion` 包住。服务商配置（含密钥）、已确认的主机与用量只存于 `AiProviderStore`（SharedPreferences `app.ai.providers` / `app.ai.usage`，**不随备份、不同步**），偏好只存于 `AiPreferences`（单个 JSON 键 `app.settings.ai_prefs`，备份字段 `aiPrefsRaw`，稀疏写入、逐字段容错、与默认相同时删除键，不含任何密钥），禁止另加零散的 AI 设置键。**私密**：多篇上下文只经 `getAiContextDiaries`（在范围过滤之外总是再加 `_privateDiaryExclusionSql`，并排除回收站与未解封的时间胶囊、用户在 AI 隐私里排除的日记本与标签），禁止页面或流程自行拼日记查询喂给 AI；单篇功能（写作、智能填写、回应、图片描述）经 `aiDiaryAllowed`，私密日记只在用户打开“允许对私密日记使用 AI”时可用。提示词文本只在 ARB（`aiPrompt*`，经 `AiPromptKit` 按回答语言选 l10n），禁止在代码里写死提示词。正文写回只经 `diary_ai_editing.dart`（一次事务、一步撤销；代码块与表格格子只写原文），写作面板是编辑页自己的浮层（会话由编辑页持有，键盘收起时生成不中断），禁止放进工具栏卡片。AI 生成的内容只存 Drift `ai_conversations` / `ai_messages` / `ai_results`（schema v17，业务 id、不建外键），读写只经 `_AppDatabaseAiOps`；彻底删除日记在同一事务里删它的回应；随完整备份导出与覆盖恢复，合并按业务 id（本机没有的新增，合并保留本机、合并并覆盖替换），日记包不带，不参与局域网同步。引用一律写作 `[Dn]`（每次请求内从 D1 编号），显示前经 `aiNormalizeCitations` 拆开合写的引用，复制 / 分享 / 另存为日记经 `aiStripCitations` 去掉；点按引用经 `openDiaryLinkTarget`。另存为日记只经 `saveAiTextAsDiary`（写一份草稿后打开新建编辑页），禁止直接写日记表。生成中一律可停止，状态只经 `AiStreamRun`；提示条与弹窗同其他模块的统一入口。
