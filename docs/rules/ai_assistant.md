# AI 助手

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.29；接口、数据与提示词见 `docs/ai_assistant.md`。

- 必须：AI 助手（设置 → AI 助手，功能管理里默认关闭；接口、数据与提示词见 `docs/ai_assistant.md`，界面见 DESIGN.md §5.29）用用户自己配置的服务。**只在用户操作时联网**：每个请求都由一次点按触发，唯一的自动行为“发表后自动回应”默认关闭，开启后也只发给已确认过的主机且确认方式不是“每次”；发请求前一律经 `confirmAiSend`（`ai_privacy_gate.dart`）按隐私设置确认，禁止绕过。入口只看 `aiAvailableProvider`（开关开启且至少一个可用的服务商与模型）再叠加各自模块的 `aiModuleAvailableProvider`（主页入口为 `aiHubAvailableProvider`），没配好服务时不放点了只会报错的入口；新增 AI 入口同样如此，并补“关闭 / 未配置时不出现”的测试。协议只经 `AiChatClient`（`lib/core/services/ai/`，OpenAI 兼容 Chat / OpenAI Responses / Anthropic / Gemini，新增协议只加 `ai_client_<协议>.dart`，并同样实现工具定义、调用拼接（共用 `AiToolCallAssembler`）、结果回传与回放数据，见 `docs/ai_assistant.md` §3），请求只经 `AiService`（解析任务模型、首个块之前才重试、记用量；模型的图片与思考默认开启，首块之前收到 400 时依次去掉图片、思考再试，仍被拒且带着工具时记为不支持工具并照常报错（禁止悄悄去掉工具重发），被拒过的模型在本次运行内记住——禁止改回按模型名猜测能力；工具调用只在 `AiFinishReason.isComplete` 时才能执行，参数不是 JSON 对象的调用把错误回传模型而不执行），HTTP 只用 `dart:io`，禁止为 AI 引入第三方 SDK；新增服务商只在 `ai_provider_presets.dart` 加预设，预设不带模型（新建后由用户获取模型列表），不用任何品牌图标。AI 页面与面板经 `AiTapOutsideUnfocus` 让点输入框以外的地方取消焦点（手机默认不取消，收起键盘后再打开面板会把键盘带回来），希望点了不收键盘的按钮用 `TextFieldTapRegion` 包住。服务商配置（含密钥）、已确认的主机与用量只存于 `AiProviderStore`（SharedPreferences `app.ai.providers` / `app.ai.usage`，**不随备份、不同步**），偏好只存于 `AiPreferences`（单个 JSON 键 `app.settings.ai_prefs`，备份字段 `aiPrefsRaw`，稀疏写入、逐字段容错、与默认相同时删除键，不含任何密钥），禁止另加零散的 AI 设置键。**私密**：多篇上下文只经 `getAiContextDiaries`（在范围过滤之外总是再加 `_privateDiaryExclusionSql`，并排除回收站与未解封的时间胶囊、用户在 AI 隐私里排除的日记本与标签），禁止页面或流程自行拼日记查询喂给 AI；单篇功能（写作、智能填写、回应、图片描述）经 `aiDiaryAllowed`，私密日记只在用户打开“允许对私密日记使用 AI”时可用。提示词文本只在 ARB（`aiPrompt*`，经 `AiPromptKit` 按回答语言选 l10n），禁止在代码里写死提示词。正文写回只经 `diary_ai_editing.dart`（一次事务、一步撤销；代码块与表格格子只写原文），写作面板是编辑页自己的浮层（会话由编辑页持有，键盘收起时生成不中断），禁止放进工具栏卡片。AI 生成的内容只存 Drift `ai_conversations` / `ai_messages` / `ai_results`（schema v17，业务 id、不建外键），读写只经 `_AppDatabaseAiOps`；彻底删除日记在同一事务里删它的回应；随完整备份导出与覆盖恢复，合并按业务 id（本机没有的新增，合并保留本机、合并并覆盖替换），日记包不带，不参与局域网同步。引用一律写作 `[Dn]`（每次请求内从 D1 编号），显示前经 `aiNormalizeCitations` 拆开合写的引用，复制 / 分享 / 另存为日记经 `aiStripCitations` 去掉；点按引用经 `openDiaryLinkTarget`。另存为日记只经 `saveAiTextAsDiary`（写一份草稿后打开新建编辑页），禁止直接写日记表；例外是智能体的 `create_diary`，只经 `publishNewDiaryDirectly`（与“返回时直接发表”同一路径），写完可撤销。生成中一律可停止，状态只经 `AiStreamRun`；提示条与弹窗同其他模块的统一入口。
- 必须：智能体（对话模块的“让 AI 使用工具”，口径见 `docs/ai_assistant.md` §9）的工具只登记在 `lib/ui/ai/tools/ai_tool_registry.dart`，每个工具继承 `AiTool`，读写只经现有的 DB ops / 控制器（禁止另写 SQL），多篇日记只经 `getAiContextDiaries`，读全文时私密日记一律不给（比单篇功能更严），摘录与正文字数计入本轮的 `AiWordAllowance`；功能关闭或平台没有的能力经 `isAvailable` 不出现。参数只经工具的 `AiObjectSchema` 集中校验与转换（只用四家共同支持的子集）。工具名、说明与参数 schema 是英文接口定义、不进 ARB（“提示词只在 ARB”的例外），说明只写作用、参数含义与必要限制；卡片标题与结果说明走 l10n。工具不持有 BuildContext：打开页面只返回 `AiToolNavigation`，经 `ai_destinations.dart` 的 `AiDestination`（复用统一入口与 `homeTabRequestProvider`）打开。只有协议正常收尾才执行调用，同一步串行执行，失败作为错误结果回传模型、不自动重试；步骤边做边落库到 `ai_messages.steps`（v20），executing 且不在进行中的按“已中断”显示，禁止重放。历史只回传最终回答与本地生成的操作摘要，禁止回放旧轮的工具消息与签名。智能体的发送前确认每轮最多一次（`AiSendSummary.agent`）。新增功能必须评估要不要接入工具与前往页面，并补“功能关闭时不出现”的测试（`test/ui/ai/ai_tools_test.dart` 兜底名称、schema 与标题）。
- 必须：智能体的改动类工具（`AiToolEffect.write` / `destructive`）一律可撤销：`run` 返回撤销数据（JSON，存进步骤记录），`undo` 按它写回；改日记的撤销前按 `aiDiaryFingerprint` 核对之后有没有被改过，改过就抛 `AiUndoConflict` 由界面问过再强制（`undoAiAgentCalls`，从后往前撤）。新写工具必须加进 `test/ui/ai/ai_write_tools_test.dart` 的清单并补“执行再撤销”的往返测试。删除类执行前必须在对话里确认（`preview` 列出要删的内容，拒绝时回传“不要换别的方式达成同样效果”）；AI 设置的“每次改动前确认”打开时写操作也确认，“允许 AI 改动数据”关掉时改动类工具不出现。`EditingSessionRegistry` 有编辑页时改动类工具不执行（编辑页整份保存会盖掉），执行期间登记为编辑会话。写日记只经 `aiWritableDiary`（私密、回收站、未解封胶囊、AI 隐私排除的日记一律不写），批量里有一篇不能写就整批不做；日记本只动手动、非私密（含继承）的本子；删除 / 合并标签同时经 `forgetDeletedTags` 清理设置里记着它的地方。写库后一次性 provider 手动失效（`aiRefreshDiaries` / `aiRefreshTags`）。智能体的 `add_comment` 直接写、可撤销（回应卡片的“存为留言”仍预填面板由用户确认）。禁止：为智能体提供彻底删除与清空回收站、备份 / 恢复 / 导入 / 导出 / 分享、网盘、局域网同步配对、应用锁与密码、私密与上锁日记本的设置、AI 服务商与密钥、存储清理、关闭 AI 助手本身的工具——这些只经 `open_page` 给“前往”按钮，由用户在原页面完成。
