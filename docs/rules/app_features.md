# 功能管理开关

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.3。

- 必须：功能管理（设置 → 功能管理，`AppFeaturesPage`）的开关只存于 `AppFeatures`（单个 JSON 设置键 `app.settings.app_features`，逐字段容错，随备份导出与失败回滚），经 `appFeaturesProvider` 读取、`saveAppFeatures` 写入，禁止另加零散的功能开关设置键。可关闭的有日历 Tab、待办 Tab（见 `todos.md`）、探索 Tab（日记始终保留；设置不是 Tab，只经日记 Tab 顶栏“更多 → 设置”推入 `openSettingsPage`，该菜单项不受任何开关影响，是重新打开功能的入口）、日记本、纪念日、日记模板、时间胶囊、留言、AI 助手、侧滑归档（只在手机上有这个手势，桌面不显示该开关），待办、纪念日、留言与 AI 助手默认关闭、其余默认开启；在功能管理里保存过就整份落盘（`AppFeatures.encode` 不省略默认值），没有这个键只表示从没保存过：纪念日改为默认关闭前的老用户只经 `keepLegacyAnniversariesVisible`（冷启动与导入备份写库后各一次）在库里已有纪念日时写入纪念日开启，禁止另加迁移标记键；关闭只隐藏该功能在应用里的全部入口、选项与自动行为，数据一律保留，重新开启即恢复。首页底栏由 `visibleHomeTabs` 按开关生成：日记排在中间，其余开启的 Tab 按日历 → 待办 → 探索的相对顺序分在两侧，共偶数个时日记居中偏左（四个时依次为日历、日记、待办、探索，两个时日记在最左），启动时按身份落在日记页（待办、日历、探索全关时只剩日记，窄窗口不显示底栏、新建入口回到全局 FAB），当前页、FAB 与返回键一律按 `HomeTab` 身份判断，禁止再按固定下标；可见集合变化时保持当前 Tab（它被关闭时回到日记），被关闭 Tab 的页面随之销毁。纪念日依附日历：界面只读 `anniversariesEnabled`（`calendar && anniversaries`），日历关闭时一并关闭；功能管理页里纪念日开关放在日历下方，只在日历开启时显示。日记本关闭时：私密日记本中的日记继续被统一谓词排除（禁止为此放回全局列表），有私密本子时关闭前须先确认；首页停在某本时经页面自己的范围控制器回到全部日记（不 `popUntil`、不提示已删除）；导入其他应用时来源文件夹按标签落地；发布新日记不写草稿里的日记本成员。时间胶囊关闭时发布忽略草稿与模板预设里的胶囊，已有胶囊照常显示与解封；模板关闭时不显示建议条、不自动套用（含日记本默认模板）；侧滑归档关闭时日记列表与归档页不传 `DiariesListSection.onArchiveDiary`（卡片不再左滑归档 / 取消归档，多选与预览页照常），草稿箱的左滑删除不受影响。新增可关闭的功能必须在 `AppFeatures` 登记并在功能管理页加开关，隐藏它在所有模块里的入口、设置项与自动行为，并补“关闭时入口不出现、开启时照常”的测试。视觉规范见 DESIGN.md §5.3。
