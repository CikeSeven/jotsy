# 功能管理开关

> 专题约束，与 AGENTS.md 同等效力；改动本主题前先读本文件，新规则写在这里。界面规格见 DESIGN.md §5.3。

- 必须：开关只存单个 JSON 键 `app.settings.app_features`，随备份导出、导入失败回滚；经 `appFeaturesProvider` 读取、`saveAppFeatures` 写入。
- 必须：可关闭的有日历 / 待办 / 探索 Tab、日记本、纪念日、日记模板、时间胶囊、留言、AI 助手、思维导图、侧滑归档（只在手机）；日记与设置 Tab 始终保留。
- 必须：待办、纪念日、留言、AI 助手默认关闭，其余默认开启；保存时整份落盘、不省略默认值。
- 必须：老用户的纪念日只经 `keepLegacyAnniversariesVisible`（库里已有纪念日时写入开启），禁止另加迁移标记键。
- 必须：底栏顺序固定为日记、待办、日历、探索、设置，关闭的直接去掉；当前 Tab 被关时回到日记。
- 必须：纪念日依附日历，界面只读 `anniversariesEnabled`，日历关闭时一并关闭。
- 必须：日记本关闭时私密本中的日记仍被排除，有私密本时须先确认；首页停在某本时回到全部日记；导入的来源文件夹按标签落地；发布不写草稿里的本子成员。
- 必须：时间胶囊关闭时发布忽略草稿与模板里的胶囊，已有胶囊照常解封；模板关闭时不显示建议条、不自动套用（含日记本默认模板）。
- 必须：思维导图关闭只隐藏创建入口，已有导图照常显示与编辑；侧滑归档关闭不影响草稿箱的左滑删除。
