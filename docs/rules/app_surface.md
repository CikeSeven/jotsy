# 背景与材质（玻璃）

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.23。

- 必须：背景与材质（设置 → 外观 → 背景与材质，`AppSurfacePage`，修改经 `AppSurfaceEditorController`）统一收在 `AppSurfaceSettings`（单个 JSON 设置键 `app.settings.app_surface`，备份字段 `appSurfaceRaw`，逐字段容错解析，随完整备份导出、只在备份里有该字段时恢复、导入失败回滚），经 `lib/ui/app_surface/providers/` 读取，禁止另加零散的背景或材质设置键。背景分全局与 7 个区域 `AppBackgroundArea`（diaries / calendar / explore / settings / editor / preview / other），每个区域跟随全局 / 不显示 / 单独设置（`AppAreaBackgroundMode`）。单独设置的图片背景可选一个跟随来源（`AppAreaBackground.source`：全局或另一个区域，`AppBackgroundSource`），“图片”与“参数”（焦点、模糊、浅色 / 深色遮罩，只能整块跟随，禁止逐项）两块各自开关跟随（`followImage` / `followParams`），取来源当前显示的值、自己的那一份原样保留；生效值只经 `AppSurfaceSettings.backgroundFor` / `resolvedCustom` 解析（成环时退回自己的值），可选的来源只经 `canFollow`（按保存的来源链判断，不论那些区域此刻是否单独设置、是否开着跟随），禁止页面自行沿来源链取值。预览页只在纸张为跟随主题时让位给背景（`diaryPreviewPageColors`）；预览页样式开了“背景遮罩随基调染色”（`DiaryPreviewPageStyle.tintScrim`，生效条件只看 `tintsBackgroundScrim`）时，预览页的背景经 `AppPageBackground(deferScrim: true)` 不画遮罩、把它交给页面（`AppPageBackdrop.deferredScrim`，页面底色同时换成它），每篇的 Scaffold 经 `diaryPreviewScaffoldColor` 按 `DiaryPreviewResolvedStyle.scrimTint` 画染色的遮罩（不透明度沿用背景设置，随页面滑动），禁止另画一层叠在背景遮罩上。背景图只经 `AppBackgroundStorageService` 拷贝进托管目录 `app_backgrounds/`，设置只存文件名；目录登记在 `backupSettingsMediaDirectories`（覆盖恢复只在备份含 `appSurfaceRaw` 时换入），禁止加进 `backupMediaDirectories`（会被日记媒体回收误删）。
- 必须：新增有 Scaffold 的页面一律经 `AppPageBackground(area:)` 画背景（首页 Tab 经 `AppPagedBackground` / `AppAreaBackdrop`），页面底色与实色栏底色只取 `AppPageBackdrop`（`pageColor` / `solidBarColor`，对比度兜底用 `estimatedColor`），禁止把 Scaffold 底色写死为主题 surface（`test/ui/app_surface/app_surface_source_test.dart` 兜底）；直接落在背景图上的文字（没有卡片或栏垫底）经 `AppPageBackdrop.onBackgroundTextStyle` 保证可读。会影响布局的判断（间距、占位）只看 `AppPageBackdrop.wantsBackground`（按设置判断，与解码进度无关），禁止用 `hasBackground`（图片解码完成那一刻才变 true，内容会跳动）；颜色类判断照旧看 `hasBackground`。首页 Tab 顶栏与第一块内容的间距统一为 `kHomeTopContentGap`（12）：日记 Tab 经 `HomeTopBarSurface.contentGapOf`（首页之下顶栏恒为玻璃，恒为 12；不在首页之下单独使用时，该区域要画背景为 12，否则为 0），日历 / 探索本就固定留 12；不在首页之下的实色顶栏且区域有背景时，状态栏那一条经 `HomeStatusBarFill`（颜色取 `HomeStatusBarFill.colorOf`）垫成实色栏底色；禁止各 Tab 自行加间距或垫色。样式编辑页（卡片、导航栏、预览页、代码块）的实时预览经 `StyleEditorScaffold(previewArea:)` 指定所模拟的区域（卡片 / 导航栏 → diaries，预览页 → preview，代码块 → editor），预览在自己的明暗主题之内经 `StylePreviewBackground` 画该区域的背景，禁止预览另画或读设置页自己的背景。默认（无背景、全部经典）必须与改版前逐像素一致。
- 必须：组件材质（`AppGlassStyle`：经典 / 玻璃整体开关 + 六类组件 `AppGlassComponent`（topBars / toolbar / sheets / dialogs / cards / controls）的覆盖，及模糊、不透明度、底色、描边）只经 `AppGlass.of(context)`（`AppGlassScope` 挂在 `MaterialApp.builder`）判断与解析，玻璃只经 `AppGlassSurface`、卡片与分组经 `AppCardSurface`、FAB 经 `AppGlassFab`、输入框填充经 `AppGlassField` / `OnGlass` 绘制，底层都是 `GlassSurface`（`lib/ui/widgets/glass/`）；小控件一律跟随“控件”材质、不模糊：主题自带底色的 Chip、输入框与开关未选中的轨道只经 `AppGlassControlsTheme`（挂在 `MaterialApp.builder`）换成玻璃底色与描边，色调按钮（`FilledButton.tonal` / `.tonalIcon` / `IconButton.filledTonal`）必须传 `style: AppGlassField.tonalButtonStyle(context)`（已有 style 时 merge；`app_surface_source_test.dart` 兜底），自行指定底色的胶囊、格子、按钮组段落与输入框经 `AppGlassField.of` 取未选中态的底色与描边（选中态保持强调色），玻璃卡片与面板里的行与凹槽经 `OnGlass.wellColor`；禁止各处自拼 `BackdropFilter` 或另写磨砂配方（例外：日记卡片的玻璃只经 `DiarySelectionSurface`，在半透明卡片底下垫共用 `contentBackdropKey` 的模糊层；对话框的整页磨砂只在 `app_dialog.dart`）。模糊策略经 `AppGlassBlur`：内容玻璃（卡片、分组、二级页顶栏）为 auto，共用页面的 `AppPageBackdrop.contentBackdropKey` 且只在有背景图时模糊；叠在内容上的（工具栏、面板、对话框、浮动按钮，以及正文从栏下滑过的预览页顶栏 `DiaryPreviewTopBar`）为 always；叠在另一块玻璃上的小控件为 none——同一区域禁止叠两层模糊。提示条（SnackBar）随组件 `controls` 只经 `AppGlassSnackBarTheme`（挂在 `MaterialApp.builder`，覆盖 `snackBarTheme`；不模糊、玻璃底色不透明度至少 0.88），禁止在 `showTrackedSnackBar` 或调用处另拼玻璃提示条。高对比度时玻璃改为不透明、不模糊（`AppGlassResolved.translucent` 为 false）。
- 必须：内容玻璃的静态背景取样只经 `GlassBackdropSample` / `GlassBackdropBlurCache`，由页面背景提供 `AppPageBackdrop.contentGlass`。只在图片已解码、背景完全落定且背景自己画遮罩时启用；首页各区域背景不一致、背景交叉淡入或预览页按基调染色遮罩时沿用实时模糊，禁止把单一区域或新图的静态取样覆盖到混合背景上。取样按背景 Leader 的实际尺寸与位置绘制，滚动只更新合成变换，窗口尺寸变化只通知取样画笔重绘；缓存最多四项，包含源图句柄的估算预算为 32 MiB（至少保留当前一项），单份输出约 4 MiB 上限，淘汰必须释放自有图像句柄。
- 必须：玻璃表面禁止放进 `Opacity` / `FadeTransition`（背景模糊采不到页面，淡入时先闪一块无模糊的底），整块淡入只经 `GlassReveal`（`ExpressiveEntrance(glass:)`、`ListItemPresence(glass:)`）、`GlassSurface.progress` 或 `LaunchReveal.builder`，`BackdropFilter` 始终在树里、只切 `enabled`；经典（不透明）表面照旧用 Opacity。相邻多片玻璃放进同一个 `BackdropGroup`（或共用 `GlassSurface.backdropKey`）；自上而下渐变（`GlassSurface.fadeToBottom` 为 true）的玻璃例外，一律自己读背景（`GlassSurface` 自动忽略共用设置，原因见 `appearance_styles.md` 导航栏样式条目）。越界效果只经 `AppScrollBehavior`（`MaterialApp.scrollBehavior`；Android Material 3 下可能有正在模糊的玻璃——有图片背景或首页玻璃顶栏——时经 `GlassSafeStretchingOverscrollIndicator` 用不产生离屏图层的 Transform 拉伸，否则仍为 SDK 拉伸），禁止各处自行恢复 SDK 的 `StretchingOverscrollIndicator` 或改滚动 physics 来规避回弹时玻璃丢失模糊。
