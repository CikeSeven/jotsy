# 外观样式：日记卡片、心情色、预览页、导航栏

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.1 / §2.3 / §5.8 / §5.19。

- 必须：日记卡片外观统一收在 `DiaryCardStyleSettings`（单个 JSON 设置键 `diaryCardStyleRaw`：当前样式 + 最多 12 份“我的样式”，逐字段容错解析，随备份导出与失败回滚），渲染统一经 `DiaryCard` + `DiaryCardResolvedStyle`；禁止各页另拼日记卡片或另加零散的卡片外观设置键（标签显示数量 `diaryCardTagLimit` 为既有独立键）。`DiaryCardStyle.defaults` 必须逐项等于 DESIGN.md §5.1 的默认规格；未解封胶囊只套用表面样式，心情色与标签色回退主题色。编辑入口为设置 → 外观 → 日记卡片样式（日记页顶栏“更多 → 显示布局 → 卡片样式”有快捷入口）。
- 必须：日记心情的颜色（预览页配色基调“心情”的种子色、卡片颜色来源“心情”与心情块）只经 `DiaryMoodPalette`（`models/diary_mood_palette.dart`，界面经 `diaryMoodPaletteProvider` 读取，卡片与预览页解析只收 palette、禁止再传心情符号列表自行换算）：内置十档心情色（相邻色相至少约 20°，由测试兜底），颜色跟着心情槽位走，默认符号始终作为别名；预览页整页主题以原色为种子，卡片用 `accentOf`（fidelity primary，按明暗换算）。用户改过的颜色只存于单个 JSON 设置键 `app.settings.mood_colors`（`DiaryMoodColors`，按槽位稀疏写入、逐项容错，全部为默认时删除键），与心情符号同为本机偏好，不随备份导出、不同步，禁止另加零散的心情颜色设置键；编辑只在心情符号页（`MoodOptionsPage`，与符号一起保存）。日历年视图与探索页心情图表的分段色只经 `MoodBandPalette`，禁止改用心情色板。视觉规范见 DESIGN.md §2.3。
- 必须：日记预览页的外观与阅读行为统一收在 `DiaryPreviewSettings`（单个 JSON 设置键 `diaryPreviewStyleRaw`：当前样式 + 最多 12 份“我的样式” + 阅读行为，逐字段容错解析，随备份导出与失败回滚）；渲染统一经 `DiaryPreviewContent` + `DiaryPreviewResolvedStyle`（页面外壳 `DiaryPreviewSurface`），设置页预览复用同一套组件；阅读行为不随预设与样式码改变；正文字体与排版仍只在 `DiaryTypography`，禁止另加零散的预览页设置键。顶栏按钮固定为分享、编辑与“更多”，不进 `DiaryPreviewPageStyle`（旧样式与样式码里的 `showTypographyButton` / `showEditButton` / `showShareButton` 读取时忽略），禁止再加按钮开关。`DiaryPreviewStyle.defaults` 必须等于 DESIGN.md §5.8 的默认规格。样式编辑页（卡片、预览页、导航栏、代码块）共用 `StyleEditorScaffold`，草稿与写入编排共用基类 `StyleDraftController`（滑块拖动只改草稿、松手才提交）；带“我的样式”与样式码的（卡片、预览页、导航栏）再经 `StyleEditorController` 与 `StyleLibraryTab`，代码块样式页没有样式库（`DiaryCodeBlockStyleEditorController` 直接继承 `StyleDraftController`）；禁止复制一份。
- 必须：首页底栏与各 Tab 顶栏的外观（导航栏样式）统一收在 `HomeBarSettings`（单个 JSON 设置键 `app.settings.home_bar_style`，备份字段 `homeBarStyleRaw`：当前样式 `HomeBarStyle` + 最多 12 份“我的样式” + 行为 `HomeBarBehavior`，逐字段容错解析，随备份导出、只在备份里有该字段时恢复、导入失败回滚），经 `home_bar_settings_provider.dart` 读取；行为（滚动时隐藏、指示器跟随滑动）不随预设 `HomeBarPreset` 与样式码 `HomeBarStyleCode`（`jotsy-bars:v1:`）改变；颜色与几何只经 `HomeBarResolvedStyle` 解析与夹取，禁止另加零散的导航栏设置键。底栏只有居中悬浮的玻璃胶囊一种形态（贴底的实色栏与 `BottomNav` 已移除，禁止再引入材质开关或 SDK `NavigationBar`），首页各 Tab 的顶栏恒为同一配方的玻璃（顶栏玻璃开关已移除，禁止再加实色顶栏选项）；渲染只经 `HomeBottomBar`（Scaffold 底栏槽位）/ `HomeFloatingBar`（胶囊）/ `HomeNavBar`（导航项行）/ `HomeTopBarSurface`（顶栏背景）/ `GlassSurface`（`lib/ui/widgets/glass/`，弹出菜单面板与文字选区胶囊 `ExpressiveMenuSurface` 同样构建在它之上），禁止其他页面自拼玻璃栏或另写磨砂配方。`HomeBarStyle` 的字段分三组：玻璃（色调、不透明度、顶栏分隔线）、形状与导航项（圆角程度 `roundness`、项宽、缝 `itemInset`、图标、文字字号、图标文字间距）、布局（文字模式、新建按钮位置）。栏高、格高、胶囊与指示器圆角只由这些推导（`HomeBarMetrics.itemHeight` / `HomeBarResolvedStyle`：格高 = 内容 + 固定留白，栏高 = 格高 + 2 × 缝，指示器圆角 = 胶囊圆角 − 缝、与胶囊同心），圆角按栏高一半的比例存；禁止开放栏高、指示器圆角这类会打破推导的单项，各数值字段的范围只在 `HomeBarStyleLimits`（要保证最大的图标 + 文字放大 1.3 倍仍放得进推导出的格高，`home_bar_style_test.dart` 兜底）。描边、投影、模糊强度（随不透明度线性变化）与饱和度增强仍是常量，禁止开放描边、指示器形态、模糊等单项调节。JSON 是相对默认值的稀疏编码，旧版本写下的其余字段（含按另一套栏高存的 `cornerRadius` / `iconSize` / `labelGap` / `blockPadding`，所以形状字段用了新键名）一律忽略、不迁移；改默认值会让没改过该字段的用户跟着新默认走，必须是有意为之并在 `HomeBarStyle` 的注释里写明（重做玻璃配方时不透明度默认值 0.72 → 0.50 换过一次）。内置预设共八个（两列网格，保持偶数）：前四个只改不透明度与色调，后四个只改形状、导航项与文字模式；改配方后必须截图核对每个预设压在照片上都看得出是玻璃（明暗各一），改形状参数后核对 360 宽的屏上四项不被收窄。底栏的位移 / 缩放类动效走真弹簧（`ExpressiveMotion.springTo`：指示器滑动、按压回弹、图标弹出、滚动隐藏），颜色与文字显现走不越界的 effects 曲线，减少动画时一律直接到位。玻璃表面的淡入、模糊共享与叠层约束见“背景与材质”条目（`GlassSurface.progress` / `GlassReveal` / `LaunchReveal.builder`）；由多片拼成的顶栏（如日记 Tab 的刊头与钉住的标签栏）只用一块玻璃：最下面一片用 `HomeTopBarSurface` 画玻璃并经 `glassAbove` 往上铺到上面各片之后（取上面各片可能的最大总高度），上面的片用 `HomeTopBarSurface.upper` 只画内容、经同一个 `HomeTopBarStackLink` 报上自己此刻的高度，顶栏的下缘也只在最下面一片；禁止各片各画一块玻璃（后画的那片读背景时会把先画那片里的标签模糊进自己的下缘，接缝处看得出一道线，渐变也连不成一条）。顶栏默认自上而下渐变——露出来的上半截是完整的玻璃，下半截里底色与模糊一起淡到下缘消失（比例只在 `GlassBottomFadePainter.fadeFraction`，禁止各页另取）；用户打开顶栏分隔线（只由 `HomeBarStyle.topBarHairline` 控制，默认关）时改为均匀玻璃加细线，高对比度时为不透明实边，三者互斥、由 `HomeBarResolvedStyle.topBarFades` 决定，页面不得自行判断。渐变段里自带底色的控件（搜索胶囊、标签胶囊、日记本切换胶囊的玻璃静止态）在 `topBarFades` 时必须改用 `HomeBarResolvedStyle.topBarControlFill`，禁止沿用压在均匀磨砂上的淡底（玻璃淡没后它们跟着看不见）；新增放在顶栏里、自带底色的控件同样处理。渐变只经 `GlassSurface.fadeToBottom`（`GlassBottomFadePainter`）绘制：模糊的淡出靠在背景模糊图层内按透明度擦除（dstIn）实现，渐变的玻璃因此禁止共用背景读取（`grouped` / `backdropKey`，`GlassSurface` 渐变时自动忽略）：Impeller 在几块玻璃共用背景且滤镜相同时不开新图层、把子节点直接画进父图层，擦除会把页面擦成黑色；同样禁止用 `ShaderMask` / `Opacity` 包住玻璃或叠多条模糊递减的 `BackdropFilter` 来做渐变，禁止另写渐变遮罩。它只变透明度，不属于“界面不用渐变色”的禁令（DESIGN.md §2.2），也不得借它做颜色过渡。新增首页 Tab 页面必须经 `HomeChromeScope` 取得顶栏样式并用 `HomeTopBarSurface` 画顶栏背景，在末尾占位补上 `MediaQuery.paddingOf(context).bottom` 并用 `SafeArea(bottom: false)`（首页 Scaffold 恒为 `extendBody`，内容从胶囊下方透出）。高对比度时保留玻璃布局但改为不透明（`translucent` 为 false），减少动画不关闭玻璃。编辑页为设置 → 外观 → 导航栏样式（`HomeBarStylePage`），复用 `StyleEditorScaffold`、`StyleEditorController` 与 `StyleLibraryTab`；条件出现的设置行统一经 `SettingsReveal` 展开收起（功能管理页同样），禁止另写一份。视觉规范见 DESIGN.md §5.19。
- 必须：首页切换 Tab 的运动只经三处：页面位移由真弹簧 `ExpressiveMotion.springPage` 推动（点按与快捷键经 `PageSpringDriver`，松手吸附经 `HomeTabPagePhysics`），跨页时的临时子页顺序只经 `HomeTabPageOrder`（PageView 子页以 Tab 身份为 key，按显示序排列；`_currentIndex` / `_targetIndex` 仍是底栏下标，页码、可见区间、景深与背景插值按显示下标），窄窗口途中的景深只经 `HomeTabDepth`（参数只在 `HomeTabDepthSpec`，舞台色只取 `ExpressiveSurfaces.tabStage`）。禁止回到固定时长 + 曲线的 `animateToPage`、禁止“先跳到隔壁再滑一页”、禁止切页途中丢弃点按（途中改道带着速度）；禁止给页面套 `Opacity` / `FadeTransition` 或 ImageFilter 离屏层做退远（各 Tab 顶栏是玻璃），`HomeTabDepth` 静止时不得产生任何图层（`home_tab_depth_test.dart` 兜底）。
- 必须：窄窗口景深切页途中各页按快照绘制（`HomeTabDepth.snapshot`）：有背景图时卡片自带本区域的背景（只经 `AppPagedAreaBackground`，与背景层静止时同一组图层），缝隙一律铺舞台色，背景层此时被整个盖住、不画插值（`AppPagedBackground.occludedWhileMoving`）；快照按卡片落在正中的位置拍（内容玻璃的取样对齐静止位置），整页移出视口即释放。可见区间跨两页时置 `_snapshotHold`，这期间（含落位后的保持）各页 ticker 暂停；保持只在“没有动画再请求下一帧”、手指按到页面上、回到顶部或满 `_snapshotHoldLimit` 时放开（`home_page_pager.dart`）。PageView 的缓存区覆盖全部 Tab（`allowImplicitScrolling` + `scrollCacheExtent`），禁止改回默认保活：页面进出保活桶会整棵子树 detach + attach；子页不另包重绘边界（`PageView.custom` + `addRepaintBoundaries: false`）：`HomeTabDepth` 单独重绘时祖先图层的位置还是上一帧的，快照里内容玻璃的取样会错开；不可见的页经 `ExcludeSemantics` 排除，页面第一次出现在可见区间时才创建。减少动画与宽窗口不拍快照、照常实时绘制。换序或 `correctPixels` 不发滚动通知，之后必须手动刷新可见区间与位置监听（`_applyPageOrder`）；切页途中换 PageView 的 physics 会新建滚动位置并接管活动，弹簧活动只在视口尺寸真的变了时才交还翻页物理。宽窗口不滑动，切页经 `HomeTabEntrance` 沿侧边栏方向入场；减少动画时一律直接跳页、没有景深。规格见 DESIGN.md §5.19“切换 Tab”与 §5.22。
