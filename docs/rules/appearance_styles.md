# 外观样式：日记卡片、心情色、预览页、导航栏

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.1 / §2.3 / §5.8 / §5.19。

- 必须：日记卡片外观统一收在 `DiaryCardStyleSettings`（单个 JSON 设置键 `diaryCardStyleRaw`：当前样式 + 最多 12 份“我的样式”，逐字段容错解析，随备份导出与失败回滚），渲染统一经 `DiaryCard` + `DiaryCardResolvedStyle`；禁止各页另拼日记卡片或另加零散的卡片外观设置键（标签显示数量 `diaryCardTagLimit` 为既有独立键）。`DiaryCardStyle.defaults` 必须逐项等于 DESIGN.md §5.1 的默认规格；未解封胶囊只套用表面样式，心情色与标签色回退主题色。编辑入口为设置 → 外观 → 日记卡片样式（日记页顶栏“更多 → 显示布局 → 卡片样式”有快捷入口）。
- 必须：日记心情的颜色（预览页配色基调“心情”的种子色、卡片颜色来源“心情”与心情块）只经 `DiaryMoodPalette`（`models/diary_mood_palette.dart`，界面经 `diaryMoodPaletteProvider` 读取，卡片与预览页解析只收 palette、禁止再传心情符号列表自行换算）：内置十档心情色（相邻色相至少约 20°，由测试兜底），颜色跟着心情槽位走，默认符号始终作为别名；预览页整页主题以原色为种子，卡片用 `accentOf`（fidelity primary，按明暗换算）。用户改过的颜色只存于单个 JSON 设置键 `app.settings.mood_colors`（`DiaryMoodColors`，按槽位稀疏写入、逐项容错，全部为默认时删除键），与心情符号同为本机偏好，不随备份导出、不同步，禁止另加零散的心情颜色设置键；编辑只在心情符号页（`MoodOptionsPage`，与符号一起保存）。日历年视图与探索页心情图表的分段色只经 `MoodBandPalette`，禁止改用心情色板。视觉规范见 DESIGN.md §2.3。
- 必须：日记预览页的外观与阅读行为统一收在 `DiaryPreviewSettings`（单个 JSON 设置键 `diaryPreviewStyleRaw`：当前样式 + 最多 12 份“我的样式” + 阅读行为，逐字段容错解析，随备份导出与失败回滚）；渲染统一经 `DiaryPreviewContent` + `DiaryPreviewResolvedStyle`（页面外壳 `DiaryPreviewSurface`），设置页预览复用同一套组件；阅读行为不随预设与样式码改变；正文字体与排版仍只在 `DiaryTypography`，禁止另加零散的预览页设置键。`DiaryPreviewStyle.defaults` 必须等于 DESIGN.md §5.8 的默认规格。样式编辑页（卡片、预览页、导航栏、代码块）共用 `StyleEditorScaffold`，草稿与写入编排共用基类 `StyleDraftController`（滑块拖动只改草稿、松手才提交）；带“我的样式”与样式码的（卡片、预览页、导航栏）再经 `StyleEditorController` 与 `StyleLibraryTab`，代码块样式页没有样式库（`DiaryCodeBlockStyleEditorController` 直接继承 `StyleDraftController`）；禁止复制一份。
- 必须：首页底栏与各 Tab 顶栏的外观（导航栏样式）统一收在 `HomeBarSettings`（单个 JSON 设置键 `app.settings.home_bar_style`，备份字段 `homeBarStyleRaw`：当前样式 `HomeBarStyle` + 最多 12 份“我的样式” + 行为 `HomeBarBehavior`，逐字段容错解析，随备份导出、只在备份里有该字段时恢复、导入失败回滚），经 `home_bar_settings_provider.dart` 读取；行为（滚动时隐藏、指示器跟随滑动）不随预设 `HomeBarPreset` 与样式码 `HomeBarStyleCode`（`jotsy-bars:v1:`）改变；颜色与几何只经 `HomeBarResolvedStyle` 解析与夹取，禁止另加零散的导航栏设置键。底栏只有居中悬浮的玻璃胶囊一种形态（贴底的实色栏与 `BottomNav` 已移除，禁止再引入材质开关或 SDK `NavigationBar`），首页各 Tab 的顶栏恒为同一配方的玻璃（顶栏玻璃开关已移除，禁止再加实色顶栏选项）；渲染只经 `HomeBottomBar`（Scaffold 底栏槽位）/ `HomeFloatingBar`（胶囊）/ `HomeNavBar`（导航项行）/ `HomeTopBarSurface`（顶栏背景）/ `GlassSurface`（`lib/ui/widgets/glass/`，弹出菜单面板与文字选区胶囊 `ExpressiveMenuSurface` 同样构建在它之上），禁止其他页面自拼玻璃栏或另写磨砂配方。`HomeBarStyle` 只有五个字段（色调、不透明度、顶栏分隔线、文字模式、新建按钮位置）：栏的几何、描边、投影与指示器固定在 `HomeBarMetrics`，模糊强度随不透明度线性变化、饱和度增强为常量（都在 `HomeBarResolvedStyle` 解析），禁止再开放栏高、圆角、描边、指示器形态、模糊等单项调节。JSON 是相对默认值的稀疏编码，旧版本写下的其余字段一律忽略、不迁移；改默认值会让没改过该字段的用户跟着新默认走，必须是有意为之并在 `HomeBarStyle` 的注释里写明（重做玻璃配方时不透明度默认值 0.72 → 0.50 换过一次）。内置预设只改不透明度、色调与文字模式，改配方后必须截图核对五个预设压在照片上都看得出是玻璃（明暗各一）。底栏的位移 / 缩放类动效走真弹簧（`ExpressiveMotion.springTo`：指示器滑动、按压回弹、图标弹出、滚动隐藏），颜色与文字显现走不越界的 effects 曲线，减少动画时一律直接到位。玻璃表面的淡入、模糊共享与叠层约束见“背景与材质”条目（`GlassSurface.progress` / `GlassReveal` / `LaunchReveal.builder`）；相邻的多片玻璃（如日记 Tab 的刊头与钉住的标签栏）放进同一个 `BackdropGroup`（`grouped`），底缘细线只画在最下面一片；顶栏分隔线只由 `HomeBarStyle.topBarHairline`（默认关）控制。新增首页 Tab 页面必须经 `HomeChromeScope` 取得顶栏样式并用 `HomeTopBarSurface` 画顶栏背景，在末尾占位补上 `MediaQuery.paddingOf(context).bottom` 并用 `SafeArea(bottom: false)`（首页 Scaffold 恒为 `extendBody`，内容从胶囊下方透出）。高对比度时保留玻璃布局但改为不透明（`translucent` 为 false），减少动画不关闭玻璃。编辑页为设置 → 外观 → 导航栏样式（`HomeBarStylePage`），复用 `StyleEditorScaffold`、`StyleEditorController` 与 `StyleLibraryTab`；条件出现的设置行统一经 `SettingsReveal` 展开收起（功能管理页同样），禁止另写一份。视觉规范见 DESIGN.md §5.19。
