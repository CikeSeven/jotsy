# 导入 / 恢复与网盘备份

> 专题约束，与 AGENTS.md 同等效力；改动本主题前先读本文件，新规则写在这里。界面规格见 DESIGN.md §5.30。

## 导入与恢复
- 必须：先只读预检再选合并或覆盖；改写本机已有数据的方式必须经 `showBackupOverwriteWarningDialog` 严重警告。
- 必须：其他应用的导出经 `JournalImportService` 解析为备份载荷、写入复用 `BackupMerge`；新增来源只加解析器，禁止另建写库路径。
- 禁止：解析器把来源的文件夹自行转成标签；落成日记本、标签或两者由用户导入时选择，不存设置键。
- 必须：复用已有日记本时不得重置用户改过的图标、封面与章节。
- 必须：正文样式只经 `journal_import_style.dart` 换算、结构块只经 `JournalBlockWriter` 写入；表格只在规整时写成表格块（≤ 12 列 / 200 行），否则展开为文字；格子里的链接只有会被解析器换成附件的才算不规整。
- 必须：8 位十六进制颜色按来源区分 CSS `#RRGGBBAA` 与 Android `#AARRGGBB`，禁止统一按一种解析。
- 必须：云端笔记只读；登录 Cookie 只留在内存与网页视图，登录前与导入后都清除，禁止落盘或另作他用。
- 禁止：静默丢弃笔记：整篇不导入的（回收站除外）按原因记入 `CloudReadIssues` 并在预览说明，能降级保留的尽量保留。

## 网盘备份
- 必须：编排只经 `CloudBackupService`、远程只经 `CloudBackupRemote`，上传下载一律流式；格式与流程见 `docs/cloud_backup.md`。
- 必须：位置、凭据与链密码只存单个 JSON 键 `app.cloud_backup.targets`，不随备份导出、不同步。
- 必须：应用密钥只经 `--dart-define` 注入，禁止进仓库；授权只用系统账号、设备码或系统浏览器，禁止内嵌网页授权；刷新的令牌立即落盘。
- 必须：增量写入顺序为包 → 快照 → 索引；远端文件不以 `.zip` 结尾，快照载荷禁止改名为 `backup_data.json`，以免旧版当完整备份覆盖。
- 必须：网盘来的索引严格校验；恢复时本机已有媒体只复制不移动，包缺失或哈希不符整次放弃。
- 必须：清理只经纯函数 `planIncrementalPrune`（24 小时宽限、读不出的链不动）；本机状态只在 `<数据根>/cloud_backup_state/`，不进偏好与备份。
- 必须：自动备份按位置开启、默认关，须先手动成功备份一次；全程静默，新增超过 50 MB 留给手动。
