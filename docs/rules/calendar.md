# 日历、纪念日、这天的心情与节假日

> 专题约束，与 AGENTS.md 同等效力；改动本主题前先读本文件，新规则写在这里。界面规格见 DESIGN.md §5.7。

- 必须：日历显示偏好只收进 `CalendarDisplayOptions`（单个 JSON 设置键，随备份导出）；筛选是页面临时状态，不写进该键。
- 必须：筛选的日记本组只列普通、非私密的手动日记本，不提供智能日记本；未解封时间胶囊在日历上的隐藏口径见 DESIGN.md §5.7。
- 必须：纪念日存 `anniversaries` 表，随完整备份导出与覆盖恢复，合并按业务 id 去重，日记包不带；彻底删除日记时解除关联。
- 必须：纪念日的日子只经 `AnniversaryCalendar` 推算，禁止页面自行换算公历 / 农历；不存在的日子顺延；不做提醒通知。
- 必须：这天的心情与各篇日记的心情相互独立，存 `day_moods` 表（一天一行，认不出的值按无心情显示、原值保留）；随完整备份导出与覆盖恢复，合并按日期，日记包不带。
- 必须：法定节假日只取 tyme 的 `LegalHoliday`，收录到依赖发布时已公布的年份，之后不标。
- 必须：日期格左上角标只经 `CalendarCellLeadingBadge` 取一个、心情格只经 `CalendarMoodTile` 绘制，禁止另加角标位置或另画心情格。
- 必须：日历上的待办口径见 `todos.md`。
