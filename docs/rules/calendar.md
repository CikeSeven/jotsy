# 日历、纪念日、这天的心情与节假日

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.7。

- 必须：日历页的显示偏好统一加在 `CalendarDisplayOptions`（单个 JSON 设置键 `calendarDisplayOptionsRaw`，逐字段容错解析并随备份导出），禁止为日历另加零散设置键；新增日期格样式经 `CalendarDayCell` 的填充/描边两种高亮形态实现。日历打点筛选 `CalendarMarkerFilter`（心情 / 标签 / 日记本三组，页面临时状态，不写进 `CalendarDisplayOptions`）的日记本组只列可见性为 normal 的手动日记本（`calendarFilterNotebooks`），禁止加入智能日记本或私密日记本；未解封的时间胶囊不参与筛选。视觉规范见 DESIGN.md §5.7。
- 必须：纪念日存 Drift `anniversaries` 表（业务 id `anniversaryId`；`linkedDiaryId` 存日记业务 id、不建外键），随完整备份导出、覆盖恢复与合并（按 `anniversaryId` 去重），日记包不含纪念日；某天落在哪、下一次是哪天一律经 `AnniversaryCalendar` 推算，禁止页面自行换算公历/农历；纪念日页面与提示统一经 `anniversary_navigation.dart` 打开，关联的日记只经 `watchActiveDiaryWithTags`（排除回收站）读取，彻底删除日记时解除关联。不做提醒通知。
- 必须：这天的心情（日历长按日期设定，与日记里各篇的心情相互独立）存 Drift `day_moods` 表（schema v14；以日期 `YYYY-MM-DD` 文本为主键、一天一行，`mood` 存 `DayMood` 枚举名，认不出的名称读取时按没有心情处理但原样保留），读写只经 `_AppDatabaseDayMoodOps`（`setDayMood` / `clearDayMood` + `restoreDayMood` 撤销），日历只经 `dayMoodsProvider`（整表订阅、按日期索引）读取；随完整备份导出与覆盖恢复，合并按日期匹配（本机没有的新增，合并保留本机、合并并覆盖替换），日记包不带。设定入口只有长按日期面板（`showCalendarDayActionsSheet` 返回 `CalendarDayMoodChoice`）→ `_CalendarDayMoodActions`；日期格只经 `CalendarMoodTile` + `DayMoodColors` / `DayMoodFace` 绘制（选择器 `DayMoodPicker` 复用同一套），禁止另画心情格；显示开关为 `CalendarDisplayOptions.showDayMoods`。心情是日期本身的属性，不受日历筛选与范围选择影响；年视图按心情着色时优先于日记平均心情。视觉规范见 DESIGN.md §5.7。
- 必须：日历的法定节假日（休/班）只取自 tyme 的 `LegalHoliday`，经 `CalendarHolidayDay` 读取，开关为 `CalendarDisplayOptions.holidayMode`；数字左上角标统一经 `CalendarCellLeadingBadge` 按优先级取一个（锁 > 休/班 > 纪念日心形 > 待办 > 天气），禁止在日期格另加角标位置。待办在日历上的口径见 `todos.md`（`CalendarDisplayOptions.showTodos`，只在待办功能开启时生效）。
