# 日记留言

> 专题约束，与 AGENTS.md 同等效力；改动本主题前先读本文件，新规则写在这里。界面规格见 DESIGN.md §5.26。

## 数据
- 必须：留言只存 `diary_comments` 表（`diaryId` 为日记业务 id），读写只经 comment ops；编辑不改写下时间；文字与图片都没有的留言一律拒绝。
- 必须：`content` 是唯一权威的纯文字（搜索、复制、AI、纯文本导出只读它）；格式只存可空的 `delta` 列，与 `content` 对不上即按无格式读；只留粗斜下删四种格式与合法链接（http(s) 带主机名、mailto、tel、日记链接）。
- 必须：彻底删除日记在同一事务里删掉它的留言，软删除不动。
- 必须：随完整备份与日记包导出、覆盖恢复；合并按 `commentId`，所属日记不在载荷里的留言丢弃；参与局域网同步（见 `lan_sync.md`）。

## 开关与隐私
- 必须：功能默认关闭，只读 `diaryCommentsEnabledProvider`；关闭时留言的全部入口、留言数、搜索、探索卡与导出开关隐藏，数据保留。
- 必须：回收站、未解封的胶囊与截取分享长图时不显示留言；分享文字与长图都不带留言。
- 必须：跨日记回看（探索卡、搜索命中）排除私密日记、回收站与未解封的胶囊；只有搜索页匹配留言，未解封的胶囊只按标题。
- 禁止：把卡片留言数放进按更新时间缓存的 `DiaryCardViewData` 或并进分页查询。

## 图片、链接与导出
- 必须：每条最多 9 张，只从相册多选，不提供拍摄入口；未保存的新图在移除或取消时立即删除，已保存的只由媒体回收按引用删除。
- 必须：链接对话框与候选列表只用正文同一套（见 `diary_links.md`），禁止另写；认不出的地址不打开，日记本功能关闭时日记本链接按普通文字。
- 必须：留言里的日记链接不算反向链接。
- 必须：导出带媒体时图片写成图片、写不成的写“[图片 ×N]”，格式按正文的行内写法（日记链接只留文字）；没有图片与格式的留言产物不变。
