# 日记留言

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.26。

- 必须：日记留言（重读时写给这一篇的回应，功能管理里默认关闭）只存 Drift `diary_comments` 表（schema v16；业务 id `commentId`；`diaryId` 存日记**业务 id**、不建外键；纯文本 `content` 与可选心情 `mood`（日记心情选项的 emoji 原文），`createdAt` 为写下时间、编辑不改，`editedAt` 非空即“已编辑”），读写只经 `_AppDatabaseCommentOps`（`addDiaryComment` / `updateDiaryComment`（有改动才记编辑时间）/ `deleteDiaryComment` + `restoreDiaryComment` 撤销），空白留言一律拒绝。功能是否开启只读 `diaryCommentsEnabledProvider`（`AppFeatures.comments`）：关闭时留言区、“更多 → 写留言”、信息栏与卡片的留言数、搜索留言、探索卡片与导出开关全部隐藏，数据保留。预览页只经 `DiaryPreviewContent(comments:)`（`DiaryPreviewComments`，null 即不显示：功能关闭、日记在回收站、未解封的胶囊（封存页不建正文）、截取分享长图期间（`DiaryPreviewExportController.capturingLongImage`））显示 `DiaryCommentsSection`，写 / 改 / 复制 / 删除只经 `diary_comment_flows.dart`（面板 `showDiaryCommentSheet` 只负责挑选），相对时间与折叠只经 `diary_comment_timeline.dart`；分享文字与长图都不带留言。卡片留言数只经 `diaryCommentCountsProvider` 由调用方传给 `DiariesListSection.commentCounts`（禁止放进按更新时间缓存的 `DiaryCardViewData`，也禁止并进分页查询），显隐为 `DiaryCardMetaStyle.showComments` 与 `DiaryPreviewMetaStyle.showCommentCount`（默认开，只在有留言时出现）。搜索只在搜索页经 `DiaryPageQuery.matchComments` 匹配留言（未解封的胶囊只按标题），`readsFrom` 只在此时订阅留言表；只命中留言的结果经 `belowCardBuilder` 附 `DiarySearchCommentHit`。跨日记回看（探索卡、搜索命中）经 `_writeDiaryScopeFilter` 排除私密，并排除回收站与未解封的胶囊。彻底删除日记在同一事务里删掉它的留言，软删除不动；随完整备份与日记包导出、覆盖恢复，合并按 `commentId`（本机没有的新增，合并保留本机、合并并覆盖替换），所属日记不在载荷里的留言丢弃。视觉规范见 DESIGN.md §5.26。
