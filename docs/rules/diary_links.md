# 日记链接

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.27。

- 必须：日记链接（正文里指向另一篇日记 / 另一本日记本）的地址只经 `DiaryLinkTarget`（`core/database/diary_blocks/diary_link_target.dart`：`jotsy://diary/<diaryId>` / `jotsy://notebook/<notebookId>`，都是业务 id，严格解析）编解码：行内链接沿用行内属性 `href`，卡片为块 `link_card`（`data.target` 为地址、`data.title` 为单行标题快照，属 `kDiaryEmbedBlockTypes`、从不挂子块），禁止另起行内属性或存本地 id。写入只经 `controllers/diary_link_editing.dart`，且只在 `DiaryEditorController.linkSource` 给出时开放（编辑页给出，模板编辑页与只读正文不给）：`@`（触发规则同 `/`；会话与浮层共用 `DiaryCaretMenuSession` / `DiaryCaretMenuHost`，禁止另写一套光标旁菜单）、`/` 菜单的“日记卡片 / 日记本卡片”（同一会话的卡片模式）与链接对话框 `editDiaryLink` 的「日记 / 日记本」页；候选只经 `searchDiaryLinkCandidates`（日记经 `watchDiaries`，天然排除私密、回收站与归档；日记本取书架树，书架没加载时经 `readDiaryLinkNotebookTree` 查一次库——禁止读没有监听者的 provider 的 future，Riverpod 3 会暂停它）。打开只经 `openDiaryLinkTarget`：日记按 id 读取，不存在或在回收站给提示，所在手动本的生效可见性为 locked 时先经 `authorizeNotebookEntry`，再经 `openDiaryPage`（删除给撤销）；日记本经 `openNotebookFromAnywhere`，编辑态不打开日记本。行内链接的点按只在 `diaryLinkTextSpan`（`diaryEditorSpanDecorator` 拦截内部地址，网址仍交上游；只读点按即开，编辑态单击选中、双击或 Ctrl / ⌘ 点按打开），卡片只经 `DiaryLinkCard` 显示实时内容（日记经 `diaryLinkDiaryProvider`，私密日记只显示“私密日记”，未解封胶囊只显示标题与解封日期，目标不存在显示快照），快照只用于导出、分享与目标缺失。日记本功能关闭时日记本链接按普通文字绘制、日记本卡片不可点，`@` 候选、`/` 命令与对话框都不出现日记本。导出与分享只留文字：`ExportInline.fromAttributes` 去掉内部地址，卡片导出为一段快照标题，禁止写出器写出 `jotsy://`；模板白名单本就丢掉日记链接与卡片（测试兜底）。反向链接只经 `_AppDatabaseDiaryLinkOps`（`watchDiaryBacklinks` / `getDiaryBacklinks` 共用一条查询：按地址 LIKE 正文 JSON，地址两侧带引号防前缀误配；含归档，排除回收站、未解封胶囊、私密日记与目标自己，不建索引表）；日记本头部与全部反向链接面板经实时的 `diaryBacklinksProvider`，预览页与它的正文、所在日记本一样只读一次（`diaryPreviewBacklinksProvider`，禁止在预览页多挂数据库订阅），经 `DiaryPreviewContent(backlinks:)`（`DiaryPreviewBacklinks`，null 即不显示：在回收站、未解封胶囊、截取分享长图期间、没有反向链接），日记本头部为“被 N 篇日记提到”胶囊，两处共用 `showDiaryBacklinksSheet`。视觉规范见 DESIGN.md §5.27。
