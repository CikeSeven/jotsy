# 日记链接

> 专题约束，与 AGENTS.md 同等效力；改动本主题前先读本文件，新规则写在这里。界面规格见 DESIGN.md §5.27。

- 必须：地址只经 `DiaryLinkTarget` 编解码（`jotsy://diary/<id>` / `jotsy://notebook/<id>`，业务 id）；行内链接用 `href`，卡片为块 `link_card`；禁止另起行内属性或存本地 id。
- 必须：只在写日记的编辑页能插入链接（模板编辑页与只读正文没有）；`@`、`[[`、`/` 卡片与链接对话框共用同一会话与浮层，禁止另写光标旁菜单。
- 必须：候选只经 `searchDiaryLinkCandidates`，排除私密、回收站与归档的日记；正文以外写链接的地方（留言）同样只用这套对话框与候选列表。
- 必须：打开只经 `openDiaryLinkTarget`：不存在或在回收站给提示，上锁本子里的日记先验证；编辑态不打开日记本。
- 必须：卡片显示实时内容，私密日记只显示“私密日记”，未解封胶囊只露标题与解封日期；标题快照只用于导出、分享与目标缺失。
- 必须：日记本功能关闭时日记本链接按普通文字、卡片不可点，候选与对话框里没有日记本。
- 禁止：导出与分享写出 `jotsy://`（只留文字）；模板丢掉日记链接与卡片（`diary_link_target_test.dart` 兜底）。
- 必须：反向链接只查正文（留言不算），含归档，排除回收站、未解封胶囊、私密日记与目标自己，不建索引表；预览页只读一次，禁止多挂数据库订阅。
- 必须：导入笔记间的链接只经 `JournalNoteLinkIndex` 写成日记链接（解析口径同 Obsidian），只认这次导入的笔记，库里没有的目标保留文字；原文直接写的 `jotsy://` 地址照写为日记链接、不交给附件解析器；代码围栏与行内代码不改写（`journal_import_note_links_test.dart` 兜底）。
