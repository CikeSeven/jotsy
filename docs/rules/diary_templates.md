# 日记模板

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.15。

- 必须：日记模板的用户模板只存 Drift `diary_templates` 表（业务 id `templateId`；`payload` 为 `DiaryTemplateJson.toPayload`，`name` 为镜像，`sort_order` 为手动排序）；内置模板的默认内容只由 ARB 文案经块描述编译（`buildBuiltInDiaryTemplates`，id 为 `builtin.<key>`），默认内容禁止落库。内置模板可直接编辑：保存后以同一 id 存进 `diary_templates` 表、替换默认内容并留在内置列表原位（`DiaryTemplateLibrary` 合并，不算“我的模板”；最近使用、自动套用与日记本默认模板的指向不变），“恢复默认”经 `DiaryTemplatesController.resetBuiltIn` 删掉这一行（可撤销）；删除内置模板只记进偏好 `hidden`（`deleteBuiltIn`，改过的内容留在库里），之后管理页不再列出、模板库 `byId` 与 `loadDiaryTemplate` 都不再认它（与删除我的模板同一口径），只能在管理页末尾的“恢复已删除的内置模板”面板（`showDiaryTemplateRestoreSheet` → `restoreBuiltIns`）找回。内置模板正文的小标题用与正文同字号的粗体彩色行（`TplLabel`：颜色取强调色同色相的文字色预设 `DiaryColorPreset`，末尾冒号不带格式，方便在同一行继续填写），小标题之间以 `TplGap` 空一行，禁止用标题块（`heading`），由 `built_in_diary_templates_test.dart` 兜底。行为偏好（建议条开关、按时间段自动套用的规则 `autoRules`（最多 12 条，JSON 字段 `rules`，逐条容错解码）与其他时间的默认模板 `autoTemplateId`、已删除的内置模板 `hidden`、最近使用）只存于 `DiaryTemplatePrefs`（单个 JSON 设置键 `app.settings.diary_template_prefs`，逐字段容错并随备份导出与失败回滚）；删除模板（含内置模板）时一并移除指向它的规则与默认模板，撤销时放回（从面板恢复不放回），禁止另加零散的模板设置键。模板（含改过的内置模板）随完整备份导出与覆盖恢复；两种合并都只新增本机没有的模板（按 `templateId`），从不覆盖本机模板；日记包不带模板。正文只允许文字块（含提示块、折叠块与表格）与分隔线：保存、导入模板码、读出数据库行、另存为模板一律经 `sanitizeDiaryTemplateBlocks` 白名单重建允许的节点和属性（v1 Delta 先经 `sanitizeDiaryTemplateOps`）——提示块只留 `icon`（单个字素、不超过 8 个 UTF-16 单位）与认得的 `tone`，折叠块只留 `collapsed`（bool）与子块，表格只在结构有效时按行列重建、只留 `colsLen` / `rowsLen` / `headerRow` 与格子位置且格内只有段落，行内 `script` 只认 super / sub；禁止任何媒体嵌入或设备路径进入模板。变量只经 `DiaryTemplateVariable` 的多语言别名表解析（中英日俄写法等价，每种界面语言插入的写法都必须在表里，认不出的原样保留），取值经 `DiaryTemplateVariableValues`：日期类按日记日期（补写取那一天），时间按当下，农历与节气只经 `CalendarLunarDay`；只有 `acceptsFormat` 的变量（目前只有时间）能在冒号后写格式（`{{时间:HH:mm}}`：半角或全角冒号、只按第一个冒号拆，格式为 intl `DateFormat` 图案，按界面语言格式化当下），其余变量带冒号的写法与空格式原样保留；图案只经 `formatDiaryTemplateMoment` 检查与格式化（检查 intl 实际采用的图案：单引号外只认已实现的字段字母、不收时区、单引号成对、至少一个字段，intl 抛错同样原样保留），禁止另调 `DateFormat` 解析模板里的格式；ARB 不能写字面 `{{…}}`，内置文案用 ICU 占位符填入变量写法。套用只经 `DiaryTemplateApplyController`：只在新建空白日记、标题与正文都为空时套用，预设只填空着的项（心情须在本机心情选项里，日历预设的胶囊优先），套用后原样未动的内容不算草稿（`snapshotFor`），撤销只在内容仍原样时生效；自动套用只经 `DiaryTemplatePrefs.autoApplyCandidates` 给出候选（只在日记日期为今天时看时间段，更具体的在前，默认模板最后），套用第一个仍存在的；换模板（顶栏菜单“选择模板”与“全部”面板）只经 `apply(..., replacePristine: true)`，只在内容仍是本次套用的模板原样时替换（先撤回旧模板的预设与它新建的标签），用户写过字时只提示、禁止覆盖；预设标签按名称经 `ensureTagsByName` 匹配、只新建缺失的，禁止在模板模块调用会改色的 `createTag`。新建编辑页的建议条与模板面板读一次性快照 `userDiaryTemplatesSnapshotProvider`（管理页每次写入后 invalidate），禁止在编辑页挂模板表的实时查询。管理页为设置 → 编辑器设置 → 日记模板（`DiaryTemplatesPage`，读写经 `DiaryTemplatesController`），模板码写 `jotsy-template:v2:`（`StyleCodeFormat`），读取兼容 v1 并转换为块文档。视觉规范见 DESIGN.md §5.15。
