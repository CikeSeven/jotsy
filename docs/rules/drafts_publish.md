# 草稿箱与发布页

> 专题约束，与 AGENTS.md 同等效力；改动本主题前先读本文件，新规则写在这里。界面规格见 DESIGN.md §5.14、§5.32。

## 草稿
- 必须：草稿只存 `diary_drafts` 表，每次新建独立一份并自动保存；返回、切后台与销毁时补存，发表成功后先停自动保存再删。
- 禁止：重新引入单键草稿；“新建空白”删除已有草稿。
- 必须：有草稿时新建先弹草稿选择面板（拍照记 / 录音记直接新建空白），禁止另写新建弹窗。
- 必须：只套了模板、原样未动的不算草稿；删除带撤销，撤销窗口结束后才回收媒体。
- 必须：桌面草稿箱不提供左滑，改为右键菜单（继续写、删除；单份删除同左滑，不确认、带撤销）；顶栏常驻“多选”入口，从它进入时没有勾选也停在多选里；Ctrl / Shift + 点按多选。手机交互不变（#350）。
- 必须：草稿随完整备份导出与覆盖恢复，合并导入与日记包不带；媒体清理把草稿当引用来源。

## 发布页
- 必须：新建日记只经发布页发表：进入即写库并删除草稿，之后防抖自动保存；写库失败退回编辑页、草稿保留。
- 必须：返回时先补存（失败留在本页），再以新日记 id 回到打开者；禁止恢复发表按钮或带草稿返回编辑页。
- 必须：“返回时直接发表”与“发布时自动展开详细信息”只存 `DiaryCreatePrefs`（随备份导出），均默认关闭；前者开启后没写东西照常离开，带胶囊的经发布页封存，写库失败补存草稿后离开；后者开启后进入发布页发表成功随即展开底部详细信息面板。
- 禁止：为直接发表另写写库逻辑，只复用发布页的同一次提交（#196）。

## 从新建按钮展开
- 必须：只有首页新建按钮打开的新建页从按钮展开，按钮不在屏上或减少动态效果时用普通转场。
- 必须：返回落点只由 `DiaryCreateMorph` 判断（发表了→新卡片，写了东西→草稿箱角标，否则→新建按钮），落点变化等整页落定后才播放。

## 用过的地点
- 必须：只经 `watchPlaceHistory` 从日记 metadata 现算，禁止另存表或设置键，以免脱离日记的备份、同步与删除。
- 必须：同名地点算一个，坐标取最近一篇带合法坐标的日记；不含回收站与私密日记，归档与胶囊照常算。
- 必须：选用只经 `DiaryMetaActions.selectPlace`：带坐标的恢复坐标与层级，手填的只换文案；正在定位时不可选用。
