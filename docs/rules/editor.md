# 编辑器与正文

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §3.2 / §5.6 / §5.20。

- 必须：日记正文的新写入统一为 AppFlowy `Document.toJson()` 同构的块文档，历史 Delta、旧节点与纯文本的读取只经 `decodeStoredDiaryBlocks`；媒体扫描和路径重绑复用 `diary_blocks_media.dart`，禁止业务模块自行扫描旧 JSON 字段。只有 `kDiaryContainerBlockTypes`（段落、列表、待办、折叠块 `toggle_list`，与编辑器真正画出子块的组件一致；`ensureDiaryEditorGlobals()` 之后须与上游 `af.indentableBlockTypes` 严格相等，测试兜底）能挂子块：换块类型经 `addDiaryBlockTypeChange`（换成不画子块的类型时子块提到它后面），已存的此类子块由 `decodeStoredDiaryBlocks`（`liftHiddenDiaryBlockChildren`）读取时修正，模板白名单同样处理，禁止留下看不见的子块。块类型与键只在 `diary_blocks_schema.dart` 定义：提示块 `callout`（delta + `icon` + `tone`）是文字块、从不挂子块；折叠块只在 `data.collapsed == true` 时收起；表格为 `table`（`colsLen` / `rowsLen` / 本应用的 `headerRow`）→ 格子 `table/cell`（`rowPosition` / `colPosition`）→ 段落，结构校验与整理只经 `diary_blocks_table.dart`（`DiaryTableGrid` / `normalizeDiaryTable`，上限 12 列 / 200 行）：读取时有效表格保留，无效表格按行优先展开为格内段落（不丢内容），表格外的零散格子换成它里面的块；纯文本镜像里表格每行一行、格间 ` | `（`DiaryTableGrid.rowTexts`）；行内上下标为 `script`（super / sub）；日记链接卡片为 `link_card`（`target` + `title`，属嵌入块、从不挂子块），行内 `href` 还可以是日记链接的内部地址（见 §6 日记链接条目）。编辑与只读正文统一经 `DiaryEditor`（`widgets/diary_editor/`），会话与事务经 `DiaryEditorController`（`controllers/`）；模板正文同为块文档，模板码 v2 兼容读取 v1。禁止重新引入 Quill 编辑器、扩展或 PDF 插件；历史 Delta 的转换只保留纯数据兼容（说明见 `docs/appflowy_migration_handoff.md`）。
- 必须：日记正文排版（字体、字号、行距、字间距、段间距、首行缩进）只存于 `DiaryTypography`（单个 JSON 设置键 `app.settings.diary_typography`，逐字段容错并随备份导出）；编辑页、预览页、发布页、模板编辑页与设置预览一律经正文位置的 `DiaryEditor(appearance: ref.watch(diaryTextAppearanceProvider), controller: …)` 解析主题与排版（禁止页面自行创建 `EditorStyle` 或绕过共用块注册表）；标题字体经 `DiaryTextAppearance.titleStyle`，禁止页面自行设置正文字号/行距或另加排版设置键。字体的作用范围只经 `DiaryTypography.applyFontToApp`（“用于整个界面”，默认关）与主题扩展 `AppFonts`（`lib/app/theme/app_fonts.dart`，由 `appFontsProvider` 解析、`NodeDiaryApp` 经 `buildSeededAppTheme(fonts:)` 装进主题）：`interface` 只在开关开启时非空、替换整份字阶，`diary` 始终是正文字体，日记卡片（`DiaryCardResolvedStyle` 的标题与摘要）与 `DiaryListRowCard` 只经 `AppFonts.of(theme).diary` 取字体，禁止卡片另读排版 provider；`SeededThemeCache.of` 另建要渲染组件的主题时必须传 `fonts: AppFonts.of(appTheme)`，只取 `colorScheme` 的可不传。启动门控经 `appFontsStartupReadyProvider` 等所选导入字体注册（上限 1.5 秒）。首行缩进只经 `DiaryParagraphBlock`（`widgets/diary_editor/diary_paragraph_block.dart`，全局缩进大于 0 或段落带工具栏写入的首行缩进标记 `kDiaryParagraphIndentKey`（`data.firstLineIndent`，两字与全局取较大者）时取代上游段落块，否则仍用上游段落块）；工具栏「缩进 / 取消缩进」在选区全是正文段落时只经 `diary_paragraph_indent_editing.dart` 写这个标记（只缩进首行，禁止改回把段落挂成子块的嵌套缩进），其余块仍为上游嵌套缩进；段首的字换成等长的“缩进 + 字”占位（`diary_first_line_indent.dart`），文字偏移与文档一一对应，光标、选区、点按与取词的几何补偿都在这个块里，禁止在文档里插入空格或另起占位来缩进；占位里的字的背景色只经 `DiaryFirstGlyphBackground` 补画（规则同下文上下标）；宽度只取 `DiaryTypography.firstLineIndentExtent`（Word 导出同一口径）。块级排版变化经 `DiaryEditor` 换上新的块渲染器才会作用到已打开的编辑器（上游只在挂载时装入块组件），禁止去掉。导入字体只经 `DiaryFontStorageService`（应用支持目录 `diary_fonts/`，字体文件不进备份，备份只带字体 id，缺失时回落内置字体）；修改经 `DiaryTypographyController`，滑块拖动只改草稿、松手才提交。规范见 DESIGN.md §3.2。
- 必须：正文文字色 / 背景色只经悬浮工具栏卡片内的颜色面板（`DiaryColorPanel`，按钮为 `DiaryToolbarColorButton`；「色板」页为色块，「色系」页为 `DiaryColorMaterialPage`（Material 色板，色系与色阶只取自 `DiaryMaterialFamily`，写入色阶原值），「自定义」页为 `DiaryColorCustomPicker` 色谱取色）写入，值一律为大写 `#AARRGGBB`（经 `encodeDiaryColor`，预设与解析见 `diary_text_colors.dart`）；色谱拖动中只改面板预览，松手才写入正文（每次松手一步撤销）。“我的颜色”只存于 `DiarySavedColors`（单个 JSON 设置键 `app.settings.diary_recent_colors`，键名与备份字段 `diaryRecentColorsRaw` 沿用早先的最近颜色、已有记录原样成为我的颜色；文字色与背景色各最多 24 个，逐项容错并随备份导出与失败回滚），一切增删只经 `diarySavedColorsProvider` 的 `edit`（在最新记录上执行）：自定义页写入正文后自动保存（同一选区上接连调色经 `save(replacing:)` 原地替换、只留最后一个；已存过的不重复、不挪位置；预设不存），色板页“我的颜色”一行（`DiaryColorSavedStrip`）的管理里移除或收藏本篇用过的颜色；点色块套用不改动我的颜色。禁止另加零散的颜色设置键；面板高度不得随保存的颜色数变化。颜色代码输入框用普通文字键盘（`TextInputType.text`，`enableSuggestions` 保持默认开启：Android 上关掉联想会被当成可见密码框、弹出密码键盘），输入法组字期间不改写文字；输入框取得焦点期间，编辑页与模板编辑页须经包住工具栏的 `Focus` 保持工具栏挂载，且此时不以键盘高度为显示条件（交接焦点时输入法可能先收起再弹出，键盘高度短暂归零）。禁止为颜色工具打开会抢走正文焦点的路由、对话框与底部面板。视觉规范见 DESIGN.md §5.6。
- 必须：编辑页标题、模板/照片建议与正文共用 AppFlowy 的原生虚拟滚动（`DiaryEditor.header/footer`）；悬浮工具栏的精确避让只经 `DiaryEditorViewport`，遮挡高度与正文末尾占位 `_editorBottomSpacer` 同源（含 `_caretToolbarClearance`），「更多」等面板展开的高度经 `_toolbarPanelExtent` 只重建正文这一层、计入交给正文的遮挡高度（`autoScrollEdgeOffset`），新增底部浮层必须同时计入占位。文字/选区变化、键盘变高的每一帧与遮挡增长时揭示光标，遮挡高度本身变高（面板展开、录音 / AI 面板打开）时带 `medium` `DiaryEditorKeyboardReopen`（`widgets/diary_editor/`，交互层里只观察指针）在点按后选区原样、键盘收起时断开并重连输入法；禁止改为直接调用平台 `TextInput.show`（可能弹出没有输入连接的键盘）。嵌入块（`kDiaryEmbedBlockTypes`：图片、视频、音频、附件、分隔线、日记链接卡片）上能停插入点：偏移 0 在块的左侧、1 在右侧，只经 `DiaryEmbedSelectable` 画成与内容等高的闪烁竖线（贴着 `DiaryEmbedContent` 的边，可画在块外），分隔线经 `DiaryDividerBlockBuilder`（不用上游分隔线块）；点在块旁的空白处（图片右侧、并排小图之间与右侧、块的上下留白、分隔线、最后一块下方）插入点停到点的那一侧，上游不为没有文字的块连接输入法，只经 `DiaryEmbedCaretInput`（`diary_embed_caret_input.dart`）连上空行的编辑值、键盘照常弹出：点按经 `DiaryEditorKeyboardReopen`，其余（退格越过文字行、撤销、插入媒体）经它的选区监听（带 `selectionExtraInfoDoNotAttachTextService` `openDiaryLineAtEmbedCaret`（在插入点那一侧补一个段落、不重连输入法）再放行给上游写进去，换行与回车只经 `insertDiaryLineAtEmbed`，粘贴与程序插入文字经 `insertDiaryEditorNodes` 插在块旁；插入媒体时插入点在块上则插在那一侧、不补空段落。退格 / Delete 只经 `diary_embed_editing.dart`（`backspaceDiaryEmbed` / `deleteForwardDiaryEmbed`）：文字块开头退格、上一块是嵌入块时，本行是空段落就删掉它、插入点到嵌入块右侧，否则只把插入点挪到右侧；插入点在块右侧退格删掉这一块、插入点退到前一个位置（全文删空时补一个空段落），在左侧退格同段首退格；Delete
