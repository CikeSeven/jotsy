# 探索页

> 专题约束，与 AGENTS.md 同等效力；改动本主题前先读本文件，新规则写在这里。界面规格见 DESIGN.md §5.25。

## 设置与卡片
- 必须：布局、外观与上次选的统计范围只存于 `ExploreSettings`（单个 JSON 键 `app.settings.explore_layout`，等于默认时删键），随备份导出、只在备份带该字段时恢复。
- 必须：逐字段容错：认不出的卡片原样留在原位，缺少的已知卡片按默认补到末尾，非法选项只让该项回默认。
- 必须：“我的布局”最多 12 份；预设与布局码 `jotsy-explore:v1:` 只换布局，不改统计范围。
- 必须：新增卡片只在 `ExploreModuleSpec.all` 登记（含依赖的功能与选项声明），编辑页按声明统一画选项，禁止为某张卡另写控件。
- 必须：纪念日、时间胶囊、日记本、留言、AI 助手关闭时对应卡片不出现；草稿卡只在有草稿时出现；探索 Tab 关闭时设置里没有“探索页”入口。
- 必须：卡片外壳一律 `ExploreCard`、外观只经 `ExploreAppearanceScope`（无 scope 时为默认外观）；卡片里的跳转只经 `ExploreActionsScope`，自定义页预览点按不跳转。

## 数据口径
- 必须：统计含归档，不含回收站、未解封的时间胶囊与私密日记（私密口径见 AGENTS.md §3）。
- 必须：跟随统计范围的只有数据看板、标签、写作习惯、心情分布、足迹与天气；连续天数与时间跨度始终按全部日记。
- 必须：聚合只算可见的卡片；改外观、宽度或顺序不得重新扫描全库。
- 禁止：把正式页的全部卡片放进单个 `SliverToBoxAdapter` 或 `shrinkWrap` 网格（须按视口惰性挂载）。

## 媒体画廊
- 必须：候选口径同上，打开后在后台按发表时间分批读完全部、首批到了即显示；禁止改回“滚到底再加载”，以免快速滚动条拿不到总量。
- 必须：分组只合并相邻同桶媒体、不重排，网格顺序即看图页下标；禁止改回每组一个 sliver 或分组标题吸顶。
- 必须：换档只经 `GalleryZoomDriver`，禁止叠预览滚动视图、缩放整页或换 key 重建正式网格；桌面另有 Ctrl + 滚轮与触控板捏合。
- 必须：日记本筛选不列上锁的本子，日记本功能关闭时整项不出现；筛选只在页面内存活、不持久化。
