# 探索页

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.25。

- 必须：探索页（`ExplorePage`）由布局里的卡片组成，布局、外观与上次选的统计范围只存于 `ExploreSettings`（单个 JSON 设置键 `app.settings.explore_layout`，`SettingsService` 只保存原文（`exploreLayoutRawNotifier`），与默认相同时删除键；备份字段 `exploreLayoutRaw`，只在备份里有该字段时恢复、导入失败回滚），经 `exploreSettingsProvider` 读取、`saveExploreSettings` 写入，禁止另加零散的探索页设置键。`ExploreSettings` 为当前布局 `ExploreLayout`（卡片顺序与每张卡的显隐 / 宽度 / 选项、范围条开关、外观 `ExploreAppearance`）+ 最多 12 份“我的布局” + 行为 `ExploreBehavior`（统计范围，不随预设 `ExplorePreset` 与布局码 `jotsy-explore:v1:` 改变）；逐字段容错、稀疏写入：认不出的卡片原文保留在原位（`ExploreUnknownModule`），缺少的已知卡片按默认补到末尾，不合法的选项只让这一项回到默认。新增卡片只在 `ExploreModuleId` 与 `ExploreModuleSpec.all` 登记（分组、图标、默认显隐与宽度、是否跟随统计范围 `periodAware`、依赖的功能 `feature`、选项声明 `ExploreChoiceOption` / `ExploreToggleOption` / `ExploreCountOption` / `ExploreMultiOption`），卡片经 `ExploreModuleConfig` 按声明读取类型化的值，编辑页按声明统一画选项，禁止在编辑页为某张卡另写控件。功能开关只经 `ExploreModuleSpec.isAvailable`：纪念日、时间胶囊、日记本、留言、AI 助手关闭时对应卡片不出现，编辑页里显示为禁用并注明原因；草稿卡只在有草稿时出现；探索 Tab 关闭时设置里的“探索页”入口不出现。数据口径：含归档，不含回收站、未解封的时间胶囊与私密日记（概览流 `watchExploreDiaryOverviews`；待解封胶囊与近期带图日记经 `_AppDatabaseExploreOps`，同样经 `_writeDiaryScopeFilter`）；条目只经 `ExploreEntryCache` 解析一次 metadata，聚合只放 `controllers/` 的纯函数（`ExploreDataBuilder` 只算可见的卡片），字数经 `DiaryWordCounts`；跟随统计范围的只有数据看板、标签、写作习惯、心情分布、足迹与天气，连续天数与时间跨度始终按全部日记计算。卡片外壳一律 `ExploreCard`（玻璃时为内容玻璃），外观只经 `ExploreAppearanceScope`（没有 scope 时为默认外观，日记本统计页因此不变），`ExploreAppearance.defaults` 必须等于改版前的外观（填充卡片、圆角 24、内边距 18、间距 12、徽章标题、主色）；图表只用强调色的不透明度档位与 `MoodBandPalette` / `CalendarYearPalette`，生长动画只经 `ExploreReveal`。卡片里的跳转只经 `ExploreActionsScope`（探索页为 `ExplorePageActions`，自定义页预览为 `ExploreModuleActions.inert`，点按不跳转）：打开日记经 `openDiaryPage` 并带顺序，按标签搜索经 `openDiaryTagSearch`，看图经 `openImageViewer`（带 `onOpenDiary`），新建经 `runDiaryCreateEntryFlow`；长按（桌面右键）菜单只经 `ExploreModuleMenu`（`ExpressiveMenuAnchor.openAt` 在指针处打开，两项：卡片设置、隐藏此卡片（可撤销））。宽窗口列数只经 `ExploreModulesView.columnsFor`（按实际可用宽度）。自定义页为 `ExploreLayoutPage`（入口：探索页顶栏与设置 → 外观 → 探索页），复用 `StyleEditorScaffold(previewArea: explore)`、`StyleEditorController`（`ExploreLayoutEditorController`）与 `StyleLibraryTab`；预览复用 `ExploreContentView`，示例数据只在 `explore_layout_samples.dart`。视觉规范见 DESIGN.md §5.25。
