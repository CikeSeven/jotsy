# 探索页

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.25。

- 必须：正式探索页经 `ExploreContentView(sliver: true)` 接入外层滚动视口，卡片 / 行 / 错落网格按缓存范围惰性挂载；已访问的行保活，保留随机回顾与轮播状态。禁止把正式页面的全部卡片放进单个 `SliverToBoxAdapter` 或 `shrinkWrap` 网格；设置页的有限预览保留盒布局。sliver 的布局子树只按实际列宽换实例，禁止因逐帧变化的滚动偏移重建列表代理。聚合缓存只比较可见模块的统计选项与数据输入，外观、宽度与顺序变化不得重新扫描全库；照片总数解析只经 `ExploreMediaStats.photoCounts` 在后台计算，媒体卡凑够显示数量后不得继续解码后续日记正文。

- 必须：探索页（`ExplorePage`）由布局里的卡片组成，布局、外观与上次选的统计范围只存于 `ExploreSettings`（单个 JSON 设置键 `app.settings.explore_layout`，`SettingsService` 只保存原文（`exploreLayoutRawNotifier`），与默认相同时删除键；备份字段 `exploreLayoutRaw`，只在备份里有该字段时恢复、导入失败回滚），经 `exploreSettingsProvider` 读取、`saveExploreSettings` 写入，禁止另加零散的探索页设置键。`ExploreSettings` 为当前布局 `ExploreLayout`（卡片顺序与每张卡的显隐 / 宽度 / 选项、范围条开关、外观 `ExploreAppearance`）+ 最多 12 份“我的布局” + 行为 `ExploreBehavior`（统计范围，不随预设 `ExplorePreset` 与布局码 `jotsy-explore:v1:` 改变）；逐字段容错、稀疏写入：认不出的卡片原文保留在原位（`ExploreUnknownModule`），缺少的已知卡片按默认补到末尾，不合法的选项只让这一项回到默认。新增卡片只在 `ExploreModuleId` 与 `ExploreModuleSpec.all` 登记（分组、图标、默认显隐与宽度、是否跟随统计范围 `periodAware`、依赖的功能 `feature`、选项声明 `ExploreChoiceOption` / `ExploreToggleOption` / `ExploreCountOption` / `ExploreMultiOption`），卡片经 `ExploreModuleConfig` 按声明读取类型化的值，编辑页按声明统一画选项，禁止在编辑页为某张卡另写控件。功能开关只经 `ExploreModuleSpec.isAvailable`：纪念日、时间胶囊、日记本、留言、AI 助手关闭时对应卡片不出现，编辑页里显示为禁用并注明原因；草稿卡只在有草稿时出现；探索 Tab 关闭时设置里的“探索页”入口不出现。数据口径：含归档，不含回收站、未解封的时间胶囊与私密日记（概览流 `watchExploreDiaryOverviews`；待解封胶囊与近期带图日记经 `_AppDatabaseExploreOps`，同样经 `_writeDiaryScopeFilter`）；条目只经 `ExploreEntryCache` 解析一次 metadata，聚合只放 `controllers/` 的纯函数（`ExploreDataBuilder` 只算可见的卡片），字数经 `DiaryWordCounts`；跟随统计范围的只有数据看板、标签、写作习惯、心情分布、足迹与天气，连续天数与时间跨度始终按全部日记计算。卡片外壳一律 `ExploreCard`（玻璃时为内容玻璃），外观只经 `ExploreAppearanceScope`（没有 scope 时为默认外观，日记本统计页因此不变），`ExploreAppearance.defaults` 必须等于改版前的外观（填充卡片、圆角 24、内边距 18、间距 12、徽章标题、主色）；图表只用强调色的不透明度档位与 `MoodBandPalette` / `CalendarYearPalette`，生长动画只经 `ExploreReveal`。卡片里的跳转只经 `ExploreActionsScope`（探索页为 `ExplorePageActions`，自定义页预览为 `ExploreModuleActions.inert`，点按不跳转）：打开日记经 `openDiaryPage` 并带顺序，按标签搜索经 `openDiaryTagSearch`，看图经 `openImageViewer`（带 `onOpenDiary`），新建经 `runDiaryCreateEntryFlow`；长按（桌面右键）菜单只经 `ExploreModuleMenu`（`ExpressiveMenuAnchor.openAt` 在指针处打开，两项：卡片设置、隐藏此卡片（可撤销））。宽窗口列数只经 `ExploreModulesView.columnsFor`（按实际可用宽度）。自定义页为 `ExploreLayoutPage`（入口：探索页顶栏与设置 → 外观 → 探索页），复用 `StyleEditorScaffold(previewArea: explore)`、`StyleEditorController`（`ExploreLayoutEditorController`）与 `StyleLibraryTab`；预览复用 `ExploreContentView`，示例数据只在 `explore_layout_samples.dart`。视觉规范见 DESIGN.md §5.25。

- 必须：媒体画廊页（`ExploreMediaGalleryPage`，探索页媒体卡标题行尾进入）按发表日期分组，分组与档位只在 `GalleryZoom`（默认 4 列按天、5 列按天、8 列按月、16 列按年；列数经 `columnsFor` 按网格实际宽度加列，4 列档即 `max(4, 宽 ÷ 120)`）与 `GalleryGroups`；图片索引只经 `ExploreMediaGalleryController`：打开后在后台分批读完全部候选（`getGalleryMediaPage`：只取有封面或正文含 `"image"` 的日记的封面、正文与发表时间，含归档，不含回收站、未解封胶囊与私密日记，范围经 `_writeDiaryScopeFilter`；正文较大时经 `ExploreMediaStats.galleryItems` 在 worker 里解析），每批通知一次、首批到了即显示，禁止改回“滚到底再加载”（快速滚动条要总量与各段日期），必须按发表时间分页（分组只把相邻的同桶媒体并成一组，不重排，网格顺序即列表顺序、看图页下标与之一致）。网格只经 `GalleryZoomableGrid`：整份画廊是一个 `GalleryRowsSliver`（子项为行：日期标题行与格子行，行位置取 `GalleryGrid` 的前缀和、二分查找），禁止改回每组一个 sliver（几千组时每帧逐组布局）或 `PinnedHeaderSliver` 吸顶；分组标题 `GalleryGroupHeader` 随网格滚动、画在页面背景上（经 `AppPageBackdrop.onBackgroundTextStyle`），高度只取 `extentFor`（按天 40、按月 44、按年 52），按天写“今天 / 昨天”或几月几日（往年带年份）+ 星期、按月写年月、按年写年份，行尾为张数；格子 `GalleryCell` 保持轻量（不用 InkWell / LayoutBuilder，圆角为 0 时不裁切），解码边长按 `GalleryZoom.decodeReference`（4 / 5 列按 4 列、8 / 16 列按 8 列）共用缓存。右缘快速滚动条复用 `FastScroller`（按行换算，标签与刻度只在 `GalleryScrollIndex`，`maxSeekItemsPerFrame: double.infinity` 一步到位）。换档只经 `GalleryZoomDriver`：双指捏合时正式网格与目标档预览（不可滚动、停在让手指下那张图对齐的偏移上的同款网格）两层以两指中点为原点随手指实时缩放、交叉淡入（`GalleryPinch`），目标档到原大时就地换档并继续走向下一档（一次手势可连跨几档），松手进度过 0.35 用弹簧走完、否则弹回；换档经 `correctPixels` 把正式网格移到预览的偏移、同一帧撤下预览，禁止换档时换 key 重建正式网格的滚动视图；捏合期间滚动物理吞掉拖动与惯性、点按不算数；桌面另有 Ctrl + 滚轮（以指针为焦点动画换一档）与触控板捏合。顶栏 ⋮ 菜单三个二级菜单：日记本图片（`GalleryNotebookFilterMenu`，全部 / 未收录 / 按树序的日记本，生效可见性为上锁的本子不列出，日记本功能关闭时整项不出现）、时间选择（`GalleryTimeRangePicker` 内联日历，规则只在 `GalleryTimeSelection`；一周起始日与农历、休/班跟随日历显示选项；选月 / 选年层经 `ExpressiveSubmenuItem.onCollapseRequest` 拦下返回与点外部、先退回日期页）与排序（最新 / 最早在前）。筛选（`ExploreMediaGalleryFilter`）只在页面内存活、不持久化，换筛选只经 `ExploreMediaGalleryController.configure`（按代号丢弃在途的旧一轮）；首批到了之后换筛选一直留在网格里（加载与空态画在网格内），禁止让 AnimatedSwitcher 同时挂着两个用同一个 ScrollController 的滚动视图。点按缩略图开看图页，长按直接打开所在日记。

- 必须：数量选项可声明为滑块（`ExploreCountOption(slider: true)`，`values` 只取首尾作为范围，存下的值夹到范围内），编辑页统一画成 `SettingsSliderTile`，拖动中经 `previewOption` 只预览、松手才经 `setOption` 写盘；媒体卡数量即为 1–12 的滑块（旧的 5 / 9 / 12 照旧有效），横条样式把所选张数在一行里等宽排完（每格不超过宫格的格子大小），不再横向滚动。
