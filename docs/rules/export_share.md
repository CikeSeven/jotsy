# 分享与导出

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.9 / §5.10。

- 必须：日记分享统一经预览页的分享面板 `showDiaryShareSheet`（只负责挑选）→ `DiaryShareController`（执行）；分享文字只经 `DiaryShareContent.composeText` 组装为纯文本（社交应用不渲染 Markdown），内容开关只存于 `DiaryShareOptions`（单个 JSON 设置键 `app.settings.diary_share_options`，逐字段容错并随备份导出），地点默认不带。分享到指定应用只经 `DiaryShareChannel`（Android 原生按包名发 Intent），图片先暂存到缓存 `diary_share/`（`DiaryShareFileProvider` 只暴露该目录，禁止直接交出日记原图路径），带图时文字经剪贴板传递；新增目标应用在 `DiaryShareTarget` 登记，并同步 `AndroidManifest.xml` 的 `<queries>` 包名。长图只经 `DiaryPreviewExportController` 截取预览页：截取期间（`capturingLongImage`）预览页不建顶栏、上一篇 / 下一篇、留言区、反向链接与 AI 回应，头图换成静态的——截图边界里禁止留下常驻或浮动的导航（顶栏这类常驻 sliver 会被逐屏截到，拼接后在长图中间重复并盖住正文）；生成后的去处只经 `DiaryLongImageDelivery`（手机为系统分享或“保存长图到相册”，桌面为另存为文件）。相册保存失败的提示只经 `imageExportErrorMessage`。视觉规范见 DESIGN.md §5.9。
- 必须：日记导出统一经 `runDiaryExportFlow`（预览页“更多 → 导出”、日记列表多选、设置 → 数据管理 → 导出日记、日记本头部 ⋮ 菜单“导出成书”四个入口共用）：导出面板 `showDiaryExportSheet` 只负责挑选，生成、保存与分享由 `DiaryExportController` 执行；导出选项只存于 `DiaryExportOptions`（单个 JSON 设置键 `app.settings.diary_export_options`，逐字段容错并随备份导出；“包含留言”`includeComments` 只在开启留言功能时列出，各写出器只经 `DiaryExportLabels.commentMetaLine` / `commentText` 写留言，关闭时产物与原来逐字节一致）。正文一律先经 `ExportBlockParser` 解析为块再交给 `lib/ui/diaries/export/` 下的写出器（当前正文直接经 `ExportBlockParser.parseDocument` 保留嵌套深度；PDF 经 `pdf` 库按块渲染，图片先检查/载入并改成虚拟地址，缺失图片与媒体嵌入先改写，代码行先经 `DiaryExportCodeTheme` 着色）；正文的文字色 / 背景色由 `ExportBlockParser` 读入 `ExportInline.color` / `background`（保留透明度），不支持透明度的格式（PDF、Word）一律经 `flattenDiaryColors` 叠到纸面上再写入。提示块、折叠块、表格各成一种块（`ExportBlockKind.callout` / `toggle` / `table`），每个写出器正式写出、禁止退化为段落；表格文字只经 `ExportBlock.tableTextLines` / `tableCellParagraphs`，行内字号只经 `ExportInline.sizeScale`，提示块的纸面颜色只取 `DiaryCalloutTone.paperBackground` / `paperAccent`（网页深色经 `darkAccent` × `kDiaryCalloutDarkTint`）；认不出但带 delta 的块按段落导出；日记链接只留文字（见日记链接条目）。PDF 直接读原生块树（`prepareBody` 读 `DiaryExportEntry.blocks`，提示块 / 折叠块 / 表格的画法在 `diary_export_pdf_rich_blocks.dart`），禁止写入 emoji 或几何符号字形（内置 HarmonyOS Sans SC 没有：标记画成矢量，提示块不写图标），表格逐行成块以便跨页换页。新增格式只加写出器并在 `DiaryExportFormat` 登记，禁止在页面里另写导出逻辑。导出成书经 `exportNotebookAsBook` 组装 `DiaryExportBook`（`notebookExportBook` / `smartNotebookExportBook`）传入 `runDiaryExportFlow`：顺序以书序为准，面板不显示先后选项；`supportsBookStructure` 的格式（CSV 与 Jotsy 日记文件除外）在选项最前显示“书籍结构”开关（默认开，只对本次有效，不写进 `DiaryExportOptions`），控制器按实际导出的日记解析为 `DiaryExportBookLayout` 交给写出器，写出器只读不改。各格式的书籍结构：PDF 为扉页、带真实页码与点按跳转的目录、章与篇的书签，每章另起一页；Word 为扉页与带链接的目录（不写页码），每章另起一页；网页为扉页、`<nav>` 目录与锚点；Markdown 全书合成一个文件，不写每篇的 front matter；纯文本为扉页、目录与带横线的章节标题。导出的字体跟随 `DiaryTypography`：选了导入字体时只经 `DiaryExportFont.load`（`DiaryFontStorageService.readFontBytes`）读取，PDF 经 `DiaryPdfFonts.load` 嵌入（`extractTrueTypeFace` 取出 TrueType 字面并试解析，CFF 轮廓或解析失败整份回落内置字体，缺字回落内置字体），Word 与网页只按字族名引用、不嵌入字体文件；禁止写出器自行读取字体文件或排版设置。PDF、Word 与网页的段落对齐、首行缩进与应用一致（口径只经 `ExportBlock.firstLineIndentOf`）：首行缩进的字数取导出时的 `DiaryTypography` 快照（带工具栏缩进标记 `ExportBlock.firstLineIndent` 的段落取两字与全局的较大者），只缩进正文段落，居中、右对齐不缩进、两端对齐照常缩进，网页的首行缩进写成以 em 计的 `text-indent`，块比所在容器（正文或折叠列表）深的层级写成每级 1.5em 的左外边距（列表仍由嵌套的 ul / ol 表达）；非文字块退化成的说明行（`ExportBlock.standIn`：PDF 的媒体名称行 `paragraphWith`、日记链接卡片的标题）不缩进；PDF 的列表标记单独一列（折行与文字对齐），待办画成矢量方框、已完成转灰划线，分隔线画成横线；正文图片的尺寸、小图与对齐与应用一致，PDF / Word / 网页只经 `ExportImageBox`（`diary_export_image_box.dart`）换算：原图像素当逻辑像素（纸面 1px = 0.75pt）、从不放大，缩放菜单或导入写入的宽高（`ExportBlock.imageMaxWidth` / `imageMaxHeight`，经 `diaryImageSizeLimits` 读出）与版心只作上限，小图（`imageThumbnail`）见方、cover 裁切（长图保留顶部），边长与应用同一口径（`diaryThumbnailExtentFor`：一排三张放得下，最大 120px）；正文顶层连续的小图与应用一样三张一排：分排只在解析时经 `diaryThumbnailRowsBy` 按顶层块算出、标在 `ExportBlock.thumbnailRow`（导出时略过的块照样隔开前后两串，容器块里的小图为 null、一张一行），写出器只经 `exportThumbnailRowEnd` 取一排、禁止自行按相邻小图分组：PDF 一排是一个不可拆分的 `Row`（`buildDiaryPdfThumbnailRow`，格间 6pt），Word 一排是一段里的几张行内图片、中间隔一段字符间距（`thumbnailRowParagraph`，写不进去的占位排在这一排之后），网页一排是一个弹性布局的 `figure.thumbs`（单独一张也是，`img.thumb` 边长随宽度一起收缩、不折行），整排都按第一张的对齐；读不出或关掉图片时这一排变短、不留空格；Markdown 与纯文本仍一张一行，对齐取块的 `align`（默认靠起始侧）；PDF 的标题与应用同一字阶（正文字号 × `kDiaryHeadingScales`，加粗），上下标倍数取 `DiaryScript`；PDF 的文字块一律撑满版心宽度再排版（pdf 库的 `RichText` 在宽松约束下只取文字宽度，单行段落的对齐会失效），正文、标题与表格格子都经 `diaryPdfLineSplitter` 让中日韩文字逐字断行（带避头尾标点；pdf 库只在空白处换行，整段中文会被首行缩进挤到下一行）：用这个切词器的 `RichText` 里每段文字都须经 `diaryPdfTextSpan` 生成。未解封的时间胶囊在任何导出格式中都不导出（完整备份除外）；导出文件不得写出设备私有路径，媒体以包内相对路径或内嵌方式交付；批量导出的媒体一律按文件流式打包（`DiaryExportBundleFile.file`），禁止把全部照片读进内存，PDF 这类只能整份持有图片的格式须设总量上限并提示。视觉规范见 DESIGN.md §5.10。
