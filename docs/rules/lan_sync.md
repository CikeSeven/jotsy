# 局域网同步

> 专题约束，与 AGENTS.md 同等效力；改动本主题前先读本文件，新规则写在这里。界面规格见 DESIGN.md §5.28。

- 必须：协议、合并判定、写入与本机状态以 `docs/lan_sync.md` 为准，改同步口径时同步更新它。
- 必须：同步日记（含回收站）、标签、日记本、留言、模板、纪念日、这天的心情、待办、托管媒体；不同步草稿、导入的字体文件、心情选项、本机偏好、网盘凭据、应用锁与密码、AI 服务商 / 密钥 / 用量 / 记录。
- 禁止：把同步当导入：不经 `chooseBackupImportMode` / `BackupMerge`，不调用会刷新 `updatedAt` 或清掉归档 / 删除标记的写库函数。
- 必须：规划器保持纯函数（不碰数据库、文件、时钟与随机数）；写库只经 `SyncApplier`，按原值写、前置条件不符即跳过、单个事务。
- 禁止：悄悄丢掉本机编辑：正文两边都改过时另存冲突副本，私密不外露、胶囊不提前解封。
- 必须：删除只在对方墓碑覆盖时传播；大量删除与无共同祖先的冲突须经用户确认（默认“保留，并恢复到另一台” / “保留两份”），自动同步遇到即中止、不写入。
- 必须：设备绑定的状态（身份私钥、配对设备、历史、墓碑、同步记录）只存不随备份的 `stateDir`；本功能不新增设置键、不提升 schema。
- 必须：覆盖恢复成功后经 `DataArchiveService.replacedAllListeners` 清掉同步状态。
- 必须：设置只在两端都开“同步设置”时同步；导入字体按内容引用 `jotsy-font:<sha256>` 同步，禁止按本机 id。
- 必须：标签顺序与数据类功能开关始终同步，数据类开关只同步开启、禁止改成双向；思维导图开关不同步。
- 必须：握着可编辑内存副本、整份写回的页面与面板必须登记为 `EditingSessionRegistry` 的阻塞者；有阻塞者时不发起同步、对方请求以忙碌拒绝，撤销提示开着时不写入。
- 必须：新增一次性读取同步数据的 provider 必须加进 `syncedDataRefreshProvider` 的清单。
- 必须：无已配对设备时只在同步页打开期间联网，有则只在前台；禁止后台常驻；传入配对只在同步页打开时接受。
- 必须：配对只经核对码或一次性二维码（2 分钟、扫过即失效）；本机有应用锁或上锁日记本时确认前先经 `IdentityVerifier` 验证。
- 必须：界面只经 `LanSyncUiController`，禁止直接调用引擎；平台门控只经 `AppPlatform.supportsLanSync` / `supportsQrScan`（扫码只在 Android，不依赖 Play 服务）。
