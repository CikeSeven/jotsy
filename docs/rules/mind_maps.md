# 思维导图

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.37。

- 必须：导图就是日记的正文，不另建表：正文块 `mind_map`（`kDiaryBlockMindMap`，属于 `kDiaryEmbedBlockTypes`，从不挂子块）的 `data.map` 是导图文档，`data.mode == "page"` 时整篇日记就是这张导图（导图日记），没有 `mode` 是普通日记里嵌入的导图卡片。导图日记只按块上的标记识别（`diaryMindMapPage` / 编辑页的 `_isMindMapDiaryDocument`：顶层第一块是 page 模式的 `mind_map`、其余都是空段落），禁止改成按结构推断（普通日记删到只剩一张嵌入导图时仍是普通日记）。导图由此随日记备份、恢复、合并、进回收站、收进日记本、带标签与留言，局域网同步走日记的 content 分面（规范形式不变，不提升 `kSyncFormatVersion`），旧版本原样保留认不出的块。
- 必须：导图文档的模型与编解码只在 `lib/core/database/mind_map/`：键名 `mind_map_schema.dart`；不可变模型 `mind_map_document.dart`（`MindMapDocument` / `MindMapNode`，逐字段容错，认不出的键原样留在 `extra` 写回，结构 / 主题 / 连线 / 间距只存 id 原文，缺少或重复的节点 id 按树中位置补确定的 id，超过 `kMindMapParseDepthLimit` 的子树原文保留）；编辑操作只经纯函数 `MindMapOps`（`mind_map_ops.dart`：只沿路径复制、做不到时原样返回，新节点 id 经 `newMindMapNodeId`，编辑与导入受 `kMindMapMaxNodes` / `kMindMapMaxDepth` 限制，读取时不截断已有数据）；文字形态 `mind_map_text.dart`（纯文本镜像 `mindMapPlainText`、大纲 `mindMapOutlineLines` / `mindMapOutlineText`、缩进大纲解析 `mindMapNodeFromOutline`、`mindMapIsBlank`）；正文块的构造与识别 `mind_map_blocks.dart`。禁止页面、导出或导入自行解析 `data.map`。
- 必须：导图在正文其余模块里的口径：纯文本镜像（`content_text`，搜索、字数、AI 读日记都用它）经 `diaryBlocksPlainText` 写入全部节点文字（含收起的、备注与标签）；只有一个空根节点的导图不算内容（`diaryBlocksHaveVisibleContent` / `DiaryEditorController.hasContent`，新建页转成导图后什么都没写不留草稿）；分享文字（`diaryBlocksToQuillOps`）与导出（`_parseNativeBlocks` → `_mindMapBlocks`）按大纲写出，嵌入导图先写加粗的中心主题，导图日记的中心主题就是标题、不再重复；智能日记本与搜索筛选的“有思维导图”是 `NotebookMediaKind.mindMap`（LIKE `"type":"mind_map"`，导图日记与嵌入导图都命中）。节点链接用日记链接的内部地址写在 `href` 键里（反向链接的 LIKE 天然命中）。
- 必须：导图日记的标题列就是中心主题的文字（压成一行、截到 200 字），编辑页经 `_syncTitleFromMindMap` 同步，禁止另设导图标题。编辑页（`EditDiaryPage`）在正文是导图日记时整页换成导图工作区（`edit_diary_mind_map_flow.dart`），导图的改动经 `_EditDiaryMindMapSession.write` 写进正文里那一块（`recordUndo: false`，导图有自己的撤销），草稿 / 编辑的自动保存、手动保存、发布与“返回时直接发表”都沿用文字日记的链路；新建页正文为空时的“思维导图”按钮（`DiaryMindMapEntryChip`）经 `_convertToMindMap` 转换，还只有中心主题的导图（`mindMapHasOnlyRoot`）经 `_convertBackToText` 转回，两者都经 `restoreContent`（不进正文撤销栈）。
- 必须：普通日记里的嵌入导图只经 `diary_mind_map_editing.dart`：`/` 命令插入（`insertDiaryMindMap`，只在写日记的正文里有，模板正文没有）、全屏编辑（`editDiaryMindMap` → `MindMapEditorPage`：编辑期间每次改动静默写进块，关闭时先静默换回打开前再把最终内容写成一步撤销）、删除（与日记链接卡片同一口径）。块的显示只经 `DiaryMindMapBlockBuilder`（page 模式为 `MindMapStage`，嵌入为 `MindMapEmbedCard`，都包 `DiaryEmbedContent`）。
- 必须：导图界面在 `lib/ui/mind_maps/`：布局引擎 `layout/`（`layoutMindMap`：纯计算，结构只经 `MindMapStructure`，横向结构按锚线上下分别计算子树占用（下划线节点的锚线是下划线），同一输入结果确定、节点不重叠，测试兜底）、绘制只经 `paintMindMap`（画布、缩略图与样式面板预览共用，转场插值只经 `MindMapFrame.lerp`）、视口只经 `MindMapViewportController`、编辑会话只经 `MindMapEditingController`（撤销栈存文档快照，上限 100 步，同一节点连续输入合并）、拖动落点只经纯函数 `planMindMapDrop`、命中与方向键只经 `mind_map_hit_test.dart`。导图编辑页、嵌入导图编辑页与查看页共用 `MindMapWorkspace` 与外框 `MindMapPageScaffold`，禁止另写画布或工具栏。节点文字的输入框（`MindMapNodeEditor`）用普通键盘并传 `appTextContextMenuBuilder`；键盘高度只由工作区里只读 `viewInsets` 的一小层交给画布，禁止在工作区或页面的 build 里读 `viewInsets`。
- 必须：导图的主题配色只经 `MindMapThemeSpec`（内置主题，只存种子色与各层级的形状 / 填充方式）→ `MindMapPalette`（种子色经 `ColorScheme.fromSeed(dynamicSchemeVariant: fidelity)` 按明暗换算，跟随应用的主题由应用主色转色相推出），节点外观只经 `MindMapStyleResolver`；节点自定义颜色存 `#AARRGGBB`，自定义底色上的文字取对比更强的一侧。
- 例外：导图主题的种子色（`mind_map_themes.dart`）是内容配色，与提示块底色档位、代码块配色同理不算硬编码颜色；但颜色一律经 `MindMapPalette` 按明暗换算，禁止直接涂种子色，禁止渐变与写死黑白。
- 必须：桌面快捷键只在 `AppPlatform.isDesktop` 生效、编辑文字时一律交给输入框（见 `MindMapWorkspace` 的类注释）；滚轮平移、Ctrl / ⌘ + 滚轮缩放只经 `pointerSignalResolver`；右键菜单经 `ExpressiveMenuAnchor.openAt`。手机上长按节点拿起拖动（`mediumImpact`，落点变化 `selectionClick`），长按不动弹出菜单。
- 必须：功能开关 `AppFeatures.mindMaps`（默认开）只隐藏创建入口：新建页的按钮、`/` 命令与新建规则里的“有思维导图”（已选中的照常显示）；已有的导图日记与嵌入导图照常显示与编辑。它是界面类开关，但不进 `kSyncUiFeatures`（加进去会改变设置分面的规范形式），只在本机与备份里。
- 必须：节点的富内容只存在节点自己的字段里：贴纸 `icons`（`分组:取值`，只经 `MindMapMarker`：同组互斥、再点取消，`emoji:` 可放任意 emoji、可以有多个，认不出的不显示但原样保留）、标签 `labels`、备注 `note`、链接 `href`（网址，或日记链接的内部地址 `jotsy://diary/<id>`，打开只经 `openDiaryLinkTarget` / `openExternalLink`）、待办 `task.done`；节点框里的排版只经 `measureMindMapNodeContent`（一行“待办框 · 贴纸 · 文字 · 进度 / 备注 / 链接标记”，下一行标签），绘制、命中测试与文字输入框的位置都读它，禁止各处另算偏移。父主题的进度环只由子孙待办经 `mindMapTaskProgress` 推出，不另存。节点样式（形状、底色、文字色、分支色、粗 / 斜 / 删除线、字号）存在 `style` 里，颜色存种子色、显示时经 `MindMapPalette.custom` 按明暗换算。
- 必须：大纲视图（`MindMapOutlineView`）与画布编辑同一份文档、同一个选中与编辑状态，缩进 / 取消缩进 / 上下移只经 `MindMapOps.indent` / `outdent` / `shift`；复制、剪切、粘贴只经 `MindMapClipboard`（复制时整棵子树留在进程里，同时把大纲文本 `mindMapSubtreeOutline` 写进系统剪贴板；粘贴时剪贴板还是那段文本就贴回完整子树，否则经 `mindMapNodesFromOutline` 按缩进解析）。单个主题的面板（插入、主题样式、图标、标签、备注、链接）只在 `sections/mind_map_node_sheets.dart`，都经 `showAppModalBottomSheet`。
- 必须：导图的文件格式只在 `lib/core/services/mind_map_io/`（纯 Dart）：Markdown（`mindMapToMarkdown` / `mindMapFromMarkdown`）、OPML 与 FreeMind（`mind_map_xml_formats.dart`）、XMind（`mind_map_xmind_io.dart`：写 2020 起的 `content.json`，读 `content.json` 或 XMind 8 的 `content.xml`），导入只经 `importMindMapFile` 按扩展名分派。贴纸与结构的对应只在各格式自己的映射表里（`_xmindMarkers` / `_xmindStructures` / `_freeMindIcons`），认不出的忽略；日记链接只在应用里打得开，导出时不写；坏文件一律返回 null、禁止抛出。
- 必须：导出与导入的流程只经 `mind_map_io_flow.dart`：图片只经 `renderMindMapPng`（与画布同一 `paintMindMap`，当前明暗与配色、页面底色，两倍清晰度、最长边 8192），PDF 是一页按图片大小的 `renderMindMapPdf`；生成期间盖 `runWithActionLoadingOverlay`，文件先暂存到缓存目录 `mind_map_export/` 再交给分享、`BackupFileSaveService.saveFile` 或相册（`ImageExportService.saveBytesToGallery`，只对图片、只在 `AppPlatform.savesImagesToGallery`）。导出面板只经 `showMindMapExportSheet`（导图日记的 ⋮、嵌入导图编辑页的 ⋮、查看页顶栏、预览页 ⋮ 共用）。导入（`importMindMapFromFile`，⋮ 与起步卡）用“任意文件”再按扩展名检查（Android 认不出这些类型），导图不止中心主题时先确认，替换经 `MindMapOps.replaceRoot`（重新分配 id、受节点数 / 深度 / 字数上限约束）写成一步撤销。
- 必须：文字日记转导图只经纯函数 `mindMapFromDiaryBlocks`（`lib/core/database/mind_map/mind_map_from_blocks.dart`：标题定层级，列表按嵌套挂在最近的标题下，段落、引用、提示块各成一个主题，待办保留勾选，嵌入导图并成子树，代码块、表格、媒体与分隔线不进导图），入口为预览页 ⋮ 的“转为思维导图”（功能开着、不是导图日记、有文字时出现），经 `openMindMapFromDiary` 打开新建页生成一篇新的导图日记，原文不动。
