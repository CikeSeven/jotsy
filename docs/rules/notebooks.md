# 日记本

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.16。

- 必须：日记本存 Drift `notebooks` 表（schema v13；业务 id `notebookId`；`kind`（manual / smart）与 `visibility`（normal / hidden / locked）是独立列，供 SQL 过滤，其余可演进设置（简介、图标、颜色、封面、章节、排序、写作目标、默认模板、智能规则）只放 `payload`，格式与逐字段容错见 `NotebookPayload`）；成员关系存 `diary_notebooks` 关联表（两端都是本地 id，带 `chapter_id` 与本内 `position`），一篇日记可同时在多本里（多对多），移出日记本不删除日记。库里从不开启外键，彻底删除日记、删除日记本、合并日记本与覆盖恢复等每条删除路径都必须在同一事务里手动清理关联行。只有手动日记本有成员行；智能日记本的成员只经 `NotebookRuleSet`（最多 12 条，认不出的规则原文保留为 `NotebookUnknownRule`）→ `compileNotebookRules` 编译为 SQL 现算（首页范围、头部统计与书架篇数共用 `compileNotebookPayloadRules`），规则里的标签只存名称、禁止存本地 id，空规则与认不出的规则一律编译为不匹配，未解封的时间胶囊只按标题、日期与置顶参与匹配；智能本可经 `convertSmartNotebookToManual` 转为普通本。私密：只有手动日记本能设为隐藏 / 上锁（智能本写入时一律存 normal）；私密日记（在任一手动、可见性非 normal 的本子里）只经统一谓词 `_privateDiaryExclusionSql` 从所有全局查询（全部日记、搜索、探索、日历、归档、导出候选等）中排除，只在它所在的私密本里出现；新增全局日记查询必须经 `_writeDiaryScopeFilter`（或该谓词）过滤，并把 `notebooks` 与 `diary_notebooks` 加进 `readsFrom`（`_diaryScopeReadsFrom`）；回收站与按 id 直接打开不过滤；认不出的可见性按 locked 解读（`NotebookVisibility.fromName`）。上锁：进入上锁本子只经 `authorizeNotebookEntry`（`DeviceAuthService`，与应用锁同一口径，设备没有锁屏密码时不放行）；编辑、合并、转换、删除这类会露出内容或设置的操作（`notebookRevealingActions`）一律经 `runNotebookAction` 先验证，禁止绕过；首页停在上锁本子时切到后台即由 `NotebookLockLayer` 盖住整个应用，回来须重新验证。首页范围：当前所在的本子与章节只存于 `homeNotebookScopeProvider`，每次切换写进单个本机偏好键 `app.settings.home_last_scope`（`HomeNotebookScopeMemory`，不随备份导出、不同步，禁止另加设置键），冷启动只经 `homeNotebookScopeRestoreProvider` 恢复上次所在的范围（启动门控与启动预热 `startupDiariesProvider` 等它完成、按恢复的范围预热首屏；日记本功能关闭、本子已不存在时静默回到全部日记，章节已不存在时回到这本的全部章节，生效可见性为上锁时以重锁状态恢复、由 `NotebookLockLayer` 从首帧盖住），日记页的实时解析与恢复共用 `resolveHomeNotebookScope`，日记本到查询范围的换算只经 `resolveNotebookScope`；书架“全部日记”下面的“未收录”（`HomeNotebookScope.unfiled`，范围 `DiaryListScope.unfiled`：不在任何手动日记本里的日记，智能本不算收录）同样只在这个 provider 里，范围身份统一看 `HomeNotebookScope.key`；首页之上的页面打开某本经 `openNotebookFromAnywhere`。收录：成员的增删与移动只经选本面板 `showNotebookPickerSheet`（三态）+ `NotebookMembershipOps`（撤销信息在写入时一并取得）、发布面板与编辑页的日记本行（`PublishNotebookTile`，随日记保存在同一事务里改写，仍选中的本子保留章节与位置）以及数据库层的成员 ops，禁止页面直接写 `diary_notebooks`；首页多选与目录页的移出必须带撤销（`persist: false`）。在本子里写：首页停在某本普通日记本时新建经 `runDiaryCreateEntryFlow(notebookId:, chapterId:)`，新建空白时套用这本的默认模板（`NotebookPayload.templateId`，优先于 `autoApplyCandidates`；用户在草稿面板选了模板时以所选为准），续写已有草稿原样打开。章节与书序：章节只有一层，存于 payload（`NotebookChapter`），删除章节时其中的日记回到“未分章”；手动书序只经目录页（`NotebookContentsPage` → `NotebookContentsController`）由 `reorderNotebookEntries` 一次写回整份顺序；本子排序为书序（`NotebookSort.book`）时按章节顺序 + 本内位置排，列表排序与置顶不生效，智能本没有书序。备份：两张表随完整备份导出与覆盖恢复；合并经 `BackupNotebookMerge` 按 `notebookId` 匹配（本机没有的新增；合并保留本机定义，合并并覆盖替换定义、保留本机书架顺序），只写本次实际写入的日记的成员关系，章节只认目标本现有的章节，智能本从不写关联行；日记包（`BackupPayload.captureDiaries`）只带包内日记所在的手动本及其成员行。封面只经 `DiaryCoverStorageService` 拷贝到私有目录（从本子的日记里选图同样拷贝一份，经 `NotebookEditorController.setCoverFromFile`，禁止直接引用日记原图），随备份作为媒体搬运（`rebindNotebookPayload`），`DiaryMediaCleanupService` 把日记本 `payload` 当作引用来源。封面版式、纹理与取景只存在 payload 的 `coverStyle`（`NotebookCoverStyle`，稀疏写入、逐字段容错），禁止另加设置键或列；渲染只经 `NotebookCoverTile`（完整封面按版式经 `NotebookCoverLayoutBody`，小封面经 `NotebookCoverMini`）与 `NotebookCoverImage`（取景），纹理只画在露出底色的部分，任何版式都不用渐变遮罩；换图或移除封面图时取景重置。导入与导出成书见导入、导出两条规则。统计与目标：统计页 `NotebookInsightsPage` 与头部卡片的字数只经 `DiaryWordCounts`（`TextStats` 口径）；写作目标（`NotebookGoal`）只对手动本计算进度，不做提醒通知。日历只支持按手动本筛选（见日历规则）。嵌套：上级存在 `notebooks.parent_id`（上级的业务 id，null 为顶层），最多 `kNotebookMaxDepth`（3）层；只有手动本能当上级，智能本只能当子本。层级口径（有效上级、层数、成环、生效可见性）只在数据库层的 `NotebookHierarchy`，界面一律经 `NotebookTree`（`notebookTreeProvider`）读取，禁止页面自行沿 `parentId` 遍历；能当上级的只经 `NotebookTree.parentCandidatesFor`（与 `moveNotebook` / `createNotebook(parentId:)` 的校验同一口径），换上级只经 `moveNotebook`（`NotebooksController.move`、编辑页保存），不合法时抛错、界面只提示。父本的列表、头部统计与书架篇数汇总全部子孙（`resolveNotebookScope(tree:)` / `watchNotebookDisplayCount`），比父本更私密的子本不汇总。私密继承：上锁与私密判断一律看 `NotebookView.effectiveVisibility`（自己与上级里最严格的一档），编辑页的隐私选项只编辑自己的 `visibility`；同一上锁范围（`NotebookTree.lockRootOf`）里切换不重复验证（`notebookSwitchRequiresAuth`），往上走不验证。删除时子本整棵提到上一层（`NotebookDeletion.childIds`，撤销挪回），合并时源本的子本改挂到目标本，批量写入后经 `repairNotebookHierarchy` 修复。书架只列顶层（置顶除外），有子本的封面经 `NotebookStackedCover` 叠放；管理页按树序缩进，拖动（手柄按住即拖，或长按整行）只在同一上级的兄弟之间重排（`notebookSiblingOrderAfterDrag` → `notebookOrderAfterReorder`）；有子本的行可收起子孙，收起状态只在内存 `notebookManageCollapsedProvider`（禁止加设置键），被收起的行留在列表里只收到 0 高度（`notebookFoldedIds`，行号不变、落点换算照旧），拖动有子本的本子时子孙在拖动期间收进来、放下后展开，本子换了上级或新出现在收起的上级下面时那些上级自动展开（这套时序只在 `NotebookManageFolding`）；选本面板、发布面板子页与上级选择面板按 `notebookTreeRows` 的树序缩进；首页头部经 `NotebookBreadcrumb` / `NotebookChildrenGrid` 在上下级之间切换，系统返回在子本里先回到上级；子本网格的列数与折叠只经 `NotebookChildrenLayout`（按实际可用宽度），展开状态只在内存 `notebookChildrenExpandedProvider`（禁止加设置键）。管理页为设置 → 日记本（`NotebooksPage`）。视觉规范见 DESIGN.md §5.16。
