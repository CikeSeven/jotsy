# 日记本

> 专题约束，与 AGENTS.md 同等效力；改动本主题前先读本文件，新规则写在这里。界面规格见 DESIGN.md §5.16。

## 数据
- 必须：日记本存 `notebooks` 表（类型与可见性为独立列，其余设置只放 `payload`）；成员存 `diary_notebooks`，多对多，移出不删日记。
- 必须：只有手动本有成员行；智能本按规则（最多 12 条）现算，空规则与认不出的规则不匹配，规则里的标签只存名称。
- 必须：成员只经选本面板、日记本行与数据库层成员 ops 写入，禁止页面直接写 `diary_notebooks`；首页多选与目录页的移出带撤销。
- 必须：章节只有一层，删除章节时日记回到“未分章”；手动书序只经目录页整份写回；智能本没有书序。
- 必须：目录页整份目录或单章转移到子日记本只经 `transferNotebookContentsToChild` 在同一事务里完成（仅限手动子孙本，保留章节与书序，按目录页私密口径过滤，目标处于另一上锁范围时先经 `authorizeNotebookEntry` 验证）。
- 必须：嵌套最多三层，只有手动本能当上级；层级只经 `NotebookTree` 读取、`moveNotebook` 改写，禁止页面自行沿上级遍历。
- 必须：删除本子时子本整棵提到上一层，合并时子本改挂到目标本；父本汇总全部子孙，比它更私密的子本不汇总。
- 必须：封面图只经 `DiaryCoverStorageService` 入库（拷进私有目录，内容相同时共用已有文件，见 `media.md`「重复的图片与视频」），禁止直接写入日记或相册原图的路径；版式、纹理与取景只存 payload，换图时取景重置。
- 必须：写作目标只对手动本计算进度，不做提醒通知。

## 私密与上锁
- 必须：只有手动本能设隐藏 / 上锁；认不出的可见性按上锁处理；生效可见性取自己与上级里最严格的一档。
- 必须：私密日记只经 `_privateDiaryExclusionSql` 排除，新增全局日记查询必须经 `_writeDiaryScopeFilter` 过滤并把 `notebooks`、`diary_notebooks` 加进 `readsFrom`（`_diaryScopeReadsFrom`）；回收站与按 id 直接打开不过滤。
- 必须：私密日记只在所在私密本里出现；回收站与纪念日关联只显示占位。
- 例外：搜索页的全局搜索（`DiaryGlobalSearchScope`）含隐藏本、只排除生效上锁的；其他全局查询禁止改用这个范围。
- 必须：进入上锁本只经 `authorizeNotebookEntry`（同应用锁验证，见 `app_lock.md`），编辑、合并、转换、删除经 `runNotebookAction` 先验证。
- 必须：同一上锁范围内切换、往上走都不再验证；停在上锁本时切到后台即重锁（应用自己打开的选图、拍照不算）。

## 首页范围
- 必须：当前本子、章节与“未收录”只存于 `homeNotebookScopeProvider`，切换时写本机偏好 `app.settings.home_last_scope`（不随备份、不同步）。
- 必须：冷启动恢复上次范围后才预热首屏；本子不在或功能关闭时静默回到全部日记，上锁的以重锁状态恢复。
- 必须：“未收录”是不在任何手动本里的日记；系统返回只在子本里先回上级，顶层本子与未收录不拦（#196）。
- 必须：在普通本里新建时带上本子与章节，新建空白套用这本的默认模板（优先于自动套用，面板里选的模板优先）。
- 必须：列出日记本供挑选的地方一律经 `notebookTreeRows` 树序缩进、`NotebookFoldableRows` 折叠，禁止平铺或自写折叠。
- 例外：首页日记本卡组经 `buildNotebookDeckEntries` 分组、按 `notebookSubtreeRows` 树序，子本在卡组里原地展开。
- 必须：各处收起 / 展开状态只在内存，禁止加设置键。

## 日记本卡组
- 必须：首页切换范围只经日记本卡组；日记列表右滑与切换胶囊打开同一个卡组，选中经日记页的范围控制器（验证、退出多选、列表过渡）。
- 必须：卡组经 `OverlayPortal` 画在首页路由之上，验证、编辑、管理等推入的页面照常盖在它上面；浮层子树结构恒定，禁止增删面板前面的兄弟节点。
- 必须：卡组看得见时系统返回、Esc 与点遮罩先收起它（长按菜单开着时先收菜单）；切 Tab、关闭日记本功能、外部改了范围时立即收起。
- 必须：长按菜单开着时点卡组里任何一张都只收起菜单，不切换。
- 必须：卡组收回途中浮层放行指针、只接住重新拉开的拖动，往回的滑动与点按落到页面（首页翻页不被收回动画挡住）；收回左缘越过终点即收尾。
- 必须：打开时为露出当前本子自动展开的上级只算一次、并进展开状态，之后照常能收起。
- 禁止：多选、标签栏展开时响应右滑；鼠标与触控板拖动、系统手势边缘里起手触发右滑（桌面经切换胶囊打开）。
- 必须：卡片位置、抬起与发牌只改绘制变换（`NotebookDeckMotion` + Flow），禁止逐帧重建或重排卡片。

## 备份
- 必须：两张表随完整备份导出与覆盖恢复；合并按 `notebookId` 匹配，“合并”保留本机定义，“合并并覆盖”替换定义、保留书架顺序。
- 必须：合并只写本次写入的日记的成员行，章节只认目标本现有的；日记包只带包内日记所在的手动本；封面随备份作为媒体搬运。
