# 平台门控、宽窗口与桌面键鼠

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.22。

- 必须：平台差异与功能门控只经 `AppPlatform`（`lib/core/services/app_platform.dart`，由 `defaultTargetPlatform` 推出，测试用 `debugDefaultTargetPlatformOverride` 切换），禁止 UI 与功能代码直接判断 `Platform.isXxx`；只有原生 MethodChannel / 插件调用旁保留运行时 `Platform` 判断兜底。桌面不可用的能力必须在 `AppPlatform` 登记为 `supportsXxx` 并隐藏入口或给出桌面替代：保存到相册 / 导出改为“另存为…”（`DesktopSaveService`，file_picker 只取路径、文件自己流式复制）；Linux 没有系统文件分享，分享面板改为复制文字与保存图片；附件交给系统打开文件；Linux / Windows 不能内嵌播放视频，正文改为交给系统播放器的 `DiaryVideoPosterCard`（尺寸与播放器一致）；长图拼接非手机在 Dart 中完成（`scrolled_boundary_capture.dart`）；Linux 无系统身份验证，应用锁与日记本上锁只能用应用密码（未设时停用，见 `app_lock.md`），指纹 / 面容快捷解锁只在 `supportsBiometricOnly`（Android、iOS、macOS）；自动定位与天气、这天的照片、云端笔记登录、应用内安装只在手机（安装只在 Android，桌面检查更新后在浏览器下载本平台安装包）；Linux 无录音；局域网同步只在 `supportsLanSync`（Android 与桌面，iOS 不支持），扫码配对只在 `supportsQrScan`（Android，桌面只显示二维码给手机扫）；选中文字的分享只在手机（`supportsTextShare`），其他应用的文字操作只在 Android（`supportsProcessText`）；应用锁的“锁屏时上锁”与防截屏只在 Android（`supportsScreenOffLock` / `supportsSecureScreen`），桌面改为“闲置时上锁”（`supportsIdleLock`，手机不提供：软键盘输入不产生指针与键盘事件）。待办提醒：手机交给系统定时（`supportsBackgroundReminders`，应用没在运行也会响），桌面只在应用运行期间按时弹出（进程内计时，见 `todos.md`），锁屏隐藏内容只在 Android（`supportsNotificationVisibility`）。屏幕自带的圆角只在 Android 读取（`supportsDisplayCorners`，`DisplayCorners`），其他平台卡片展开的整页终点为直角。托管数据（数据库、媒体、录音、封面、备份暂存）的根目录只经 `appDataRootDirectory`（手机为应用文档目录，桌面为应用支持目录），禁止服务自行用 path_provider 取根目录。
- 必须：宽窗口布局按窗口宽度而不是平台分档，只经 `AppBreakpoints`（compact < 600、medium 600–1023、expanded ≥ 1024）；compact 必须与改版前的手机布局逐像素一致。内容宽度只取 `AppContentWidth` token（reading / form 720、editor 760、explore 960、grid 1200、navRail 96），禁止散写最大宽度。滚动内容以 `AppContentWidth.gutter` 作左右内边距居中（滚动视图本身铺满，滚动条与留白处的滚轮留在窗口边缘），不滚动的内容用 `CenteredContent`；一律按实际可用宽度（`LayoutBuilder`）判断，禁止用 `MediaQuery` 屏宽（宽窗口首页左侧有导航栏）。首页 ≥ 600 用 `HomeNavRail` 取代底栏（导航项自上往下排，设置不在栏内；跨断点保留各 Tab 页面状态）；日记 Tab ≥ 1024 为列表–阅读双栏（`DiariesPageLayout` 排布，右栏 `DiaryDetailPane` 经 `DiaryPreviewView(host:)` 嵌入预览，选中只在页面内存、不持久化、与多选互不影响）；`DiariesListSection` 的调用方必须传 `availableWidth`。新增二级页经 `FormWidth` + `AppTopBar(contentMaxWidth:)` 限宽，标题栏随内容列内收。视觉规范见 DESIGN.md §5.22。
- 必须：键鼠专属行为只在 `AppPlatform.isDesktop` 生效，手机上结构与交互不变：首页快捷键 Ctrl / ⌘ + N（新建；在待办 Tab 为新建待办）/ F（搜索）/ 1–4（切 Tab，`home_page_shortcuts.dart`）；日记双栏 ↑← / ↓→ 换篇、Enter 编辑、Delete 删除（确认 + 撤销）、Esc 清除选中（`DiariesReadingSelectionController`）；预览页与看图页翻页只经 `DesktopPageArrows`（悬停按钮）/ `DesktopPageKeys`（←/→、PageUp/PageDown、Esc）；卡片右键菜单经 `DiaryCardContextMenu`（`ExpressiveMenuAnchorState.openAt` 在指针处打开）；正文的复制 / 粘贴菜单在桌面选中时不出现，只在右键时经 `diaryEditorContextMenuBuilder`（上游 `contextMenuBuilder`）弹在指针处，手机仍为选中后自动浮出（`DiaryEditorSelectionToolbar`）；Ctrl / Shift + 点按多选（`diary_pointer_selection.dart`）；桌面关闭卡片左滑归档（手机上的列表左滑只经 `DiarySwipeActionItem`：松手时已越过阈值且手指总位移以横向为主才生效，不按甩动速度触发，背景按卡片圆角挖空裁切，禁止改回 `Dismissible`）；新增横向滚动条带必须套 `DesktopHorizontalScroll`（鼠标拖动；普通滚轮交给页面纵向，Shift + 滚轮横向）；文件拖放插入（desktop_drop）只在编辑页正文（`DiaryEditorDropTarget`）；编辑器悬浮工具栏在桌面常显、“始终显示工具栏”开关在桌面隐藏，Esc 返回；Linux 的工具栏设置与预览不列出录音。
- 禁止：Android 的预测性返回（侧滑返回时缩小当前页、露出上一页或桌面的预览）。页面转场只经主题的 `appPageTransitionsTheme`（`lib/app/theme/theme.dart`，Android 为去掉跟手预览、`delegatedTransition` 置空的 `NoPredictiveBackPageTransitionsBuilder`，普通进出页面动画与框架默认一致；例外：从卡片点开日记经 `ContainerTransformPageRoute` 展开，只在 `AppPlatform.supportsContainerTransform`（iOS / macOS 以外）时使用——那两个平台保留 Cupertino 转场的左缘侧滑返回；它被普通页面盖住时仍按主题转场让开，见 `diary_list_preview.md`），AndroidManifest 的 `enableOnBackInvokedCallback` 保持 `"false"`，`MainActivity` 不转发返回手势进度；侧滑与返回键一样松手后才返回（`android_no_predictive_back_test.dart` 兜底）。
- 必须：Android 上在第一个路由按返回、Dart 已无可返回时，应用只退到桌面（`MainActivity.leaveToHomeScreen` 经 `moveTaskToBack(true)`，与按主屏键相同：进程、引擎与当前页面状态都留着），不结束 Activity；只在它是任务根时这样做，否则照旧结束、回到启动它的应用。禁止在 Dart 里调用 `SystemNavigator.pop` 或 `exit` 来“退出应用”（#196）。
