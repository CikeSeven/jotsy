# 待办（清单、重复、提醒、日历与日记联动）

> 专题约束，与 AGENTS.md 同等效力；改动本主题前先读本文件，新规则写在这里。界面规格见 DESIGN.md §5.35。

## 数据
- 必须：待办独立于日记，存 `todo_lists` / `todos` 两表；收集箱不是一行数据；截止日存本地日期与分钟数，不存时间戳。
- 必须：JSON 列只在 `todo_rules.dart` 容错解码，重复日期只经 `TodoRecurrence`；禁止页面自行换算日期或解析 JSON 列。
- 禁止：日记正文的待办块与独立待办自动迁移或双向同步；只提供手动“转为独立待办”，正文不改动。
- 必须：逐项修改只写那一列，不整行写回；批量在一个事务里，值本来相同的行不写。
- 禁止：为待办另加同步顺序列表；拖动只改被拖的那一行。
- 必须：完成重复待办只经 `completeTodo`：原行推到下一次，另插已完成副本（id 只经 `todoOccurrenceId`，两台设备完成同一次只得一条）。
- 必须：删除为硬删除并可撤销；删清单在同一事务连其中待办删掉（确认框写明条数）；彻底删除日记时清空待办的关联。
- 必须：随完整备份导出与覆盖恢复，合并按业务 id，清单缺失的落回收集箱；日记包不带。局域网同步见 `lan_sync.md`。
- 必须：偏好只存 `app.settings.todos`，随备份导出（失败回滚）；排序默认按优先级，智能识别默认开。
- 例外：待办数据 provider 都基于 `.watch()`，不必登记 `syncedDataRefreshProvider`。

## 功能与入口
- 必须：受 `AppFeatures.todos` 控制（默认关闭）；关闭时隐藏 Tab、设置行、日历与预览页入口，并取消全部提醒。
- 必须：页面只经 `todo_navigation.dart` 打开，面板只经 `showTodoSheet`，快速新建只经 `showTodoQuickAddSheet`。
- 必须：详情只有一份 `TodoDetailBody`，禁止另建详情页；改一项写一项，标题与备注防抖、关闭时立即写。
- 必须：方框只用 `TodoCheckBoxVisual`，优先级配色只经 `TodoPriorityColors`（禁止改回跟随主题色），清单配色只经 `TodoListStyle`。
- 例外：页头“更多”用弹出菜单（用户要求），不受 AGENTS.md §6“约 4 项以内”限制。
- 必须：列表里勾选先收起这一行再写库；日历与日记里勾选即写。滑动操作只在手机，桌面改右键菜单。
- 必须：批量操作只经 `todo_batch_actions.dart`，各一条可撤销提示；批量改日期不选时刻时各自保留时刻。
- 必须：界面上的“今天”（分组、逾期、相对日期、概览卡、日历索引）只经 `todoTodayProvider`，跨零点自动换天、回到前台时校正；禁止在待办界面里用 `DateTime.now()` 算今天（写库时取时刻不在此列）。
- 必须：拖动排序松手后先按新顺序显示，库里的顺序推送回来（或写完后又来了一次推送）再以库为准，只经 `TodoReorder`。
- 必须：列表里接连完成的撤销提示经 `TodoCompletionUndo` 合并成一条“已完成 N 条”，撤销整批恢复；日历、详情里的完成仍各自一条。
- 必须：行上按分钟变化的说法（一小时内到期的“还有 N 分钟”）只经 `todoMinuteProvider`，只有倒数胶囊监听它，别的界面禁止每分钟重建。
- 必须：手机左滑按 `TodoSettings.swipeLeft`（删除 / 改期），改期弹截止日面板、这一行弹回原位不移走；整行另挂读屏动作（完成 / 恢复、改期、删除），与滑动和右键菜单等价。
- 必须：桌面行可拖到左栏，只有今天（改到今天）、收集箱与清单（移进去）接（`TodoView.acceptsDrop`），可撤销；多选时拖的是全部选中的。
- 必须：步骤转为独立待办只经 `convertTodoStepToTodo`、备注清单行（`- [ ]` / `- [x]`）转步骤只经 `moveTodoNoteChecklistToSteps`，各自一个事务；清单行的识别只经 `splitTodoNoteChecklist`。
- 必须：推迟次数存 `metadata.postponeCount`，只在未完成的待办改到更晚的日子时加一（单条与批量改期同经 `_todoDueChangeFor`），只读改这一个键；改早、只换时刻、第一次设日期不算。
- 必须：坚持记录只按这串的已完成副本（`watchTodoOccurrences`）经 `TodoStreak.build` 算：累计次数、从最近一次往前连续按时完成的次数、最近 12 周的完成格；不另存统计。
- 必须：改期只经改期面板 `showTodoDueSheet`（今天 / 明天 / 本周末 / 下周一 / 一周后 / 选日期…，日子只经 `TodoRescheduleDays`，选日子时保留原时刻）；入口为左滑（设为改期时）、桌面右键“改期”、多选栏、逾期组、详情与规划今天。
- 必须：“规划今天”只经 `TodoDayPlan.build`（已逾期 / 三天内到期 / 重要但没日期 / 三天内添加，今天的不列），只由今天概览卡上的按钮打开、不自动弹出，不加数据列；推迟 3 次起行上提示。
- 必须：计划视图七天内每天一组（`TodoGroupKind.day`），再往后归“更晚”；概览卡下的周条只往后翻，点某天在那天新建，桌面可把行拖到某天改期（可撤销）。
- 必须：回顾数字（本周完成、最近 7 天、连续天数）只经 `TodoReviewStats.build` 按已完成的待办现算，已完成视图的概览卡与探索页的待办卡共用 `TodoReviewSummary`，不另存统计；今天还没完成时连续天数算到昨天。
- 必须：桌面键盘流只在 `AppPlatform.isDesktop` 生效、只经 `TodoKeyboardActions`（↑↓ 移动焦点行、空格勾选、回车打开详情、Delete / Backspace 删除可撤销、Ctrl / ⌘ + D 改期、Alt + 1–6 切智能视图、Esc 依次退出多选 / 关详情栏 / 放下焦点行），只在列表本身有焦点时接（输入框、面板里按键不受影响）；Ctrl / ⌘ + 数字仍归首页 Tab。待办 Tab 上 Ctrl / ⌘ + F 打开待办搜索，其余 Tab 仍是日记搜索。
- 必须：Shift + 点按从上次点的那条（`TodoPageSelection.anchor`）连选到这一条，按当前可见顺序；悬停浮出的行尾按钮只放改期与删除，与右键菜单同一入口。
- 必须：搜索拆词只经 `splitSearchTerms`、命中高亮只经 `searchHighlightSpans`（与日记搜索同一口径）；筛选（状态、清单、高优先级、有日期）只经 `TodoSearchFilter`，是页面临时状态、不持久化；没有关键词但选了筛选时按筛选列出全部未完成的与最近完成的。
- 必须：待办标签与日记标签完全分开（用户决定，防止互相污染）：只存在待办的 `metadata.tags`（口径只经 `TodoTags`：去首尾空白与开头的 `@` / `#`、中间空白换成 `_`、不分大小写去重、每条至多 10 个、每个至多 24 字），不进 `tags` 表、没有标签顺序与颜色，不升 schema、不提升同步格式版本；禁止在待办里复用日记标签的表、顺序、建议、搜索（`openDiaryTagSearch`）、批量标签与组件，日记侧（标签管理、标签栏、探索页、同步的标签顺序）也禁止读到待办标签。外观只借 DESIGN §5.2 的微胶囊。
- 必须：标签的读写只经 `_AppDatabaseTodoTagOps`，每个方法一个事务、只读改 `tags` 这一个键、标签不变的行不写；批量加标签、改名 / 合并、删除都返回改动前的行，撤销只经 `restoreTodoFields(..., TodoBatchField.tags)`。重复待办的已完成副本、复制为新待办、步骤转为独立待办都带上原来的标签。
- 必须：一个标签存在就是至少有一条待办带着它（`watchTodoTags` 现算用量，不另存）；标签视图（`TodoView.tag`，键 `tag:<名称>`，不分大小写）只列带它的未完成待办，在里面新建的预先带上它；视图面板与左栏有标签时才出现“标签”一组，“管理”进标签管理页（改成已有的名字即合并，删除只从待办上去掉）。
- 必须：清单分区的定义只存在清单行的 `metadata.sections`、待办所属只存在待办的 `metadata.sectionId`（口径只经 `TodoSections`，每个清单至多 30 个、名称至多 40 字），读写只经 `_AppDatabaseTodoSectionOps`：一个事务里读改写、只动这一个键、值不变的行不写；不升 schema、不提升同步格式版本。局域网同步按清单行整条“后写者胜”，两台设备同时改同一清单的分区以后写的为准，不另做分区级合并。
- 必须：认不出的分区（被删、或待办移到了别的清单）一律按“未分区”显示，不清掉待办上的 `sectionId`（移回原清单即回到原分区）；收集箱没有分区，智能视图不分区、行上写“清单 · 分区”。
- 必须：分区只在单个清单视图里出现：未分区的在最上、各分区按顺序（空的也出标题），标题可折叠（折起时行从列表里拿掉、由列表动效收起），行尾“+”在这个分区里新建、菜单为重命名 / 上移 / 下移 / 删除；删除分区时其中的待办默认回到未分区，可勾选连同删除（确认框写明条数），可撤销（`restoreTodoSection`）。
- 必须：手动排序时分区标题与行在同一个可拖动列表里，行拖过标题即换进那个分区，顺序与分区在同一个事务里写（`moveTodoToSection`），松手时本地先按新分区排、库里的分区跟上才撤掉（`TodoReorder.sections`）；批量移到分区只经 `moveTodosToSectionWithUndo`，撤销经 `TodoBatchField.section`。重复待办的已完成副本、复制、步骤转待办都带上分区。
- 必须：智能识别只经 `parseTodoQuickInput`，中英日俄写法同时生效、与界面语言无关；手动选的 > 识别的 > 视图预填（快速新建面板手上的值只经 `TodoQuickAddDraft`）。
- 必须：识别顺序为清单 → 已有标签 → 优先级 → 重复 → 提醒 → 日期 → 时刻 → 新标签，`@标签` 前面必须是空白或开头（`a@b.com` 不算），新标签写到空白、标点或下一个已识别片段为止，标签可单个点掉；后识别的不与先识别的重叠（“每周一”是重复不是日期，“前一天晚上8点”是提醒不是截止时刻）；识别出重复而没写日期时截止日取今天起第一个符合的日子；提醒没有截止日、或按分钟提前却没有截止时刻时不算识别，原文留在标题里。中文“工作日”为法定工作日（`legalWorkdays`），英日俄的 weekdays / 平日 / по будням 为周一到周五。
- 必须：快速新建粘贴多行时先问“拆成 N 条待办？”，拆开时每行各自识别、一次写库；刚添加的进“已添加”堆栈（可点开、可撤销删除）。
- 必须：专注记录只存 `todo_focus_sessions`（schema v24，口径只经 `todo_focus.dart`：不到 60 秒不记、实际时长不超过计划时长），读写只经 `_AppDatabaseTodoFocusOps`；写完即不可变、应用里不改不删，备份合并与局域网同步按 `session_id` 取并集；进行中的计时只存本机，结束才落库。
- 例外：删除待办（含删清单、连同删除分区）时不清空专注记录上的 `todo_id`，与“删除路径清理关联”的总规则不同：撤销删除后这条待办的累计照旧，同步也不必改写不可变的记录；指向不存在的待办时按“没有关联”算，总时长照常计入回顾。
- 必须：AI 入口只有详情步骤卡的“AI 拆解”与快速新建的“AI 整理”，只在 `aiModuleAvailableProvider(AiModule.todos)` 时出现（AI 规则见 `ai_assistant.md`）；流式生成与预览只经 `TodoAiDrafts`，模型输出只经 `parseTodoAiSteps` / `parseTodoAiItems` 逐行、逐字段校验，生成中只认收完的整行。建议一律先预览、可勾掉与改写，确认后才写库：拆解经 `setTodoSteps` 一次接在已有步骤后（去掉已有的、不超过 `TodoStep.maxSteps`），整理经 `createTodos` 一次建好（自带的值优先，没带的按 `TodoQuickAddDraft.inputForAi` 取面板上手动选的 / 预填的，整段原文的识别结果不算）；放弃不写任何东西。
- 必须：日记互通只有“添加待办”“转为独立待办”与正文后的“相关待办”；功能关闭时不订阅、不占位。
- 必须：日历上的待办只经 `todoCalendarIndexProvider`，待办开启且 `showTodos` 时才订阅；AI 工具口径见 `ai_assistant.md`。
- 必须：日历选中日的待办与日记排在同一条时间线，排序只经 `CalendarDayAgenda`（全天在前，定时按时刻穿插，已完成留在原处）；逾期只在选中今天时列在时间线之上，逾期的重复待办在今天的投影不重复列出。

## 动效
- 必须：列表数据变化（换排序，改日期、优先级或清单，撤销，同步）只经 `ListChangeHost` + `MakeRoomController(acrossSlivers: true)`：仍在视图里的行滑到新位置（跨组也一样），移出视图的行与空了的组标题原地收起再让位，回到视图的行原地展开；勾选后先收起的行不再滑动；分组与列表项按数据缓存，同一份数据不重算。
- 必须：可折叠的已完成组的出现、消失与折叠一律整块展开 / 收起（`AnimatedSliverCollapse`），禁止逐行收起；消失途中留下的画面不可点、不参与让位，已挪到别处的行不留。
- 必须：切换视图先让旧列表退场、在看不见的那一帧换视图、再错峰入场（与日记列表整体切换共用 `DiaryListSwitchMotion`），方向按视图面板里的先后；每个视图各自记住滚动位置；页面不在屏上或减少动画时直接换。
- 必须：概览卡、分组条数、视图格与左栏计数变化时逐位滚动（`AnimatedRollingText`），句中的数字只滚数字；静止时仍是普通文字。
- 必须：列表里勾选的时序只经 `TodoCompleteMotion`（按下压小 → 弹起、对勾描出 → 删除线按行划过 → 停一拍 → 收起 → 写库）；删除线按标题实际断行逐行划，RTL 镜像；减少动画时直接写库。
- 必须：“今天清零”（今天还剩的当场由有变 0 且今天完成的变多）只演一次：环合拢后轻弹、环心换成对勾、主句交叉淡入、一次中等触觉；打开时已做完或把最后一件改走都不演。
- 必须：多选的页头只换内容（`PageHeader.contentKey` 交叉淡入）、不换底板；操作栏以弹簧升起、退出时沉到屏外再移出树，只平移不淡入淡出（可能是玻璃）。
- 必须：详情打开时各块按列表切换的节奏错峰入场（`ExpressiveEntrance.delay`）；宽窗口详情栏换一条时交叉淡入；属性胶囊值变化时底色、字色与描边补间、宽度按弹簧过渡、文字交叉淡入；步骤增删展开 / 收起，删除收起后才写库。

## 提醒与通知
- 必须：提醒一律相对截止日；自定义时间可选到截止日之后、截止日随之顺延，禁止改回只许选到截止日。
- 必须：排提醒只经 `planTodoReminders` 与系统已排通知对账：只新排今后 30 天、最多 200 条（iOS 60）；仍有效且尚未投递的系统提醒到点后保留一天。排程失败须重试。禁止在网关外直接排系统通知。
- 必须：系统通知只经 `TodoNotificationGateway`：手机交给系统定时，不许精确闹钟时退回不精确；桌面只在应用运行时提醒，设置页写明。
- 必须：Android 定时唤醒走原生 `TodoReminderManager`（`AlarmManager.setAlarmClock` + 开机 / 升级 / 时间与时区变化 / 权限变化接收器 + `WorkManager` 巡检），确保应用不在后台也能弹出；通知按钮与小组件勾选在后台 isolate 写入后须同步取消或补排原生闹钟。
- 必须：通知小图标 `ic_stat_todo` 在 `res/raw/keep.xml` 登记保留，以免 release 资源裁剪删掉。
- 禁止：启动时主动请求通知权限；只在用户加提醒时与设置页权限行请求。
- 必须：通知按钮写库只经 `applyTodoNotificationAction`，“完成”只在那一次仍是当前截止日时生效；后台与主 isolate 不同时写库。
- 必须：点开通知先切到待办 Tab 再打开详情，应用锁遮罩在上。
