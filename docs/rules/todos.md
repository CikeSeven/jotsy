# 待办（清单、重复、提醒、日历与日记联动）

> 从 `AGENTS.md` 拆出的专题约束，与 `AGENTS.md` 同等效力（必须 / 禁止 / 例外）。改动本主题的代码前先读本文件；本主题新增或修改的规则写在这里，不写回 `AGENTS.md`。界面规格见 DESIGN.md §5.34。

- 必须：待办独立于日记，存 Drift `todo_lists` / `todos` 两张表（schema v19，`app_database_todo_schema.dart`）：业务 id 为 `list_id` / `todo_id`（UUID v4），`list_id` 为 NULL 即收集箱（收集箱不是一行数据），截止日 `due_date` 存本地日期文本 `YYYY-MM-DD`、截止时刻另存 `due_minute`（一天中的分钟数，NULL 为全天），不存时间戳；步骤、提醒、重复与扩展字段是 JSON 文本列，模型与逐字段容错解码只在 `todo_rules.dart`（认不出的提醒 / 步骤跳过、认不出的重复按不重复推算，行里的原文不改写），重复日期推算只经纯函数 `TodoRecurrence`（`todo_recurrence.dart`，月底与 2 月 29 日顺延到月末，法定工作日直接读 tyme `LegalHoliday`）；禁止页面自行换算日期或解析 JSON 列。日记正文里的 `todo_list` 块与独立待办互不相干，禁止自动迁移或双向同步；只提供手动的“转为独立待办”（日记正文不改动）。
- 必须：读写只经 `_AppDatabaseTodoQueries` / `_AppDatabaseTodoOps` / `_AppDatabaseTodoCompleteOps` / `_AppDatabaseTodoListOps`：逐项修改每次只写一列（外加 `updated_at`），不整行写回；排序 `sort_order` 为 REAL，拖动只把被拖的那一行改为两邻居的中点（`TodoSortOrder`），分不开时才整清单重新编号（重新编号不刷新 `updated_at`），禁止为待办另加同步顺序列表。完成重复待办只经 `completeTodo`：原行推到下一次（`TodoRecurrence.nextDueAfterCompletion`：按截止日时取“当前截止日与完成当天较晚者”之后的下一次，按完成日时从完成当天加一个间隔并把起点挪过去）、步骤重置、稍后提醒作废、`metadata.repeatDone` 加一，另插一条已完成副本（id 只经 `todoOccurrenceId(todoId, 这一次的日期)`，两台设备各自完成同一次只得一条）；次数用完或过了截止日期时只把原行标为完成。撤销只经 `undoTodoCompletion`。
- 必须：删除都是硬删除并给可撤销提示（`todo_actions.dart` / `todo_list_actions.dart` 经 `showTrackedSnackBar`）：删清单连同其中的待办（含已完成）在同一事务里删掉，确认框写明条数；彻底删除日记在同一事务里清空 `todos.linked_diary_id`。备份：随完整备份导出（载荷键 `todoLists` / `todos`）、覆盖恢复，合并按业务 id（`BackupTodoMerge`，合并并覆盖时清单的拖动顺序保留本机的），所在清单不在载荷里的待办落回收集箱；日记包不带待办。局域网同步见 `lan_sync.md`（两个实体、整条记录后写者胜，悬空的清单 / 日记引用由规划器置空）。
- 必须：待办 Tab 为 `HomeTab.todos`（底栏在日记之后），受 `AppFeatures.todos` 控制（默认关闭，属于数据类开关、局域网同步只同步开启）；关闭时隐藏 Tab、设置首页“整理”组的“待办”行、日历上的待办、预览页的待办入口，并停掉全部提醒，数据保留。页面只装配（`todos_page.dart`），视图与分组只经纯函数 `buildTodoGroups`（今天 / 计划按截止时刻分组，重要为高优先级，全部按清单分组，收集箱与清单底部可折叠“已完成”，已完成按完成日期分组），当前视图是页面临时状态，“打开时显示”存进设置。窄窗口（< 1024）页头下一排视图胶囊（`TodoViewStrip`，套 `DesktopHorizontalScroll`），宽窗口左栏 `TodoSidebar`。新建入口：窄窗口为首页 FAB（玻璃底栏为并排按钮，只在日记 / 待办 Tab，`HomeTab.hasCreateFab`），待办 Tab 上新建待办（`TodosPage` 经 `onCreateActionChanged` 注册）；宽窗口外壳（`HomeChromeScope.wideShellOf`）没有 FAB，新待办在页头；Ctrl / ⌘ + N 在待办 Tab 新建待办。快速新建只经 `showTodoQuickAddSheet`（回车即写库、面板留着接着记），按视图预填清单 / 今天 / 高优先级。
- 必须：待办相关页面只经 `todo_navigation.dart`（`openTodoDetail` / `openTodoSearch` / `openTodoListsManage` / `openTodoSettings`）打开；面板只经 `showTodoSheet`（`showAppModalBottomSheet` 之上统一按内容高度展开、减少动态效果时直接出现）。详情页改一项写一项，标题与备注经 `TodoDebouncedWriter` 防抖写库、离开页面立即写掉，页面期间登记为 `EditingSessionBlocker`；列表与清单管理的拖动排序经 `ReorderEditingGuard`。待办方框统一用 `TodoCheckBoxVisual`（与日记正文的待办块同一种方框），按优先级着色（高 error、中 tertiary、低 primary，配对的 on 色画对勾），禁止另画方框；手机列表左滑删除只经 `DiarySwipeActionItem`，桌面不提供滑动。清单的强调色与图标只经 `TodoListStyle`（颜色与日记模板、日记本同一套 `diaryTemplateAccentColors` 换算，图标共用 `NotebookIcon`，默认 `listCheck`），禁止直接涂种子色。
- 必须：待办的偏好只存单个 JSON 设置键 `app.settings.todos`（`TodoSettings`：显示已完成、默认清单、排序、打开时显示、全天待办的提醒时刻、稍后提醒时长、锁屏隐藏内容），逐字段容错，随备份导出（失败回滚），全部为默认时移除该键；禁止另加零散设置键。数据 provider 一律基于 `.watch()`，不必登记 `syncedDataRefreshProvider`。
