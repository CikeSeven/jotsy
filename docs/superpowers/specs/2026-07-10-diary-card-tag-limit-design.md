# 日记卡片标签展示数量设计

## 目标

允许用户在设置中配置日记卡片最多展示多少个标签。取值范围为 `0–20`，默认值保持为 `2`；`0` 表示不展示标签行。主页、搜索页和归档页应使用同一配置并在保存后立即刷新。

## 方案比较

1. 推荐：在 `SettingsService` 持久化整数，通过响应式 provider 由页面装配层读取，再显式传入共享列表与标签组件。依赖清晰，三个页面行为一致，展示组件保持可独立测试。
2. 在 `DiaryItemTagRow` 内直接读取全局设置。改动较少，但会把纯展示组件耦合到 Riverpod 和持久化服务，不符合现有分层。
3. 只在主页读取配置。实现最小，但搜索页和归档页仍固定展示两个标签，产生用户可见的不一致。

采用方案 1。

## 架构与数据流

- `SettingsService` 新增 `diaryCardTagLimit` 配置、`ValueNotifier<int>`、SharedPreferences key 和 setter。加载与写入均将值约束到 `0–20`，缺失或不可解析时回退到 `2`。
- `app_service.dart` 增加响应式 provider，将 notifier 变化桥接给 Riverpod。
- 主页、搜索页和归档页 watch 同一 provider，并把当前值传给 `DiariesListSection`。
- `DiariesListSection` 将值传给普通列表与瀑布流中的 `DiaryItemTagRow`。
- `DiaryItemTagRow` 展示前 N 个标签，剩余数量继续以 `+N` 汇总；N 为 0 时不渲染标签行。
- `DataArchiveService` 显式导出和兼容恢复该配置，旧备份缺少字段时保留默认值。

## 设置界面

配置放在“外观与语言”二级页的新“日记卡片”显示区。列表项显示当前状态，点击后打开数值选择弹窗：

- 使用 `0–20`、20 个分段的 Slider。
- `0` 显示为“不显示标签”，其他值显示为“最多显示 N 个标签”。
- 左侧为灰色“取消”文本按钮，右侧为主色“确定”文本按钮。
- 所有新增文案进入中英文 ARB，并包含 `@key` metadata；含数量的文案使用 `int` placeholder。

标签数量较大时，标签按卡片可用宽度自然换行，避免窄瀑布流出现横向溢出。锁定时间胶囊继续隐藏普通卡片内容，不展示标签。

## 边界与失败处理

- 设置读取到负数时归一化为 `0`，大于 `20` 时归一化为 `20`，错误类型或缺失值回退为 `2`。
- setter 同样归一化，避免调用方绕过 UI 写入非法值。
- 设置保存沿用当前即时更新后持久化的模式；弹窗取消时不修改配置。
- 标签列表为空或配置为 `0` 时不保留额外垂直间距。

## 验证

- SettingsService 测试覆盖默认值、`0`、`20`、越界归一化、持久化恢复和 notifier 更新。
- `DiaryItemTagRow` widget 测试覆盖自定义上限、`+N`、`0` 隐藏，以及窄宽度下 20 个标签无 overflow。
- 列表 section 测试确认配置透传且锁定卡仍不泄露标签。
- 设置 UI 测试确认弹窗可选择并保存数值。
- 备份源码/行为测试确认新字段参与导出与恢复。
- 完成后运行 `flutter gen-l10n`、`dart format`、相关 `flutter test` 与 `flutter analyze`。
